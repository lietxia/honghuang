# 其他凶兽（异兽志）

除四凶外的知名凶兽、异兽——多出自《山海经》《淮南子》等，洪荒流常以"凶兽"纳入量劫/洪荒大战素材。详见[灵兽神兽/山海经异兽图鉴]（70+异兽全图鉴）。

## 一、尧时"害民六兽"（后羿除害群）
| 凶兽 | 形象/特性 | 出处 | 结局 |
|---|---|---|---|
| **九婴** | 九头怪（水火之怪），喷水吐火，声如婴儿啼 | 《淮南子》 | 尧命后羿射杀 |
| **凿齿** | 齿长三尺如凿（人形怪兽），持戈盾 | 《淮南子》 | 羿杀之于畴华之野 |
| **大风（大凤）** | 大鸟/鸷鸟，振翅则大风，害民 | 《淮南子》 | 羿以青丝系矢射杀 |
| **修蛇（巴蛇）** | 巨蛇——"巴蛇吞象，三岁而出其骨" | 《山海经·海内南经》 | 羿斩之于洞庭 |
| **封豨（封狶）** | 大野猪，为害桑林 | 《淮南子》 | 羿杀之 |
| **十日** | 十日并出（灼杀万物） | 《淮南子》 | 后羿射落九日（[大事件/后羿射日与夸父逐日]） |

> 即"尧使后羿上射十日、下除六害"（九婴/凿齿/大风/修蛇/封豨+猰貐）神话群——上古英雄除兽叙事核心。

## 二、《山海经》凶兽/异兽（知名者）
| 凶兽 | 形象/特性 | 出处 |
|---|---|---|
| **相柳（相繇）** | 共工之臣——九首蛇身，所过之处成泽溪（水患），其血腥臭不可生谷 | 《山海经·海外北经》 |
| **猰貐（窫窳）** | 龙首（或人面牛身），食人，为害（羿所除"六害"之一） | 《山海经·海内西经》 |
| **朱厌** | 猿形、白首赤足——"见则天下大兵"（战争之兆） | 《山海经·西山经》 |
| **蛊雕** | 似雕而有角，音如婴儿——食人 | 《山海经·南山经》 |
| **蠃鱼** | 鱼身鸟翼、音如鸳鸯——"见则天下大水"（水灾之兆） | 《山海经·西山经》 |
| **诸怀** | 牛形、四角、人目、猪耳——食人 | 《山海经·北山经》 |
| **狍鸮** | 羊身人面、目在腋下——即饕餮（见[凶兽/四大凶兽]） | 《山海经·北山经》 |
| **帝江** | 六足四翼无面目（浑敦/混沌相类） | 《山海经·西山经》 |
| **穷奇/梼杌/混沌** | 四凶（见[凶兽/四大凶兽]） | 《山海经》《神异经》 |

## 三、传说凶兽（典籍/民间）
| 凶兽 | 特性 |
|---|---|
| **犼（hǒu）** | 似犬（或马形有鳞），极凶，好食龙脑——"犼食龙"传说（旱魃/石犼相关） |
| **旱魃（魃）** | 黄帝之女（或僵尸），所过赤地千里（干旱之妖） |
| **九尾狐**（恶面） | 食人（《山海经》青丘之狐）——妲己之形（[人物/妲己]）；后世瑞/妖两面 |
| **魑魅魍魉** | 山林鬼怪总称（浑敦/穷奇之属演化） |
| **毕方** | 独脚火鸟，见则火灾（亦为火神使者） |
| **灭蒙鸟/钦原** | 剧毒之鸟（螫兽兽死、螫树树枯） |

## 四、洪荒流凶兽设定
- 洪荒流"凶兽"体系：混沌戾气所生（兽皇神逆统领，杀戮大道）——见[凶兽/总览]；
- 凶兽在量劫中的定位："无灵智、只知杀戮的量劫燃料"——巫妖大战/封神大战可见凶兽群出；
- 知名洪荒凶兽：穷奇/梼杌/饕餮/混沌（四凶）+九婴/相柳/凿齿/猰貐（后世演绎为洪荒凶兽）——构成凶兽谱系；
- 与[灵兽神兽/山海经异兽图鉴]（70+异兽）交叉收录（异兽/凶兽/神兽分类：灵兽神兽篇重祥瑞、凶兽篇重凶暴）。
