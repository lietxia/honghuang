# 其他凶兽

除四凶外的知名凶兽、异兽（多出自《山海经》）。

| 凶兽 | 形象/特性 | 出处 |
|---|---|---|
| 九婴 | 九头怪，喷水吐火，尧命后羿射杀 | 《淮南子》 |
| 相柳（相繇） | 共工之臣，九首蛇身，所过成泽溪，禹杀之其血腥臭 | 《山海经·海外北经》 |
| 修蛇（巴蛇） | 巨蛇，能吞象，三岁吐骨；尧命羿斩之 | 《山海经·海内南经》 |
| 朱厌 | 猿形、白首赤足，见则有兵（大战之兆） | 《山海经·西山经》 |
| 蛊雕 | 似雕而有角，音如婴儿，食人 | 《山海经·南山经》 |
| 蠃鱼（luǒ yú） | 鱼身鸟翼，音如鸳鸯，见则有水灾 | 《山海经·西山经》 |
| 诸怀 | 牛形、四角、人目、猪耳，音如鸣雁，食人 | 《山海经·北山经》 |
| 凿齿 | 齿长三尺如凿，尧命羿杀之 | 《淮南子》 |
| 大风 | 大鸟（或鸷鸟），害民，羿以弓矢除之 | 《淮南子》 |
| 封豨（封狶） | 大野猪，为害，羿杀之 | 《淮南子》 |
| 犼（hǒu） | 似犬、食龙脑，形如马而有鳞，极凶 | 传说/榜中榜 |
| 穷奇（见四凶） | 详见四大凶兽篇 | — |

> 以上"十日、九婴、大风、封豨、修蛇"等，多归于"尧使后羿除害"的神话群。
