# 阵法总览（洪荒阵法体系）

洪荒流小说中的"阵法"是一门博大精深的大道——不同于凡间兵法奇门，而是以天地为盘、以星辰万物为子、以圣人或多位大能的修为为引，将无穷法力凝聚成可改天换地、甚至毁天灭地的恐怖杀局。在《佛本是道》所奠定的现代洪荒体系里，阵法既是种族气运的守护屏障，也是量劫之中决定胜负的关键底牌。本总览为索引，梳理整个阵法体系。来源：洪荒流设定、《封神演义》阵法、《西游记》阵法。

## 体系定位
| 要素 | 说明 |
|---|---|
| 阵法本质 | 以天地为盘、星辰万物为子——多位大能合力凝聚法力的"集体大神通" |
| 主持者 | 普通阵法一人/数人主持——顶级大阵需多位准圣/大罗/圣人联手布置或攻破 |
| 威力决定 | 阵法威能直接取决于主持者修为——圣人级大阵足以演化地水火风、重立乾坤 |
| 圣人默契 | 圣人之间忌讳直接厮杀——多以阵法博弈（以免洪荒崩碎）——"圣人不出手、阵法定胜负"（[量劫/量劫机制]） |

## 阵法文化
- **阵法=集体力量**：一人不成阵——阵法体现"万仙来朝/多人协作"的洪荒战争形态；
- **阵法与气运**：镇族大阵守护种族气运（周天星斗护妖庭、都天神煞护巫族——[概念/气运功德香火业力]）；
- **阵法与量劫**：封神大战本质=阵法大战（十绝阵→黄河阵→诛仙阵→万仙阵——层层升级——[大事件/封神之战始末]）；
- 攻伐大阵vs守护大阵、圣人不出手的默契——理解洪荒战争逻辑的关键（[量劫/量劫机制]）。
