# 阵法总览

洪荒强者以阵法聚势，顶级大阵需多人或圣人主持。

## 攻伐大阵
| 阵法 | 主持/所属 | 威力 |
|---|---|---|
| **诛仙剑阵** | 通天教主（诛仙四剑） | 非四圣不可破，杀伐第一 |
| **万仙阵** | 通天教主 | 截教镇教，集万千弟子之力的绝阵 |
| **周天星斗大阵** | 妖族天庭（河图洛书） | 引周天星辰之力，可灭世 |
| **混元河洛大阵** | 帝俊（河图洛书） | 演绎地水火风、时空 |
| **十二都天神煞阵** | 十二祖巫 | 聚盘古真身，战力媲美圣人 |
| **九曲黄河阵** | 三霄（混元金斗） | 削十二金仙三花五气 |
| **两仪微尘阵** | 玉虚/元始一脉 | 时空困敌 |

## 十绝阵（封神）
- 天绝、地烈、风吼、寒冰、金光、化血、烈焰、落魂、红水、红砂 —— 截教弟子所布，封神大战有名。

> 阵法威能取决于主持者修为；圣人级大阵可改天换地，故圣人之间不直接厮杀（见[量劫/量劫机制](量劫/量劫机制.md)）。
