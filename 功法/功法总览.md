# 功法总览（修炼根基谱）

功法是修行者打下的修炼根基——决定吸纳灵气的效率、境界上限与神通高度。不同教派、种族传承各异。本篇为[功法/道门与佛门]的补充拓展，收录道佛妖巫散修各系功法全景。

## 一、道门功法
| 功法 | 传承 | 说明 |
|---|---|---|
| **太上道经 / 九转玄功** | 老子、人教 | 内丹无为，炼炁化神——人教根本（见[丹道与内丹]） |
| **玉虚道经 / 玉清诀** | 元始、阐教 | 内丹心性，玉虚宫十二金仙所修 |
| **上清灵宝真诀 / 通天剑道** | 通天、截教 | 剑修、法宝法术并重（诛仙四剑配合） |
| **斩三尸法** | 鸿钧所传 | 圣人证道必修（斩善/恶/执念，见[境界/斩三尸与证道]） |
| **玄功四气**（玄清/玄灵/玄空/玄明） | 鸿钧分传 | 人教/阐教/截教/西方教根基（见[功法/道门与佛门]） |
| **五雷正法 / 神霄雷法** | 道门雷部 | 召雷役神（见[道教神佛/雷部]） |
| **符箓咒术** | 正一道 | 符水治病、神咒驱邪（见[符箓咒术]） |

## 六、境界与功法关系
- **功法决定根基上限**：圣人功法（斩三尸/造化玉碟）皆触及大道；凡人功法难逾大罗；
- **功法→境界→神通→法宝**：功法筑基、境界定高、神通应用、法宝外物——四者递进（见[境界/境界详解]）；
- **功法与气运**：大教功法承载教派气运（[概念/气运功德香火业力]）——截教万仙来朝皆修截教道法，封神覆灭后功法随之凋零。
