# 功法总览

功法是修行者打下的修炼根基，不同教派传承各异。

## 一、道门功法
| 功法 | 传承 | 说明 |
|---|---|---|
| 太上道经 / 九转玄功 | 老子、人教 | 内丹无为，炼炁化神 |
| 玉虚道经 / 玉清诀 | 元始、阐教 | 内丹心性，十二金仙所修 |
| 上清灵宝真诀 / 通天剑道 | 通天、截教 | 剑修、法宝法术并重 |
| 斩三尸法 | 鸿钧所传 | 圣人证道必修 |

## 二、佛门功法
| 功法 | 说明 |
|---|---|
| 八九玄功 | 杨戬、袁洪（佛道同源） |
| 大日如来真经 | 佛门根本 |
| 六字大明咒 | 观音 |
| 掌中佛国 | 空间困敌 |

## 三、妖族功法
| 功法 | 使用者 |
|---|---|
| 太阳真经 | 金乌、帝俊太一 |
| 天妖化形术 | 妖族化形 |
| 周天星斗功 | 妖族天庭（配大阵） |

## 四、巫族功法
| 功法 | 说明 |
|---|---|
| 九转玄功（体修版） | 肉身成圣，不修元神 |
| 都天神煞诀 | 祖巫合阵之法 |

## 五、散修/特殊
| 功法 | 使用者 |
|---|---|
| 血神经 | 冥河、阿修罗族 |
| 红云真诀 | 红云（已失传） |
| 造化玉碟残篇 | 鸿钧、创始元灵一脉 |

## 六、境界与功法关系
- 功法决定根基上限，神通是应用，法宝是外物
- 圣人功法皆触及大道，凡人功法难逾大罗
