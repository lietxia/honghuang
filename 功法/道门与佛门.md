# 道门与佛门功法

## 道门功法
| 功法 | 创派/传承 | 说明 |
|---|---|---|
| 玄清气 | 鸿钧传太上老君 | 人教正统，清静无为，炼丹长生 |
| 玄灵气 | 鸿钧传元始天尊 | 阐教正统，正气浩然，护道降魔 |
| 玄空气 | 鸿钧传通天教主 | 截教正统，包罗万象，有教无类 |
| 玄明气 | 鸿钧传接引/准提 | 西方教法门，慈悲渡人 |
| 斩三尸法 | 鸿钧传诸圣 | 斩善/恶/执念三尸，证混元道果 |
| 金丹大道 | 太上老君 | 炼丹内修，长生久视 |
| 太上道经 | 老君 | 人教核心，抱元守一 |
| 玉虚道经 | 元始 | 阐教心法，正气驭宝 |
| 通天剑道 | 通天 | 截教核心，以剑入道，杀伐至极 |
| 大品天仙诀 | 菩提祖师授悟空 | 佛道合一，悟得长生 |
| 天罡变化 | 道门 | 三十六变，猪八戒修炼 |
| 地煞变化 | 道门 | 七十二变，孙悟空/杨戬修炼 |

## 佛门功法
| 功法 | 说明 |
|---|---|
| 六度法门 | 布施、持戒、忍辱、精进、禅定、般若 |
| 四禅八定 | 禅定次第法门 |
| 念佛三昧 | 净土法门，念阿弥陀佛往生极乐 |
| 密宗真言 | 咒语、手印、观想三密相应 |
| 丈六金身 | 佛门至高法身，释迦牟尼证 |
