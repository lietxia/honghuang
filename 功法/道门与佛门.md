# 道门与佛门功法

道教与佛教两系的功法体系——洪荒流中道门功法（玄清气/金丹/剑道/变化）与佛门功法（六度/禅定/金身/真言）各成体系，对应两大修炼道统。来源：洪荒流设定+道教内丹学+佛教禅密法门。

## 一、道门功法

### 玄功四气（鸿钧分传）
洪荒流经典设定：鸿钧老祖闭关后得四道玄气，分传四大弟子，奠定四方道统：
| 功法 | 传人 | 教派 | 特点 |
|---|---|---|---|
| **玄清气** | 太上老君 | 人教 | 清静无为，炼丹长生（正统之首） |
| **玄灵气** | 元始天尊 | 阐教 | 正气浩然，护道降魔 |
| **玄空气** | 通天教主 | 截教 | 包罗万象，有教无类（最杂最博） |
| **玄明气** | 接引/准提 | 西方教 | 慈悲渡人，西方极乐 |

（另一版本：创始元灵四弟子各得一气——鸿钧玄清、混鲲玄灵、女娲玄空、陆压玄明）

### 核心大道功法
| 功法 | 传承 | 说明 |
|---|---|---|
| **斩三尸法** | 鸿钧传诸圣 | 斩善/恶/执念三尸证混元道果（见[境界/斩三尸与证道]） |
| **金丹大道** | 太上老君 | 炼丹内修，长生久视（见[丹道与内丹]）——"一粒金丹吞入腹，我命由我不由天" |
| **太上道经** | 老君 | 人教核心，抱元守一（《道德经》道法） |
| **玉虚道经** | 元始 | 阐教心法，正气驭宝 |
| **通天剑道** | 通天 | 截教核心——以剑入道、杀伐至极（诛仙四剑配合） |
| **八九玄功** | 玉鼎真人→杨戬 | 七十二变护道神功（见[神通/天罡地煞详解]） |
| **大品天仙诀** | 菩提祖师授悟空 | 佛道合一，悟得长生（"灵台方寸山"功法） |
| **天罡变化** | 道门 | 三十六变（猪八戒修炼，见[神通/天罡地煞详解]） |
| **地煞变化** | 道门 | 七十二变（悟空/杨戬修炼） |
| **巫族九转玄功** | 祖巫传巫族 | 肉身成圣不修元神——"盘古真身"（见[势力/巫族]） |
| **妖族天妖吞元功** | 妖族 | 吞噬日月精华、掠夺元气 |

### 道门法脉分支
- **雷法**（五雷正法/神霄雷法）：召雷役神（见[道教神佛/雷部]、[天罡地煞详解]掌握五雷）；
- **符箓咒术**：符水治病、神咒驱邪（见[符箓咒术]）；
- **丹鼎术**：外丹（炼丹炉）内丹（炼精化气）（见[丹道与内丹]）；
- **御剑术**：剑修一脉（通天剑道延伸，[境界/境界详解]剑修）；
- **阵道**：周天星斗大阵/都天神煞大阵/诛仙剑阵（见[阵法/阵法总览]）。

## 二、佛门功法

### 根本法门
| 功法 | 说明 |
|---|---|
| **六度法门** | 布施、持戒、忍辱、精进、禅定、般若——菩萨六波罗蜜（大乘根本） |
| **四禅八定** | 禅定次第（色界四禅+无色界四定）——修止观 |
| **念佛三昧** | 净土法门——念阿弥陀佛往生极乐（"南无阿弥陀佛"） |
| **密宗真言** | 咒语、手印、观想三密相应（藏密/唐密） |
| **三学** | 戒、定、慧——佛教修行总纲 |
| **十二因缘观** | 观无明→行→识→名色……（见[佛教/因果与轮回]） |

### 佛门果位功法（法身）
| 层次 | 说明 |
|---|---|
| **丈六金身** | 佛门至高法身——释迦牟尼证（"金身罗汉"等由此） |
| **金刚不坏体** | 护法金刚修炼（韦驮/四大天王） |
| **卍字神通** | 佛光普照（如来"掌中佛国"） |
| **六神通** | 天眼通、天耳通、他心通、宿命通、神足通、漏尽通（佛教/道教共有，见[神通/各家神通]） |

### 佛门特殊神通（西游/封神）
- **掌中佛国**（如来收悟空）：一掌化作五行山（"五指山"——五行，见[人物/如来佛祖]）；
- **钵盂/金钵**（法海镇白蛇，见[人物/法海]）；
- **六根清净竹**（准提钓金鳌——乌云仙，见[人物/西方二圣]）；
- **人种袋/金铙**（弥勒黄眉，见[人物/黄眉大王]）。

## 三、道佛功法对比
| 维度 | 道门 | 佛门 |
|---|---|---|
| 目标 | 长生久视、飞升成仙 | 脱离轮回、证悟涅槃 |
| 核心 | 炼精化气→元神 | 戒定慧→般若 |
| 果位 | 地仙→天仙→金仙→大罗→圣人 | 阿罗汉→菩萨→佛 |
| 手段 | 丹鼎/符箓/剑道/雷法/阵法 | 禅定/念佛/咒印/六度 |
| 常见神通 | 变化（天罡地煞）、遁术 | 六通、金身、掌中佛国 |

- 洪荒流中佛道互相吸收：大品天仙诀（菩提祖师=佛道融合）、慈航（道教→佛门观音）——见[参考/各小说设定差异]。
