# 洪荒地理架构

## 一、三界
- **天界**：三十三重天，天庭所在（三十六重天为部分设定）。
- **人间（洪荒大陆）**：盘古身躯所化，生灵居所。
- **幽冥（冥界）**：幽冥血海、六道轮回、地府。

## 二、重要地点
| 地点 | 说明 |
|---|---|
| 三十三天 | 天庭、兜率宫（离恨天）、玉虚宫等圣人道场所在 |
| 昆仑山 | 元始道场、玉虚宫、黄中李所在地 |
| 须弥山/灵山 | 西方教/佛教道场，罗睺曾布诛仙阵 |
| 不周山 | 天柱，共工触之而倒；葫芦藤生长处 |
| 幽冥血海 | 冥河老祖、阿修罗族、六道轮回所在 |
| 蓬莱/方丈/瀛洲 | 海上仙山 |
| 火云洞 | 三皇居所 |
| 万寿山五庄观 | 镇元子，人参果树 |

## 三、连通
- 南天门（天界↔人间）、幽冥海（人间↔幽冥）是三界勾连要冲。
