# 九州与名山

洪荒大陆广袤无垠——其上既有以大禹治水划定的"九州"行政地理——又有星罗棋布的"名山"与"道场"。九州是人间文明的坐标，名山则是天地灵脉与神仙道场的汇聚之所——二者一横一纵——共同勾勒出洪荒人间的骨骼与经脉。来源：大禹九州制（《尚书·禹贡》）、[人物/大禹]、[地理/总览]。

## 一、九州（大禹治水所定）
洪水退去后——大禹勘定天下为九州——奠定华夏地缘之基（[人物/大禹]定九州）：
| 州 | 今地 | 说明 |
|---|---|---|
| 冀州 | 河北一带 | 尧舜中心（帝都所在——"冀州为天下之中"） |
| 兖州 | 山东/河南 | 黄河下游 |
| 青州 | 山东东部 | 泰山以东 |
| 徐州 | 苏北/鲁南 | 淮泗之间 |
| 扬州 | 江淮/江南 | 东南富庶 |
| 荆州 | 两湖 | 楚地 |
| 豫州 | 河南 | 居中为中原（"中国"之始） |
| 梁州 | 川陕 | 西南 |
| 雍州 | 陕西/甘肃 | 关中 |

- 九州不仅是凡间王朝的疆域划分——洪荒流中更被认为是**地脉龙气汇聚之处**——每一州皆有镇守的山水灵秀与气运走向（[概念/气运功德香火业力]地脉气运）——封神、人皇治世皆与之相关（[人族/人皇体系与朝代更替]）；
- **九鼎镇九州**：大禹铸九鼎（[法宝/兵器谱]九鼎——"问鼎中原"）——一鼎镇一州（[人物/大禹]铸九鼎）。

## 二、天下名山
| 名山 | 定位 | 说明 |
|---|---|---|
| **昆仑山** | 万山之祖 | 西王母所居——下通地脉、上接天界——灵气最盛——元始天尊玉虚宫即在此山——洪荒"山系"的总源头（[人物/西王母]、[人物/三清]） |
| **不周山** | 撑天之柱 | 盘古脊梁所化——共工怒触（天柱折断、天倾西北、地陷东南）——最具转折意义的山（[人物/共工]、[大事件/巫妖大战·不周山倾·女娲补天]） |
| **须弥山** | 佛教中心 | 帝释天居其巅——四大部洲的地理与信仰枢纽（[地理/三十三天与四大部洲]） |
| **海上三仙山** | 蓬莱/方丈/瀛洲 | 漂浮于东海之外的仙岛——散仙福地——与洞天福地体系相通（[洞天福地/三岛十洲]） |
| **五岳** | 东岳泰山/西岳华山/南岳衡山/北岳恒山/中岳嵩山 | 各镇一方地脉——人间与天庭沟通的祭礼重地——东岳泰山掌生死（[地祇/五岳大帝]） |

名山之中更分布着牵动量劫的圣人、大能道场（[地理/总览]重要道场）：
| 道场 | 主人 | 说明 |
|---|---|---|
| 昆仑山玉虚宫 | 元始天尊 | 阐教根本（万山之祖） |
| 金鳌岛碧游宫 | 通天教主 | 截教根本（[人物/截教群仙]万仙来朝） |
| 首阳山八景宫 | 太上老君 | 人教道场 |
| 须弥山灵山 | 西方教/佛教 | 佛门圣地（[人物/如来佛祖]雷音寺） |
| 火云洞 | 三皇 | 人道圣地（[人物/火云洞三皇]） |
| 万寿山五庄观 | 镇元子 | 地仙之祖——人参果树（[人物/镇元子与红云]） |

这些道场往往既是修行净土、也是气运锚点——**道场兴衰常与主人乃至整个教派的命运相连**（[概念/气运功德香火业力]教派气运）。

## 四、小结
- **九州定"人界之序"、名山与道场定"天地之灵"**——读懂九州与名山便读懂了洪荒大战之外那片静默却至关重要的地理底盘；
- 无数量劫的因果最终都要落回某一座山下、某一州之中（量劫的地理锚点——[量劫/总览]）；
- 地理与气运：龙脉/灵脉/风水（[道教神佛/道教经典与传统历法]堪舆）——名山=灵脉汇聚——"人杰地灵"的神话表达。
