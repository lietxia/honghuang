# 概念速查

本页以表格速览洪荒流与神话体系中的核心概念，为读者提供快速检索之便。每个概念背后皆有宏大设定，详细阐释请参见天道与因果、五行阴阳八卦及各专篇。

| 概念 | 解释 |
|---|---|
| 鸿蒙紫气 | 成圣之机，共七道，得之可证天道圣位，是洪荒最珍贵的证道凭据 |
| 紫霄宫 | 鸿钧老祖讲道之所，三千客听道、分鸿蒙紫气，是洪荒圣人诞生的圣地 |
| 天道 | 洪荒宇宙的秩序意志，无情无欲、运行万物，制衡圣人；鸿钧合道后身化天道 |
| 大道 | 超越天道的终极法则，即混沌三千大道，混元之上仍可追求 |
| 清灵空明 | 创始元灵四徒（鸿钧、混鲲、女娲、陆压）所修四气：清、灵、空、明 |
| 气运 | 种族与教派兴衰的根本，争夺气运是洪荒斗争的终极目标 |
| 功德 | 开天、造人、立教、补天所获之善报，可证道成圣，女娲即以功德成圣 |
| 六道轮回 | 众生死后归宿，洪荒流中为后土（平心娘娘）所化，佛门则为自然业力机制 |
| 斩三尸 | 圣人超脱之法，斩善、恶、自我执念三尸，证混元道果 |
| 以力证道 | 凭绝对实力破枷锁成圣，最强最难，盘古即以此道开天 |
| 混元大罗金仙 | 圣人的正式称号，洪荒世界的至高境界 |
| 都天神煞大阵 | 巫族十二祖巫合召盘古真身之阵，洪荒第一凶阵 |
| 周天星斗大阵 | 妖族天庭帝俊、太一所布，以周天星辰为基的大阵 |
| 诛仙剑阵 | 通天教主之阵，非四圣齐聚不可破，封神之战的焦点 |
| 不周山 | 天柱，共工怒触而倒，导致天倾地陷、女娲补天 |
| 三十三天 | 天庭及圣人道场所在，鸿钧、三清等居于其上 |
| 圣人不出手 | 圣人不直接厮杀，以免毁天灭地，故洪荒大事多由门人弟子代行 |

以上概念彼此勾连，共同构成洪荒世界"天道—因果—气运—证道"的完整逻辑链条。

## 速查使用说明

**成圣三要素**为鸿蒙紫气、无量功德与自身道行，三者缺一难证圣位；**证道四途**（以力、斩尸、功德、鸿蒙）各有难易高下，以力最强、功德最易。**量劫**源于因果积累过甚，天道借大杀伐以清算，故大神通者皆慎沾因果。**气运之争**贯穿巫妖、封神、佛道之争三大劫，是各教派兴衰沉浮的枢纽。**阵法三绝**为都天神煞、周天星斗、诛仙剑阵，分属巫、妖、截三教。借助本表，读者可快速定位任一概念，再深入对应专篇，即可完整把握洪荒世界的概念体系。
