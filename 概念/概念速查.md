# 概念速查

| 概念 | 解释 |
|---|---|
| 鸿蒙紫气 | 成圣之机（共七道），得之可证天道圣位 |
| 紫霄宫 | 鸿钧讲道之所，三千客听道、分紫气 |
| 天道 | 洪荒宇宙的秩序意志，制衡圣人；鸿钧合道后身化天道 |
| 大道 | 超越天道的终极法则，混元之上 |
| 清灵空明 | 创始元灵四徒所修四气（清/灵/空/明） |
| 气运 | 种族/教派兴衰根本，争夺核心 |
| 功德 | 开天、造人、立教、补天所获，可证道 |
| 六道轮回 | 死后归宿，后土所化 |
| 斩三尸 | 圣人超脱之法（善、恶、我执） |
| 以力证道 | 凭实力破枷锁成圣，最强最难 |
| 混元大罗金仙 | 圣人的正式称号 |
| 都天神煞大阵 | 巫族合盘古真身之阵 |
| 周天星斗大阵 | 妖族天庭之阵 |
| 诛仙剑阵 | 非四圣不破 |
| 不周山 | 天柱，共工触之而倒 |
| 三十三天 | 天庭及圣人道场所在 |
| 圣人不出手 | 圣人不直接厮杀，以免毁天灭地 |
