# 剑仙与飞剑（剑道文化）

中国特有的"剑仙"文化——从"剑"的兵器崇拜到"飞剑千里取人头"的剑仙想象，魏晋志怪至唐传奇定型，还珠楼主《蜀山剑侠传》集大成。"剑仙"与道门"御剑术"（[神通/各家神通]）、截教"通天剑道"（[功法/道门与佛门]）、蜀山"御剑飞行"一脉相承。来源：唐代剑侠传奇（聂隐娘/红线）、《蜀山剑侠传》、道教剑法。

## 一、剑的崇拜与剑仙源流
| 阶段 | 代表 | 说明 |
|---|---|---|
| 先秦铸剑 | 干将莫邪（[上古神话典故/志怪精怪篇]搜神记） | 铸剑神话——剑灵/剑魂想象（"干将莫邪"以身殉剑） |
| 魏晋志怪 | 《列仙传》 | 剑作为仙家法器出现（"剑解"尸解术之一） |
| 唐代传奇 | 聂隐娘、红线女（《甘泽谣》《传奇》） | 剑仙定型——"飞剑"意象（"隐娘刺猿精"——剑术通神） |
| 道教法术 | 青城/武当剑法 | 剑为道器（"剑舞"——[道教神佛/斋醮科仪]法剑） |
| 近代集大成 | 还珠楼主《蜀山剑侠传》 | 蜀山剑仙体系——御剑飞行/飞剑斗法/剑光分化（仙侠小说之祖） |

| 剑仙 | 剑光分化（"万千剑光"）、剑遁飞行（"御剑飞行"）——蜀山体系 |

| 剑之大道 | 洪荒流"大道三千"之一（[宇宙/三千大道]——剑道法则） |

## 四、剑仙文化与洪荒流
- **通天剑道**：截教以剑入道——诛仙四剑（[阵法/诛仙剑阵]）——"剑道"正朔（[人物/三清]通天教主）；
- 御剑术：飞剑千里取人头（[神通/各家神通]——剑修体系在[境界/境界详解]剑修分支）；
- 剑修流派：洪荒流常见"剑修"职业（清高孤傲/攻伐第一——"一剑破万法"）——如《莽荒纪》纪宁剑道（[参考/经典书目与流派沿革]）；
- 剑即大道：剑道法则（洪荒三千大道之一——[宇宙/三千大道]）——"剑修=杀伐之道"代表。
