# 气运·功德·香火·业力（洪荒核心概念）

洪荒流世界观的核心运转机制——气运（命运归属）、功德（天道奖励）、香火（信仰之力）、业力（因果反噬）四者构成了"天道之下众生博弈"的动力系统。来源：知乎（洪荒流系统梳理）、创世中文网（功德气运设定）、知乎（业力释义）。

## 一、气运（天地主角之争）

### 概念
- **气运**：一方势力/种族/个人所承载的"天地气数"——气运盛则万法皆顺、遇难呈祥；气运衰则诸事不顺、劫难临头。
- 天道之下，气运总量有限：气运的争夺贯穿洪荒史（"天地主角"之争）——先天三族→巫妖→人族，每次量劫都是气运大洗牌。
- 气运可聚可散：立教（圣人立教传道聚气运）、造人（人族气运）、功德（天道奖励）皆可聚运；杀伐、失德、逆天则散运。

### 主要气运体系
| 气运 | 归属 | 说明 |
|---|---|---|
| **天道气运** | 天道/鸿钧 | 天地之本运，量劫之源 |
| **圣人气运** | 六圣 | 立教聚运——三清（人教/阐教/截教）、女娲（人族香火）、接引准提（西方教） |
| **人族气运** | 人族 | 女娲创造人族享受人族香火气运；三皇五帝镇火云洞、圣人把控人道气运——"人道气运"之争为封神后主线 |
| **妖/巫气运** | 妖族天庭/巫族 | 巫妖两族气运在巫妖大劫中同归于尽 |
| **势力气运** | 教派/王朝 | 截教（万仙来朝→封神覆灭）、商周（天命转移） |

### 洪荒流经典气运叙事
- 女娲因造人功德+人族香火享受人族气运，此后基本不干涉人族之事（"人妖之母"立场特殊）。
- 三皇五帝受困于火云洞中不得出，圣人把控人道气运——"人族自强不息还是被圣人操控"为洪荒流深度议题（[人族/人皇体系与朝代更替]）。
- 鸿钧合道补天、传道众生、诸圣立教传道、女娲造人补天、后土化轮回——皆为"大功德"（即天运归附）。

## 二、功德（天道奖励）

### 概念
- **功德**：行合天道之事（补天、造人、立教、传道、化轮回、治水等）后天道的奖励——功德金光护体、可证道成圣（"以功德证道"）。
- 功德武学/法宝：至宝有"功德圣器"（鸿蒙量天尺、天地玄黄玲珑塔——盘古开天功德所化，立于头顶先占不败）。
- 功德证道：三清（开天功德+立教）、女娲（造人功德）、接引准提（立西方教宏愿）皆以功德成圣（见[境界/斩三尸与证道]）。

### 大功德事件（天道功德降世）
| 事件 | 主体 | 功德去向 |
|---|---|---|
| 盘古开天 | 盘古 | 开天功德化为开天三宝（太极图/盘古幡/混沌钟）与玄黄玲珑塔 |
| 鸿钧合道 | 鸿钧 | 以身合道，天道运转 |
| 女娲造人+补天 | 女娲 | 造人功德成圣；补天功德 |
| 三清立教 | 老子/元始/通天 | 立教功德（引动开天功德）成圣 |
| 接引准提立西方教 | 二圣 | 立教宏愿功德成圣 |
| 后土化轮回 | 后土（平心） | 轮回功德（无圣位，化平心镇幽冥） |
| 大禹治水 | 大禹 | 治水功德（人皇之位/人道第一人） |
| 三族灭兽神神逆 | 龙/凤/麒麟 | 天道降功德：一成归四混沌魔神、三成归三族、六成修补洪荒地脉（黑信版本设定） |

### 功德运用
- 功德可造"功德法宝"（红绣球、山河社稷图等带功德属性）；
- 功德护体：立功德者不沾因果（女娲因此不参与量劫）；
- 伪功德：伪善欺世亦可"窃"功德（准提圣人常被设定为"钻天道空子"）

## 三、香火（信仰之力）

### 概念
- **香火**：众生信仰、祭祀所产生的愿力——神明/教主吸取香火增长法力、稳固神道。
- 香火神道：以香火信仰证道者（封神榜正神、民间俗神、城隍土地、关公妈祖等）——"神仙"（香火神）vs"仙真"（清修）之别（见[地仙谱]）。
- 香火双刃剑：受香火则受约束（欠众生因果、被香火愿力捆绑），故大能者多不轻易受祀（圣人无香火而超然）。

### 相关体系
- 封神榜=天庭以香火神道充实神位（365正神皆香火神，见[大事件/封神榜三百六十五位正神]）；
- 人神谱（关公/妈祖/岳飞）均为香火成神（[人神谱]）；
- 巫族不修香火、妖族不敬神——香火是"人道/神道"专属资源。

## 四、业力（因果反噬）

### 概念
- **业力**：过去行为所积累的力量（善业/恶业），产生相应后果——佛教"因果报应"（[佛教/因果与轮回]）。
- 洪荒流中业力=杀伐/逆天/害生累积的"负功德"：业力缠身则气运衰败、劫难临头、天罚加身。
- 量劫机制：众生业力积累到一定程度，天道降量劫清洗（"量劫=业力清算"）——见[量劫/量劫机制]。

### 业力典型案例
- 龙汉初劫：三族杀伐过重，业力缠身——祖龙/元凤/始麒麟或死或困（麒麟化身麒麟崖镇洪荒气运赎业力——后世麒麟为瑞兽之因）。
- 妖族天庭：帝俊杀伐+十日晒死生灵，业力招致巫妖大劫覆灭。
- 截教通天：万仙来朝却杀伐重，封神大劫中截教几乎覆灭（部分设定为业力所至）。
- 魔道罗睺：以杀证道、杀戮大道——业力之极（[人物/罗睺]）。

### 业力与因果
- 因果≠业力：因果是"天地间一切联系"（欠债还债），业力是"行为积累的力量"——大能者怕沾因果（欠人情债/天机因果），修士怕积业力（堕落魔道）。
- 化解业力：行善积德、补天救世、立教传道（功德对消业力）。

## 五、四者关系（洪荒运行逻辑）
```
天道（规则）→ 气运（格局）→ 量劫（洗牌）
      ↑                    ↓
  功德（奖励）↔ 业力（惩罚）  众生博弈（香火/因果）
```
- 天道以功德奖善、以业力惩恶、以量劫清算积累的因果业力——此为"天地不仁，以万物为刍狗"的洪荒版诠释。
- 圣人超然：不沾因果（功德护体）、不为气运所困（超脱）——故圣人之争多借"教派气运"间接进行（封神即以教派代理战争完成量劫）。
