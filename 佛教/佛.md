# 佛

佛教修行最高果位——"觉者"（佛陀）。以下综合百度百科、禅世界、中华网佛学资料。

## 一、三世佛
### 横三世佛（空间）
| 佛 | 世界 | 说明 |
|---|---|---|
| 释迦牟尼佛 | 中央娑婆世界 | 本师佛，现世教主，农历四月初八佛诞 |
| 阿弥陀佛 | 西方极乐世界 | 无量光/无量寿，接引往生，净土宗主尊 |
| 药师佛 | 东方净琉璃世界 | 消灾延寿，大医王佛 |

### 竖三世佛（时间）
| 佛 | 时代 | 说明 |
|---|---|---|
| 燃灯佛 | 过去庄严劫 | 释迦牟尼授记之师 |
| 释迦牟尼佛 | 现在贤劫 | 贤劫第四佛 |
| 弥勒佛 | 未来星宿劫 | 五十六亿七千万年后于娑婆成佛 |

## 二、三身佛
| 身 | 佛 | 说明 |
|---|---|---|
| 法身 | 毗卢遮那佛（大日如来） | 真理本身，无始无终 |
| 报身 | 卢舍那佛 | 证果之身，享佛国净土 |
| 应身（化身） | 释迦牟尼佛 | 度众生随缘应化 |

> 密宗视毗卢遮那（大日如来）为至高唯一法身佛；华严宗以毗卢遮那为报身佛；天台宗以之为法身佛。各宗解释不同。

## 三、五方佛（密宗）
| 方位 | 佛 | 象征 |
|---|---|---|
| 中央 | 毗卢遮那佛（大日如来） | 法界体性智 |
| 东方 | 阿閦佛（不动如来） | 大圆镜智 |
| 南方 | 宝生如来 | 平等性智 |
| 西方 | 阿弥陀佛 | 妙观察智 |
| 北方 | 不空成就佛 | 成所作智 |

## 四、过去七佛
毗婆尸佛、尸弃佛、毗舍浮佛、拘留孙佛、拘那含牟尼佛、迦叶佛、释迦牟尼佛。

## 五、其他重要佛
- **卢舍那佛**：报身佛，光明遍照
- **大日如来**：即毗卢遮那，密教主尊
- **不动如来（阿閦佛）**：东方妙喜世界
- **宝生如来 / 不空成就佛**：密教五方佛之二

> 洪荒流中"接引、准提"为西方二圣，是小说将佛教阿弥陀佛/准提菩萨改写为"圣人"的演绎，非佛教正统。
