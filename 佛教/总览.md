# 佛教体系总览

佛教完整神谱与组织体系——从佛、菩萨、罗汉到护法神将的完整等级，与洪荒流"西方教→佛教"设定对照。本目录专收"佛教体系"，来源以百度百科（神佛总谱）、禅世界佛学、中华网佛学、维基百科为准。

## 一、佛教神阶总览
```
佛（觉者·法界最高果位）
 ├─ 三世佛：横三世（释迦牟尼·阿弥陀佛·药师佛）/竖三世（燃灯古佛·释迦·弥勒）
 ├─ 三身佛：法身毗卢遮那·报身卢舍那·应身释迦
 ├─ 五方佛（密宗）：中央毗卢遮那·东方阿閦·南方宝生·西方阿弥陀·北方不空成就
 └─ 七佛（过去七佛）：毗婆尸…释迦
菩萨（求大觉者·上求佛道下化众生）
 ├─ 四大菩萨：文殊（智）·普贤（行）·观音（悲）·地藏（愿）
 ├─ 三圣组合：西方三圣（阿弥陀·观音·大势至）/华严三圣（毗卢遮那·文殊·普贤）/东方三圣（药师·日光·月光）
 └─ 其他：大势至·弥勒·准提·虚空藏·金刚手…
罗汉（解脱果位·声闻圣者）
 ├─ 十大弟子（舍利弗/目犍连/迦叶/阿难等）
 ├─ 十六罗汉（《法住记》）→十八罗汉（+降龙伏虎）
 └─ 五百罗汉（寺院罗汉堂）
护法
 ├─ 二十四诸天（大梵天/帝释天/四大天王/韦驮等）
 ├─ 四大天王（风调雨顺）
 ├─ 天龙八部（天/龙/夜叉/乾闼婆/阿修罗/迦楼罗/紧那罗/摩睺罗伽）
 ├─ 韦驮（护法安僧）、伽蓝（关公）
 └─ 金刚明王（五大明王/八大明王）
```

## 二、佛（见[佛教/佛]）
- **横三世佛**：释迦牟尼佛（娑婆教主）、阿弥陀佛（西方极乐教主）、药师佛（东方琉璃教主）；
- **竖三世佛**：燃灯古佛（过去佛，[人物/燃灯古佛]）、释迦牟尼（现在佛）、弥勒佛（未来佛）；
- **三身佛**：法身（毗卢遮那=真理之身）、报身（卢舍那=受用之身）、应身（释迦=应化之身）；
- **五方佛**（密宗）：五智如来——中央大日如来。共十四佛（或更多）。

## 三、菩萨（见[佛教/菩萨]）
- **四大菩萨道场**：五台山文殊、峨眉山普贤、普陀山观音、九华山地藏（[洞天福地/佛道名山道场]）；
- 中国特色菩萨："大慈大悲观音菩萨""大智文殊""大行普贤""大愿地藏"——四大菩萨精神象征；
- 封神→佛门对应：文殊广法天尊→文殊菩萨、普贤真人→普贤菩萨、慈航道人→观音菩萨（[人物/观世音菩萨]）。

## 四、罗汉（见[佛教/罗汉]）
阿罗汉=断尽烦恼、解脱生死的圣者——十六罗汉/十八罗汉/五百罗汉（"杀贼、应供、无生"三义）。

## 五、护法（见[佛教/护法]、[佛教/罗汉与天龙八部]）
二十四诸天、四大天王（风调雨顺）、天龙八部（八部众）、韦驮、伽蓝（关公）——佛门护法体系庞大。

## 六、佛教核心教义（见[佛教/因果与轮回]）
- **因果轮回**：六道（天道/阿修罗道/人道/畜生道/饿鬼道/地狱道）、十二因缘、业力轮回；
- **三法印**：诸行无常、诸法无我、涅槃寂静；
- **四圣谛**：苦、集、灭、道；
- 涅槃解脱（阿罗汉/菩萨/佛果）。

## 七、宗派与传播（见[佛教/宗派与道场]）
- 汉传八宗（禅/净/天台/华严/法相/三论/律/密）+藏传（红黄花白）+南传（上座部）；
- 四大名山道场、重要寺院（白马寺/少林/东林/大雁塔）。
