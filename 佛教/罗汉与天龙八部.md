# 罗汉与天龙八部（佛教护法体系）

佛教护法神体系详录——从罗汉到天龙八部，构成佛法护卫的完整谱系。来源：中华网佛学（上海玉佛禅寺）、维基百科（天龙八部）、佛教文献。

## 一、罗汉（阿罗汉）

### 概念
- 罗汉是梵语"阿罗汉"（Arhat）的简称，意为"杀贼（断烦恼）、应供（堪受人天供养）、无生（了脱生死）"——佛陀弟子修证的最高果位。
- 罗汉按修行程度分初果到四果，四果阿罗汉已断除所有烦恼、不再受生死轮回。

### 十六罗汉（《法住记》）
- 佛陀涅槃时嘱咐十六大阿罗汉：不入涅槃、常住世间护持正法，受世人供养作众生福田。
- 唐玄奘译《大阿罗汉难提密多罗所说法住记》（简称《法住记》，狮子国高僧难提密多罗著）记载十六罗汉名号与住处，此后罗汉信仰普遍。

### 十八罗汉（十六+二）
- **降龙罗汉**（庆友尊者）：降伏恶龙（济公传说为其转世，杭州灵隐寺供奉）。
- **伏虎罗汉**（宾头卢尊者/弥勒尊者两说）：伏虎（虎为侍者）。
- 另一版本：十六罗汉外另加达摩多罗尊者（达摩）与布袋和尚。

### 五百罗汉
- 佛陀在世时常随教化的大比丘众五百阿罗汉；或佛陀涅槃后结集经典的五百阿罗汉。
- 各地名寺罗汉堂（北京碧云寺、苏州西园、昆明筇竹寺五百罗汉塑像闻名）。
- 罗汉形象无经典仪轨依据，多为艺术家创作——剃发比丘、身着僧衣、姿态不拘（五代贯休十六罗汉图最为著名）。

## 二、天龙八部（八部众）

佛教护法神的八类神话种族，以"天众""龙众"为首故称"天龙八部"（梵语Aṣṭasenā"八个部众"）。金庸名作《天龙八部》即取名于此。来源：维基百科。

| 部众 | 梵语 | 特征 |
|---|---|---|
| **天众**（天人/提婆） | Deva | 天神——大梵天、大黑天、帝释天、四大天王、韦驮天等；帝释天为三十三天诸神领袖；天神临死有"天人五衰"（衣裳垢腻/头上花萎/身体臭秽/腋下出汗/不乐本位） |
| **龙众**（那伽） | Nāga | 神龙/蛇神，专管兴云降雨；无数龙王；娑竭罗龙（海龙）之女龙女八岁成佛；大鹏金翅鸟（迦楼罗）为其天敌 |
| **夜叉**（药叉） | Yakṣa | 捷疾勇健的鬼道众生；与罗刹由大梵天脚掌生出、相互敌对；对人类友善（"真诚者"） |
| **乾闼婆** | Gandharva | 香神/乐神，以香为食，飞天奏乐（敦煌飞天即此） |
| **阿修罗** | Asura | 好斗的非天，与帝释天争战不休（六道之一，见[人物/冥河老祖]） |
| **迦楼罗** | Garuda | 金翅大鹏鸟，以龙（那伽）为食，护法（见[人物/金翅大鹏雕]） |
| **紧那罗** | Kiṃnara | 歌神（人非人），似人而头上有角，善歌舞（"紧那罗王"即此） |
| **摩睺罗伽** | Mahoraga | 大蟒神，人身蛇首，乐神 |

- 天龙八部随侍佛、菩萨、阿罗汉到世界各地说法，护持修行人与寺院（华严圣众）。
- 八部众多属天道/鬼道/畜生道，福报享尽仍可能堕落三恶道，故亦须精进修行。

## 三、四大天王（护法之首）
- 见[人物/魔家四将]：东方持国天王（魔礼海/琵琶）、南方增长天王（魔礼青/宝剑）、西方广目天王（魔礼寿/花狐貂）、北方多闻天王（魔礼红/宝伞）——封神后镇守南天门，佛教中护持须弥山四洲。

## 四、二十诸天与二十四天
- **二十诸天**（佛教护法神）：大梵天、帝释天、四大天王、日天、月天、金刚密迹、摩醯首罗、散脂大将、韦驮天、坚牢地神、菩提树神、鬼子母、摩利支天、娑竭罗龙王、阎魔罗王、紧那罗王、紫微大帝、东岳大帝、雷神。
- 后加四天（道神/龙王/星宫/风天）成**二十四诸天**——佛道融合的护法体系。

## 五、韦驮天（护法伽蓝）
- 韦驮（韦陀天）：四大天王三十二将之首，持金刚杵，护法安僧——"天目山韦驮道场"；弥勒佛背后、面对大雄宝殿的护法神位。
- 韦驮杵式样有禅宗密义（横杵在臂=十方丛林，合掌托杵=小寺院等）。

## 六、伽蓝与金刚
- 伽蓝神（寺院守护）：关羽为"伽蓝菩萨"（佛道融合，见[人神谱]）；十八伽蓝神。
- 金刚力士：哼哈二将（郑伦陈奇封神后为金刚/密迹金刚）、八大金刚。
