# 宗派与道场

## 一、汉传佛教八宗（大乘）
| 宗派 | 创始人/祖庭 | 核心 |
|---|---|---|
| 禅宗 | 菩提达摩（初祖） | 直指人心、见性成佛，不立文字 |
| 净土宗 | 慧远/善导 | 念阿弥陀佛、往生极乐 |
| 天台宗 | 智顗（隋） | 法华经、一念三千 |
| 华严宗 | 法藏（唐） | 华严经、法界缘起 |
| 法相宗（唯识） | 玄奘 | 万法唯识 |
| 三论宗 | 吉藏 | 中观三论 |
| 律宗 | 道宣 | 戒律 |
| 密宗（唐密） | 善无畏/金刚智/不空 | 仪轨、真言、曼荼罗 |

## 二、藏传佛教
- 宁玛派（红教）、萨迦派（花教）、噶举派（白教）、格鲁派（黄教，达赖/班禅）
- 活佛转世体系

## 三、南传佛教（上座部）
- 流行东南亚、云南傣族地区
- 修习巴利三藏，重个人解脱（阿罗汉道）

## 四、四大名山（菩萨道场）
- **五台山**（山西）— 文殊菩萨
- **峨眉山**（四川）— 普贤菩萨
- **普陀山**（浙江）— 观音菩萨
- **九华山**（安徽）— 地藏菩萨

## 五、重要寺院
- 洛阳白马寺（汉传第一寺）
- 西安大雁塔（玄奘译经）
- 嵩山少林寺（禅宗祖庭）
- 庐山东林寺（净土祖庭）
