# 宗派与道场（佛教中国化）

汉传佛教宗派体系与道场名山——佛教传入中土两千年间完成"信仰、思想、制度"三层面本土化，形成八大宗派与四大名山道场。来源：维基百科、新华网（四大名山形成考）、佛教常识。

## 一、汉传佛教八大宗派（大乘）
| 宗派 | 创始人/祖庭 | 核心教义 |
|---|---|---|
| **禅宗** | 菩提达摩（初祖）/嵩山少林寺 | 直指人心、见性成佛，不立文字；六祖慧能（曹溪南华寺）顿悟法门 |
| **净土宗** | 慧远（东林寺）/善导 | 念阿弥陀佛、往生极乐（"净土三经"）——"家家阿弥陀，户户观世音" |
| **天台宗** | 智顗（隋，天台山国清寺） | 《法华经》、一念三千、三谛圆融 |
| **华严宗** | 法藏（唐，陕西华严寺） | 《华严经》、法界缘起、理事无碍 |
| **法相宗（唯识宗）** | 玄奘/窥基（大慈恩寺） | 万法唯识、三性三无性（"唐僧"玄奘回国译经） |
| **三论宗** | 吉藏（嘉祥寺） | 中观"三论"（中论/百论/十二门论） |
| **律宗** | 道宣（终南山净业寺） | 戒律持守（南山律） |
| **密宗（唐密）** | 善无畏/金刚智/不空（开元三大士） | 仪轨、真言、曼荼罗；后传日本（东密/台密） |

## 二、藏传佛教
- 四大教派：宁玛派（红教）、萨迦派（花教）、噶举派（白教）、格鲁派（黄教——达赖/班禅转世体系）；
- 特色：活佛转世（祖古）、密宗仪轨、坛城曼荼罗、六字真言；
- 与汉传并立：五台山汉藏寺院汇聚（建筑最雄伟密集，四大佛山之首）。

## 三、南传佛教（上座部）
- 流行东南亚、云南傣族地区；
- 修习巴利三藏，重个人解脱（阿罗汉道）。

## 四、四大名山道场（菩萨道场）
| 名山 | 位置 | 菩萨 | 特点 |
|---|---|---|---|
| **五台山** | 山西 | 文殊菩萨 | 清凉山；北魏起传华严，唐代文殊信仰鼎盛，明万历三百余寺；汉藏汇聚，佛像最精美 |
| **峨眉山** | 四川 | 普贤菩萨 | 金顶"佛光"（普贤祥瑞）；明鼎盛170余寺、僧三千 |
| **普陀山** | 浙江 | 观音菩萨 | 梅岑山"不肯去观音院"；补怛洛迦应化地；观音信仰"半个亚洲" |
| **九华山** | 安徽 | 地藏菩萨 | 新罗王子金地藏驻锡（袈裟覆山、骨节如锁）；"九华一千寺"，香火最旺 |

- 四山对应佛家"四大"：九华=地、普陀=水、峨眉=火、五台=风（《普陀山志》）；
- "五大名山"候选：雪窦山/梵净山（弥勒）、狼山（大势至）、鸡足山（迦叶）；
- 详见[洞天福地/佛道名山道场]。

## 五、重要寺院
- **洛阳白马寺**：汉传佛教第一寺（东汉明帝求法，白马驮经——"白马驮经"典故）；
- **西安大雁塔**（大慈恩寺）：玄奘译经场（法相宗祖庭）；
- **嵩山少林寺**：禅宗祖庭（达摩面壁九年，"少林武功"）；
- **庐山东林寺**：净土宗祖庭（慧远，虎溪三笑）；
- 其他：五台山显通寺/塔院寺、峨眉报国寺、普陀普济寺、九华化城寺、天台国清寺、南京栖霞寺（三论）、终南山净业寺（律宗）、法门寺（佛指舍利）。

## 六、佛教中国化
- 唐宋之际完成信仰（菩萨应化）、思想（宗派消化）、制度（丛林清规）三层面本土化（清华圣凯）；
- 佛教与道教/民间信仰融合：文殊普贤观音地藏"四大菩萨应化"、关羽成"伽蓝菩萨"（佛道融合见[人神谱]）、四大天王"风调雨顺"民间化；
- "四大名山"之说约明万历出现、清康熙成共识——标志着以中国为世界佛教中心之格局。
