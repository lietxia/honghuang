# 十二金仙法宝

阐教玉虚宫十二金仙，各有本命灵宝（多后天灵宝/极品先天）。

| 金仙 | 本命法宝 |
|---|---|
| **广成子** | 番天印（半截不周山）、八卦仙衣、扫霞衣、雌雄剑 |
| **赤精子** | 阴阳镜（照生照死）、紫绶仙衣、水火锋 |
| **黄龙真人** | 剑（无显著本命，战力偏弱） |
| **惧留孙** | 困仙绳、指地成钢符 |
| **太乙真人** | 九龙神火罩、乾坤圈（哪吒用）、火尖枪、金砖、阴阳剑、莲花化身术 |
| **灵宝大法师** | 龙虎印、降妖剑（多宝天尊同门） |
| **文殊广法天尊** | 遁龙桩（七宝金莲）、捆妖绳、七星剑（后化文殊） |
| **普贤真人** | 长虹索、吴钩（后化普贤菩萨） |
| **慈航道人** | 清净琉璃瓶、玉净瓶杨柳、缚妖索（后化观音） |
| **玉鼎真人** | 斩仙剑、陷仙剑（借）、八九玄功（传杨戬） |
| **道行天尊** | 降魔杵、松枝木剑、宝斗 |
| **清虚道德真君** | 五火七禽扇、莫邪宝剑、攒心钉、飞电枪 |

## 其他玉虚门下
- **云中子**：巨阙剑、通天神火柱、紫金钵盂、照妖鉴（终南山） 
- **南极仙翁**：五火七禽扇（部分说）、仙鹤、寿桃
- **姜子牙**：打神鞭、封神榜、四不相、杏黄旗
- **申公豹**：开天珠、飞头术
