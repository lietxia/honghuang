# 十二金仙法宝（玉虚宫灵宝谱）

阐教玉虚宫十二金仙各有本命灵宝（多为后天灵宝/极品先天），加之姜子牙、云中子、南极仙翁等玉虚门下法宝——构成封神阐教法宝体系。详录见[法宝/后天灵宝详录]、[法宝/兵器谱]。

## 十二金仙本命法宝
| 金仙 | 本命法宝 | 说明 |
|---|---|---|
| **广成子** | 番天印、八卦仙衣、扫霞衣、雌雄剑 | 番天印=半截不周山所炼（先天灵宝）——砸人无解（[人物/广成子]） |
| **赤精子** | 阴阳镜、紫绶仙衣、水火锋 | 阴阳镜照生照死（[人物/赤精子与清虚道德真君]） |
| **黄龙真人** | 剑 | 战力偏弱、无显著本命（"四无道人"调侃） |
| **惧留孙** | 捆仙绳、指地成钢符 | 捆仙绳擒土行孙/赵江；指地成钢克地行术 |
| **太乙真人** | 九龙神火罩、乾坤圈、火尖枪、金砖、阴阳剑 | 大部分传哪吒（[人物/太乙真人]、[人物/哪吒]） |
| **灵宝大法师** | 龙虎印、降妖剑 | 玉虚十二金仙之一 |
| **文殊广法天尊** | 遁龙桩（七宝金莲）、捆妖绳、七星剑 | 遁龙桩擒王魔/杨森；后为文殊菩萨（[佛教/菩萨]） |
| **普贤真人** | 长虹索、吴钩 | 后为普贤菩萨（坐骑灵牙仙=白象） |
| **慈航道人** | 清净琉璃瓶、玉净瓶杨柳、缚妖索 | 后为观音菩萨（坐骑金光仙=金毛犼） |
| **玉鼎真人** | 斩仙剑、陷仙剑（借）、八九玄功 | 八九玄功传杨戬（[人物/杨戬]） |
| **道行天尊** | 降魔杵、松枝木剑、宝斗 | 降魔杵传韦护（肉身成圣） |
| **清虚道德真君** | 五火七禽扇、莫邪宝剑、攒心钉、飞电枪 | 五火扇搧死王奕（红水阵）；攒心钉传黄天化、飞电枪传杨任 |

## 十二金仙法宝特点
1. **本命传承制**：金仙法宝多传弟子（太乙→哪吒、道德真君→黄天化/杨任、道行天尊→韦护）——封神"三代弟子"战力来源（[人物/黄天化]等）；
2. **借用法宝**：金仙可向师尊借宝（赤精子借太极图化殷洪）——"法宝在师尊处"；
3. **转佛门**：文殊/普贤/慈航三金仙转佛门后法宝随之（遁龙桩/长虹索/琉璃瓶成佛门法器）——"封神→西游"法宝谱系桥梁（[教派/西方教与佛教]）。
