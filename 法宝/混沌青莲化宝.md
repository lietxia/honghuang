# 混沌青莲化宝（创世青莲·三十六品）

洪荒流开天设定中的核心至宝——**混沌青莲（创世青莲）**：混沌时期孕育的第一株青莲——盘古开天时破碎——其碎片化为洪荒无数顶级先天灵宝（"青莲化宝"——洪荒法宝体系的源头）。三十六品青莲=混沌至宝之首（与盘古斧、造化玉碟并列为混沌三大至宝——[法宝/至宝体系]）。来源：洪荒流设定（《佛本是道》体系）、百度百科。

## 一、混沌青莲本相
- **混沌青莲**（创世青莲/三十六品青莲）——混沌未开时的第一株神物——孕育于混沌深处（与[创始元灵/创始元灵与四大弟子]同期——"混沌三宝"之一）；
- **三十六品**：品级至极（先天灵宝以品计——十二品金莲已是顶级——三十六品=混沌级（[法宝/十大先天灵宝榜]十二品功德金莲对照——十二品降九品的品级体系）；
- 盘古开天时青莲受损破碎——"开天辟地，青莲化宝"——碎片化为洪荒灵宝源头（"化宝"=分解为无数法宝）。

## 二、青莲化宝（碎片去向）
| 碎片 | 化宝 |
|---|---|
| **莲叶** | 五片莲叶化为**五行旗**（中央戊己杏黄旗/东方青莲宝色旗/南方离地焰光旗/西方素色云界旗/北方玄元控水旗——[法宝/十大先天灵宝榜]五行旗——先天五行大阵） |
| **莲瓣** | 十二片莲瓣化为十二件**先天灵宝**（部分设定：莲瓣化山河社稷图/河图洛书等） |
| **莲蓬** | 莲蓬化**乾坤鼎**（炼化万物——[法宝/十大先天灵宝榜]乾坤鼎） |
| **莲子** | 莲子化成**十二品功德金莲**（接引）、**十二品业火红莲**（冥河）等（[法宝/十大先天灵宝榜]） |
| **莲茎** | 莲茎化**弑神枪**（魔祖罗睺/元始天王的凶兵——[法宝/兵器谱]） |
| **莲藕** | 藕段化**玲珑宝塔**（[法宝/后天灵宝详录]）等 |
| **根须** | 根须化**六根清净竹**（准提——[法宝/十大先天灵宝榜]）等 |

> 各作品细节不同——但"青莲碎片→顶级灵宝"的总设定一致（洪荒法宝的"创世层"源头）。

## 三、与三大至宝的关系
| 至宝 | 说明 |
|---|---|
| **创世青莲** | 混沌第一株神物（孕万物——[法宝/至宝体系]混沌三宝之一——后破碎化宝） |
| **盘古斧（开天神斧）** | 盘古开天斧——劈开混沌（后化太极图/盘古幡/混沌钟——开天三宝——[法宝/至宝体系]） |

混沌三宝各有归宿：青莲化万宝（灵宝源）、盘古斧化三宝（开天三件）、玉碟归鸿钧（合道之基）——共同构成洪荒"顶级法宝的全部源头"（[法宝/总览]法宝谱系）。

## 四、意义
- **法宝谱系之根**：混沌青莲=所有先天灵宝的"总源头"——洪荒法宝体系的创世层（[法宝/总览]"从混沌三宝到先天灵宝到后天灵宝"三级谱系）；
- **品级标杆**：三十六品=混沌级（青莲）>十二品（金莲/红莲——先天顶级）>九品（[法宝/十大先天灵宝榜]品级体系）；
- **佛教关联**：十二品功德金莲（接引）即青莲莲子所化——"佛门至宝的洪荒源头"（[教派/西方教与佛教]——佛本是道的法宝层体现）；
- 洪荒流设定常以青莲化宝解释"为何先天灵宝那么多"——"创世遗产"的叙事功能。
