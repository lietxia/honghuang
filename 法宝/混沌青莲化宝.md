# 混沌青莲化宝

盘古诞生于混沌青莲（三十六品），开天后青莲因承载盘古而破碎，分解为洪荒诸多至宝。

## 青莲结构 → 所化之宝
| 青莲部位 | 所化法宝 | 最终持有 |
|---|---|---|
| 莲子（十二品） | 十二品净世青莲 | 分裂为多件（部分说归女娲/西方） |
| 莲花 | 十二品业火红莲 | 冥河 |
| 莲花 | 十二品功德金莲 | 接引 |
| 莲花 | 十二品灭世黑莲 | 罗睺（后碎） |
| 莲叶 | 先天五行旗（五方旗） | 分属多圣 |
| 莲茎 | 弑神枪（部分说） | 罗睺 |
| 莲蓬 | 乾坤鼎（部分说） | 女娲 |
| 根须 | 混沌珠（部分说） | 混沌老祖 |

## 主流说法：净世青莲三分化
- **十二品业火红莲** → 冥河（血海防御）
- **十二品功德金莲** → 接引（极乐防御）
- **十二品灭世黑莲** → 罗睺（魔道防御，后碎为蚊道人血莲等）

> 青莲化宝是洪荒"一件混沌至宝分裂为诸宝"的经典母题，解释了为何多件至宝同源。
