# 至宝体系

## 品级排名
```
混沌至宝（开天遗泽、造化玉碟、混沌青莲）
  > 先天至宝（开天三宝：太极图 / 盘古幡 / 混沌钟）
  > 先天灵宝 / 先天极品灵宝
  > 功德至宝（后天功德所成，威能等同先天灵宝）
  > 后天至宝
  > 后天灵宝
  > 凡品法宝
```

## 混沌至宝（开天前即有）
| 宝物 | 由来 | 持有 |
|---|---|---|
| 盘古斧 | 盘古伴生，开天之力 | 盘古（后解体） |
| 造化玉碟 | 载大道三千法则总纲 | 鸿钧老祖 |
| 混沌青莲 | 盘古所出，孕育万物 | 解体化宝（见[混沌青莲化宝](混沌青莲化宝.md)） |
| 混沌珠 | 混沌老祖伴生，控混沌 | 混沌老祖 |
| 分宝岩 | 紫霄宫天道无上异宝，分赐诸圣 | 鸿钧 |

## 先天至宝（开天神斧解体·开天三宝）
开天斧解体为三：
| 宝物 | 所化部位 | 持有 | 特性 |
|---|---|---|---|
| **太极图** | 斧背 | 太上老君 | 平定地水火风、转化阴阳、金桥护身，防御控制第一 |
| **盘古幡** | 斧刃 | 元始天尊 | 撕裂鸿蒙、破碎时空、攻伐第一 |
| **混沌钟（东皇钟）** | 斧柄 | 东皇太一 | 镇压时空、颠倒阴阳、攻防一体，万法不侵 |

> 三件皆承载开天功德，蕴含大道法则，位格最高，象征"开辟、定型、镇守"。

## 诛仙四剑（主杀伐）
罗睺伴生，后归通天教主：诛仙、戮仙、陷仙、绝仙 + 诛仙阵图。非四圣不破，攻伐之利冠绝洪荒（见[先天至宝与先天灵宝](先天至宝与先天灵宝.md)）。

## 功德至宝（后天成就）
- **天地玄黄玲珑塔**：老子所有，后天第一功德至宝，防御无双（与太极图并称"不败双壁"）
- 此类需注入大功德于后天灵宝而成，威能等同先天灵宝。
