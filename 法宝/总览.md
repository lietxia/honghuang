# 法宝总览

洪荒法宝品级体系与分类索引。洪荒流设定中，法宝是战力核心，"圣人之下皆蝼蚁，但法宝有高低"。

## 品级（由高到低）
```
混沌至宝（开天遗泽）
  > 先天至宝（开天三宝：太极图/盘古幡/混沌钟）
  > 先天灵宝 / 先天极品灵宝
  > 功德至宝（后天功德所成，同级先天）
  > 后天至宝
  > 后天灵宝
  > 凡品法宝
```
