# 法宝总览

洪荒法宝品级体系与分类索引。洪荒流设定中，法宝是战力核心，所谓"圣人之下皆蝼蚁，但法宝有高低"——一件先天至宝，往往能决定一场量劫的胜负走向。本页给出品级总纲与分类目录，各专页详录具体法宝。

## 品级（由高到低）

```
混沌至宝（开天遗泽）
  > 先天至宝（开天三宝：太极图/盘古幡/混沌钟）
  > 先天灵宝 / 先天极品灵宝
  > 功德至宝（后天功德所成，同级先天）
  > 后天至宝
  > 后天灵宝
  > 凡品法宝
```

法宝之分，首重"先天"与"后天"。先天法宝生于开天之际或灵脉孕育，自带大道法则、与天地同寿；后天法宝由修士祭炼或功德成就，威能视祭炼者修为而定。品级越高，威能越近乎规则级——混沌至宝可重演混沌，先天至宝能定地水火风，诛仙四剑非四圣不破，功德至宝则随主人功德增减。

## 法宝分类简述

- **攻击类**：诛仙四剑、盘古幡、混沌钟、番天印、斩仙飞刀、金蛟剪、弑神枪
- **防御类**：太极图、天地玄黄玲珑塔、十二品莲台、戊己杏黄旗
- **空间类**：山河社稷图、六魂幡、七宝妙树
- **辅助类**：河图洛书（演算推演）、乾坤鼎（炼化）、招妖幡（统御群妖）
- **灵根类**：人参果、蟠桃、黄中李，以及混沌青莲化生的诸般灵根

法宝体系之繁复，堪称洪荒一大特色。自开天三宝、混沌青莲，到封神众仙的随身灵宝，层层嵌套、各有克制，是洪荒战斗与气运之争的物质基础。一件至宝的归属，往往牵动整个量劫的胜负与势力此消彼长。
