# 兵器谱

洪荒世界的神兵利器（非法宝类，以兵刃为主）。兵刃与法宝的分界：法宝重"神通"，兵刃重"攻伐"。

## 顶级神兵（圣人级）
| 兵器 | 持有者 | 能力 |
|---|---|---|
| **青萍剑** | 通天教主 | 截教教主佩剑，先天灵宝级神剑，被准提七宝妙树所刷（交战时折断/受创） |
| **诛仙四剑** | 通天教主 | 诛仙/戮仙/陷仙/绝仙四剑，非四圣不可破（阵法核心，属法宝亦属神兵） |
| **轩辕剑** | 轩辕黄帝 | 轩辕剑（圣道之剑），斩蚩尤，人皇之剑，后世镇国之剑 |
| **射日弓（彤弓）** | 后羿 | 一箭射日，弓道极致 |
| **三尖两刃刀** | 杨戬 | 重达数万斤，二郎神主兵器，与悟空金箍棒对砍不分胜负 |
| **如意金箍棒** | 孙悟空 | 定海神针铁，重一万三千五百斤，可大可小，如意变化 |

## 兵器文化
- **"兵器随人"**：神兵认主，如金箍棒只认悟空（定海神针）。
- **重兵崇拜**：洪荒流中"大力出奇迹"——金箍棒一万三千五百斤、三尖两刃刀数万斤，重兵=身份的象征。
- 兵器可升级为法宝（剑→飞剑，棍→棍法大道），"剑之大道""枪之大道"皆自兵器入道。
