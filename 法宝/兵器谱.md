# 兵器谱（神兵总表）

洪荒世界的神兵利器（非法宝类、以兵刃为主）。兵刃与法宝的分界：法宝重"神通"、兵刃重"攻伐"——但顶级神兵往往兼具法宝属性（诛仙四剑/金箍棒皆如此）。神兵文化：重兵崇拜（"大力出奇迹"）+兵器认主（"兵器随人"）+以兵入道（剑道/枪道）。来源：封神/西游原著、洪荒流设定。

## 四、兵器文化
| 主题 | 说明 |
|---|---|
| **"兵器随人"** | 神兵认主——如金箍棒只认悟空（定海神针——"如意"认主——[人物/孙悟空]） |
| **重兵崇拜** | 洪荒流"大力出奇迹"——金箍棒一万三千五百斤、三尖两刃刀数万斤——重兵=身份象征（力量美学） |
| **以兵入道** | 兵器可升级为法宝（剑→飞剑、棍→棍法大道）——"剑之大道""枪之大道"皆自兵器入道（[功法/道门与佛门]通天剑道） |
| **兵器vs法宝** | 兵器重攻伐（物理）、法宝重神通（法则）——顶级神兵两者兼具（诛仙四剑=剑+阵） |
