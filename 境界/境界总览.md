# 境界总览

洪荒流境界划分各书略有差异，以下为最主流的"凡—仙—圣—道"四境框架（综合《佛本是道》《重生混元道》及修真通用体系）。

## 凡境（未脱轮回）
| 境界 | 说明 |
|---|---|
| 凡人 | 无修为，寿元百年 |
| 炼精化气 | 引灵气入体 |
| 炼气化神 | 灵力养神 |
| 炼神返虚 | 元神初成 |
| 炼虚合道 | 触及道则边缘 |

> 部分作品细分：炼气→筑基→金丹→元婴→化神→渡劫（合道）→地仙。

## 仙境（长生不朽）
| 境界 | 说明 |
|---|---|
| 地仙 | 镇地脉，不入仙班（如镇元大仙） |
| 天仙 | 列仙班，受天道册封 |
| 金仙 | 凝不灭金仙道体，不堕轮回 |
| 太乙金仙 | 悟太乙大道，顶上三花、胸中五气 |
| **大罗金仙** | 超脱时间线，过去未来皆不朽（老牌强者主流） |

## 圣境（混元）
| 境界 | 别称 | 说明 |
|---|---|---|
| 准圣 | 混元金仙 | 斩三尸未圆满，距圣人一步之遥（如孔宣、赵公明、三霄） |
| **圣人** | **混元大罗金仙** | 立教/功德/以力证道，不死不灭，掌天道法则 |
| 混元太极金仙 | 至圣 | 圣人圆满 |

## 道境（超脱）
| 境界 | 说明 |
|---|---|
| 混沌无极金仙 | 合道级 |
| 混沌天尊 | 天道级，执掌天道权柄 |
| 混沌至尊 / 大道级 | 生于鸿蒙，世界观战力天花板（盘古曾逼近） |

## 斩尸对应
- 斩一尸 → 准圣初期；斩二尸 → 准圣中期；斩三尸 → 准圣后期 → 准圣巅峰
- 准圣之上成圣，三法见[境界/斩三尸与证道](境界/斩三尸与证道.md)
