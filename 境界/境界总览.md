# 境界总览

洪荒流境界划分各书略有差异，以下为最主流的"凡—仙—圣—道"四境框架（综合《佛本是道》《重生混元道》及修真通用体系）。完整链条+各作品差异见[境界/境界详解]。

## 一、凡境（未脱轮回）
| 境界 | 说明 |
|---|---|
| 凡人 | 无修为，寿元百年 |
| 炼精化气 | 引灵气入体（筑基） |
| 炼气化神 | 灵力养神 |
| 炼神返虚 | 元神初成 |
| 炼虚合道 | 触及道则边缘 |

> 细分版（主流修真）：炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫（渡劫成仙）——寿元递增（炼气100岁→金丹500岁→元婴千年→化神2千年→渡劫飞升）。详见[境界/境界详解]。

## 二、仙境（长生不朽）
| 境界 | 说明 |
|---|---|
| **地仙** | 镇地脉、不入仙班（如镇元大仙——"地仙之祖"） |
| **天仙** | 列仙班、受天道册封 |
| **真仙/玄仙** | 部分体系增设（飞天入地、法则皮毛） |
| **金仙** | 凝不灭金仙道体、不堕轮回（"金者不朽"） |
| **太乙金仙** | 悟太乙道果——顶上三花、胸中五气（封神十二金仙此级） |
| **大罗金仙** | 大罗道果——超脱时间长河、过去未来皆不朽（老牌强者主流，如杨戬级） |

## 三、圣境（混元）
| 境界 | 别称 | 说明 |
|---|---|---|
| **准圣** | 混元金仙 | 斩三尸未圆满，距圣人一步之遥（孔宣/赵公明/三霄/冥河） |
| **圣人** | **混元大罗金仙** | 立教/功德/以力证道——不死不灭、掌天道法则（六圣） |
| 混元太极金仙 | 至圣 | 圣人圆满 |

## 四、道境（超脱）
| 境界 | 说明 |
|---|---|
| 混沌无极金仙 | 合道级（鸿钧合道后——"鸿钧即天道"） |
| 混沌天尊 | 天道级、执掌天道权柄 |
| 混沌至尊/大道级 | 生于鸿蒙，世界观战力天花板（盘古曾逼近——半步大道） |

## 五、斩尸对应
- 斩一尸→准圣初期；斩二尸→准圣中期；斩三尸→准圣后期→准圣巅峰；
- 准圣之上成圣三法（以力/斩三尸/功德）见[境界/斩三尸与证道]。

## 六、境界要点
1. **境界决定寿命与权能**：凡境百年→仙境长生→圣境不灭→道境合天；
2. **各境界标志**：金丹（丹火）、元婴（婴火）、化神（元神出窍）、金仙（道体不灭）、太乙（三花五气）、大罗（超脱时间）、准圣（斩尸）、圣人（法则）；
3. **强行提升**：圣人可提人至大罗金仙（再难寸进）、鸿钧可提至准圣（玉帝/王母）——"强行提境损根基"（[境界/斩尸与证道]）；
4. **洪荒流差异**：各书境界名目不同（腾讯动漫版有太乙真仙/太乙玄仙细分、凡人流有炼气13层）——详见[境界/境界详解]。
