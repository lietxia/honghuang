# 境界详解（修炼体系全表）

洪荒流修炼境界的详细划分。网络小说修仙境界体系源于萧潜《飘渺之旅》等早期修仙文，"洪荒流"由梦入神机《佛本是道》确立大罗金仙、准圣、圣人、无量量劫、鸿钧道祖等核心概念，境界名多参考《道德经》《钟吕传道集》《悟真篇》《抱朴子》《参同契》《黄庭经》等道经内丹法。来源：CSDN（鸿蒙炼体/洪荒等级）、知乎、腾讯动漫、新浪、巴哈姆特。

## 一、通用完整链条（主线）
```
炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫
→ 地仙→天仙→真仙→玄仙→金仙→太乙金仙→大罗金仙
→ 准圣→混元大罗金仙（圣人）→天道→大道
```

| 阶段 | 境界 | 特征 |
|---|---|---|
| 凡境 | 炼气（9/10/12/13层） | 引灵气入体，用低阶法术符箓；寿约100-130岁 |
| 凡境 | 筑基 | 真元液化，仙凡分界（"一入筑基，仙凡永别"）；寿约200岁 |
| 凡境 | 金丹（结丹） | 丹田凝金丹，"一粒金丹吞入腹，我命由我不由天"；有丹火；寿约500岁 |
| 凡境 | 元婴 | 丹碎成婴，元婴可离体、可夺舍；有婴火；寿约1000-1200岁 |
| 凡境 | 化神 | 元婴与魂魄融合、灵魂升为元神，可元神出窍；寿约2000岁 |
| 凡境 | 炼虚 | 化神飞升后起点，悟法则皮毛；寿3000-5000岁 |
| 凡境 | 合体 | 元神与肉身深度融合，肉身堪比法宝；寿1-2万岁 |
| 凡境 | 大乘 | 灵界巅峰，渡五行劫/真雷劫/心魔劫；寿约5万岁 |
| 凡境 | 渡劫（合道期） | 渡雷劫成地仙；雷+风+火三劫齐渡可直接天仙（极险，几乎无人） |
| 仙境 | 地仙 | 渡劫成功；镇地脉（镇元大仙类） |
| 仙境 | 天仙 | 列仙班，受天道册封 |
| 仙境 | 真仙 | 飞升仙界起点，灵力转仙灵力 |
| 仙境 | 玄仙 | 高于天仙（部分体系置于金仙之下，有争议） |
| 仙境 | 金仙 | **金者不朽**——凝不灭金仙道体，不堕轮回 |
| 仙境 | 太乙金仙 | 悟太乙道果，顶上三花、胸中五气 |
| 仙境 | 大罗金仙 | 大罗道果，超脱时间长河、法则圆满，寿元无尽 |
| 圣境 | 准圣 | 大罗金仙修斩三尸：斩一尸=初期、斩二尸=中期、斩三尸=后期→巅峰 |
| 圣境 | 混元大罗金仙（圣人） | 以力/斩三尸/功德证道，不死不灭，掌天道法则 |
| 道境 | 天道级（混元太极） | 执掌天道权柄（鸿钧合道后为半步天道，鸿钧即天道、天道却不是鸿钧） |
| 道境 | 大道级（混元无极→混元虚无→鸿蒙造化→鸿蒙超脱） | 生于鸿蒙，世界观战力天花板（盘古为半步大道级，开天成功则与大道平起平坐，惜失败） |

## 二、各作品细分差异
| 体系 | 链条 |
|---|---|
| 主流洪荒流 | 炼气→筑基→金丹→元婴→化神→渡劫→地仙→天仙→金仙→太乙金仙→大罗金仙→准圣→圣人→天道→大道 |
| 腾讯动漫版 | 练气→筑基→金丹→元婴→化神→炼虚→大乘→地仙→天仙→真仙→玄仙→金仙→太乙真仙→太乙玄仙→太乙金仙→大罗真仙→大罗玄仙→大罗金仙→仙帝→仙尊→准圣→圣人 |
| 凡人流 | 人界：炼气(13层)→筑基→金丹→元婴→化神；灵界：炼虚→合体→大乘→渡劫；仙界：人仙→地仙→天仙→真仙→玄仙→金仙→太乙→大罗→道祖 |

## 三、武道（人族武道）
后天→先天→宗师→大宗师→武道金丹→丹碎成婴→武道元神
- 后天/先天≈炼气，宗师/大宗师≈筑基，武道金丹/婴/元神≈金丹/元婴/化神。
- **以武入道之元神无法合道、无法渡劫成仙**——武道巅峰即止步（与仙道本质不同）。

## 四、修炼流派
| 流派 | 特点 |
|---|---|
| 法修 | 主流，炼气凝神、法术多样 |
| 体修 | 不修天道修己身，肉身成圣（巫族九转玄功相近） |
| 剑修 | 法修分支，一剑破万法，攻击力极强 |
| 魔修 | 进度快、易生心魔 |
| 妖修 | 妖兽化形，凭天赋神通与真灵之血（妖族天劫晋升） |
| 香火神道 | 以信仰/功德成神（地仙谱"神仙"之别） |
| 鬼修 | 鬼魂修炼 |

## 五、说明
- "炼精化气→炼气化神→炼神返虚→炼虚合道"四阶段为传统丹道框架（见[丹道与内丹]），小说境界在此基础上细分。
- 每个境界大体分初期/中期/后期/巅峰。
- 真正的道教神话与民俗志怪并无此等级划分——皆为网络小说二创体系，参考时不必过于较真。
