# 经典书目与流派沿革（神话源流·洪荒流发展）

中国神话与洪荒流小说的典籍源流——从上古神话元典到洪荒流开山之作的完整脉络。理解"洪荒流"必须知道它从哪些典籍取材（本源典籍）、以哪些小说为蓝本（神魔小说）、由哪部书开创（开山之作）。来源：中国文学史、网络文学研究、梦入神机作品考。

- **《封神演义》（明·许仲琳）**：封神大战、三百六十五位正神、三教之争（阐截人）——**洪荒流的直接蓝本**（[大事件/封神之战始末]）；
- **《西游记》（明·吴承恩）**：大闹天宫、西天取经、佛道神魔——**洪荒流西游量劫蓝本**（[人物/西游记妖怪全录]）；
- **《四游记》**（东/南/北/西游）：八仙/华光/真武体系补充（[参考/四游记与神魔小说]）；

## 三、洪荒流开山与发展
| 阶段 | 作品 | 贡献 |
|---|---|---|
| **开山（2006）** | 梦入神机**《佛本是道》** | 首创"洪荒流"框架：盘古开天、鸿钧合道、圣人体系、量劫设定、佛本是道（"洪荒流鼻祖"） |
| 发展 | 血红《神魔》《巫颂》等 | 巫族设定丰富（十二祖巫/都天神煞完善） |
| 巅峰期 | 《重生混元道》《混元无极》《洪荒之玄龟不周山》等 | 完善境界、法宝、量劫分级（境界体系定型——[境界/境界详解]） |
| 经典续作 | 《莽荒纪》（我吃西红柿） | 混沌宇宙观、道之体系（严格说不算纯洪荒流但深受影响） |
| 现代 | 大量起点/番茄洪荒文 | 三千大道、混沌魔神、圣人博弈等设定已成共识 |

## 四、洪荒流核心设定共识
1. 盘古开天+三千魔神（[大事件/盘古开天与三千魔神之战]）；
2. 鸿钧合道、紫霄宫讲道、圣位（[大事件/鸿钧紫霄宫讲道]）；
3. 圣人之下皆蝼蚁、圣人永不灭（[境界/境界详解]）；
4. 四大量劫：龙汉、巫妖、封神、西游（[量劫/总览]）；
5. 先天三族退场、巫妖争霸、人族崛起（[势力/势力总览]）；
6. 佛本是道（西方教=佛教前身——[教派/西方教与佛教]）；
7. 封神榜365正神=天庭官僚化（[大事件/封神榜三百六十五位正神]）。
