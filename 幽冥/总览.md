# 幽冥总览（幽冥血海·六道轮回·地府阴司）

幽冥是洪荒世界死后的归处——与天界（生）、人间（住）并立为三界之一。洪荒流设定中幽冥并非单一机构，而是三大体系交织：**幽冥血海**（最古老源头）、**六道轮回**（后土化生）、**地府阴司**（管理中枢）。三者各有源头、各有主宰，却又彼此勾连——共同维系"死后有归处、轮回有秩序"的大道闭环。本总览为索引，详述见各专篇。来源：洪荒流设定、《山海经》、道教冥府信仰（[道教神佛/冥府]）。

## 一、三大体系
| 体系 | 主宰 | 说明 |
|---|---|---|
| **幽冥血海** | 冥河老祖 | 盘古开天时的污血所化（肚脐血）——孕育冥河老祖与阿修罗一族——幽冥最古老、最凶戾的源头——"血海不枯冥河不死"（[人物/冥河老祖]、[幽冥/血海冥河]） |
| **六道轮回** | 后土（平心娘娘） | 巫妖大战后祖巫后土不忍亡魂漂泊——于血海之畔以身化轮回——补全天道缺失——自此称平心娘娘、为"地道之主"（[人物/后土娘娘]、[幽冥/六道轮回与地府]） |
| **地府阴司** | 酆都大帝 | 后土化轮回后逐步成型的管理机构——以酆都大帝为尊——下辖十殿阎罗、判官、牛头马面、黑白无常、孟婆等——掌生死簿、勾魂、审判、发配轮回（[道教神佛/冥府]、[地祇/十殿阎罗与地府诸神]） |

## 二、体系关系（生死流程）
```
生灵死后
  → 魂魄入幽冥（血海为其地缘背景——幽冥界）
  → 地府审判（酆都/十殿阎罗——判善恶、定刑期）
  → 六道轮回（后土轮回——决定来世）
  → 转世投胎
```
- 天庭掌"生"之秩序——地府掌"死"之秩序——六道轮回为中枢枢纽；
- **三界通道**：南天门连通天界与人间（[势力/天庭]）、幽冥海（或轮回入口）连通人间与幽冥——两处要冲。

## 三、幽冥的"半独立"姿态
- 幽冥既不归天庭直辖（冥河老祖"圣人不死"特例、酆都听命于天道而非玉帝）——又受天道与地道约束；
- 后土（地道之主）与鸿钧（天道）——"天道管生、地道管死"的二元格局（部分设定）；
- 佛教地藏王菩萨"地狱未空誓不成佛"——幽冥的佛门力量（[人物/地藏王菩萨]相关、[佛教/菩萨]）——佛道共构幽冥（[道教神佛/冥府]十八层地狱）。
