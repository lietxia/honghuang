# 人族总览

人族，盘古开天之后由女娲以九天息壤与自身形象抟土所造的种族。人族肉体凡胎、寿元短暂，却得天独厚：**灵性第一、智慧超群、气运所钟**，历经巫妖大劫后崛起，终成天地主角。

## 一、种族起源
- **女娲造人**：巫妖纪元，女娲以九天息壤混合自身精血抟土造人，第一批人族自女娲之手而生（后以藤条蘸泥浆甩出更多）。女娲因此**功德圆满，证道成圣**。
- **人族之基**：人族生而"弱"——无妖族之肉身、无巫族之血脉神通，却有"灵"（智慧）与"心"（人性），可修行、可悟道。
- **先天不足**：人族初生时茹毛饮血、寿命不过百，面对妖兽巫妖皆是蝼蚁，全赖女娲与三皇庇护。

## 二、种族特征
| 特征 | 说明 |
|---|---|
| 肉体凡胎 | 无爪牙之利、无筋骨之强，靠工具与智慧生存 |
| 灵性第一 | 天地间唯一"灵性圆满"的种族，可修仙、可悟道、可成圣 |
| 繁衍极快 | 百年一代，人口增长远超巫妖，气运随之膨胀 |
| 人道气运 | 天道钦定"天地主角"，种族气运鼎盛，圣人亦要倚仗人族气运立教 |
| 三皇庇护 | 火云洞三圣（伏羲、神农、轩辕）以人道圣人之身护佑人族 |

## 三、人族崛起（巫妖大劫的受益者）
- 巫妖大战中，巫族与妖族两败俱伤——妖族天庭崩塌、十二祖巫尽灭（后土化轮回），大地主角之位空缺。
- 人族因"不在劫中"（弱小无争）幸存，顺势崛起，从蛮荒部落走向三皇治世的文明时代。
- 此后人族历经：三皇定伦 → 五帝立制 → 绝地天通 → 大禹治水 → 夏商周三代 → 封神之战 → 西游取经，终成天地正统。

## 四、人族的"天地人"定位
- **天**：天道之下，人族受天庭统辖（昊天掌三界）。
- **地**：人族居于四大部洲之南赡部洲（人界核心）。
- **人**：人族自有人道一脉——火云洞三皇、历代人皇、人道气运，独立于天道之外，是洪荒流"人道 vs 天道"叙事的核心。

## 五、人族与各大势力
| 势力 | 关系 |
|---|---|
| 妖族 | 上古敌对（妖族视人族为食粮/蝼蚁），巫妖大劫后人妖两立 |
| 巫族 | 上古共生（巫族占大地，人族初依附），后黄帝战蚩尤彻底决裂 |
| 阐教 | 元始天尊立阐教"顺天应人"，姜子牙助周伐纣正因商周之争属人道气运更替 |
| 截教 | 通天教主"有教无类"收人族修士，封神中截教多为人族修士应劫 |
| 佛教 | 西游东扩，以人族为主要信众（唐僧取经渡化南赡部洲） |

## 六、洪荒流中的"人"
- 洪荒流核心设定之一：**人族是天道选定的天地主角**，但"人道"与"天道"并不完全一体——三皇证道成圣但不管天道，只管人族，形成洪荒流的"人道一脉"。
- 人族修士上限极高：老子（太上老君）立人教、多宝化佛、历代人皇（轩辕）皆可证道；凡人亦可修仙成神（封神榜 365 正神多为人族/修士魂魄）。
