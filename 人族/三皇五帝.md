# 三皇五帝：人族文明奠基

三皇五帝是中国上古传说中人族从蒙昧走向文明的黄金时代，也是洪荒流设定中"人皇正统"的源头。三皇定人道、五帝立纲常，人族自此成天地主角。

## 一、三皇（火云洞三圣）

三皇通常指**伏羲、神农（炎帝）、轩辕（黄帝）**，功成后居火云洞，称"火云洞三圣"，为**人道圣人**——地位比肩天道圣人，却不掌天道、不沾量劫，专司人族气运教化。

### 天皇伏羲（人文之祖）
- **画八卦**：仰观天象、俯察地理，始画八卦，以通神明之德——人族智识之始。
- **创文字**：代结绳记事，造书契文字，文明得以记录传承。
- **教渔猎/制嫁娶**：教民结网捕鱼、驯养牲畜，定嫁娶之礼、别男女之序。
- **演河图洛书**：得河图（龙马负图）悟天地数理，开启人族推演天机之道。
- 神通：八卦推演、河图洛书演算；法宝：八卦盘、河图、伏羲琴。

### 地皇神农（炎帝·医药农耕之祖）
- **尝百草**：亲尝百草以辨药性，一日曾遇七十毒，著《神农本草》——医药之祖。
- **教农耕**：制耒耜、教稼穑，播种五谷，人类从渔猎游牧走向定居农耕。
- **日中为市**：以物易物、设市交易，商业雏形。
- **神农鼎/赭鞭**：神农鼎炼药，赭鞭鞭百草知毒——医药之道的神化。

### 人皇轩辕（黄帝·人文初祖）
- **统一华夏**：战炎帝于阪泉、败蚩尤于涿鹿，华夏诸族一统，奠定中华民族根基。
- **立官制/造舟车**：设官职、定律吕、造舟车、制衣裳，国家制度萌芽。
- **战蚩尤**：得九天玄女授兵信神符，造指南车破蚩尤大雾，杀蚩尤于涿鹿（见[人物/蚩尤]）。
- **轩辕剑**：人皇圣剑，斩蚩尤、镇天下，后世帝王传国之宝。
- 神话化：黄帝乘龙升天（鼎湖龙去），道教尊为中央黄帝。

## 二、五帝（定人伦、立纲常）

五帝通行说：**少昊、颛顼、帝喾、尧、舜**（接续黄帝）。

| 帝 | 身份 | 功绩 |
|---|---|---|
| **少昊** | 黄帝之子，金天氏 | 治西方，以鸟纪官，凤鸟司历，立少昊之国 |
| **颛顼** | 黄帝之孙，高阳氏 | **绝地天通**——命重司天、黎司地，断绝人神自由往来，凡人不得轻上天、神祇不得擅下凡，人神之隔自此而定 |
| **帝喾** | 颛顼之侄，高辛氏 | 仁德宽厚，万民归心，历法更精 |
| **尧** | 帝喾之子，陶唐氏 | 仁德如天，命羲和制历法、敬授民时；年老禅让于舜，开"公天下"之范 |
| **舜** | 尧所禅，有虞氏 | 以孝德闻，命大禹治水，功成后禅于禹，开"家天下"前最后的禅让盛世 |

## 三、绝地天通（人神分野的关键事件）

- 颛顼"绝地天通"是上古神话与人族命运的分水岭：
  1. **此前**：人神杂处，巫觋通天，凡人可自由往来天地（"民神杂糅，不可方物"）。
  2. **此后**：神归天、人守地，修行归仙神专管，凡人只得人道修持。
- 意义：① 安天地秩序，杜绝巫术泛滥；② 使人族彻底脱离"神之附庸"，自成一体；③ 为后世"封神"（人神分野、封神榜）奠定法理基础。
- 洪荒流中，绝地天通常被解释为"鸿钧合道后收紧人神界限""人道独立于天道的标志"。

## 四、三皇五帝的文明贡献
| 领域 | 贡献者 |
|---|---|

| 农耕 | 神农教稼穑 |

| 渔猎畜牧 | 伏羲教结网 |

| 政治 | 轩辕立官制、尧舜行禅让 |
| 人神秩序 | 颛顼绝地天通 |

## 五、洪荒流设定
- 洪荒流中三皇为"人道圣人"（火云洞三圣），与天道圣人（三清、女娲等）并列而不相干——形成"天道""人道"双线格局。
- 五帝多为"人族英主"，部分被设定为仙神转世（尧舜受天道点化）或少昊、颛顼为上古天帝。
- 三皇退居火云洞后不涉量劫，专司庇护人族；每逢人族危难，以人道气运暗中指引（如封神中助西岐）。
