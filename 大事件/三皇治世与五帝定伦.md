# 三皇治世与五帝定伦

人族从蛮荒进入文明的黄金时代，确立人皇正统。

## 三皇（火云洞三圣）
| 圣皇 | 功绩 |
|---|---|
| 天皇伏羲 | 画八卦、教渔猎、制嫁娶、创文字（替结绳） |
| 地皇神农（炎帝） | 尝百草、教农耕、辨药性、日中为市 |
| 人皇轩辕（黄帝） | 统华夏、战蚩尤、造舟车、制音律、建制度 |

三皇功成后，退居火云洞，不再干涉人间，为人道圣人（地位等同于圣人，但不掌天道，不沾量劫）。

## 五帝
| 帝 | 功绩 |
|---|---|
| 少昊（黄帝长子） | 金天氏，治西方，以鸟纪官 |
| 颛顼（黄帝之孙） | 绝地天通（断人神往来），治北方 |
| 帝喾（颛顼之侄） | 仁德，天下归心 |
| 尧 | 帝喾之子，禅让制，命羲和历法，仁德之君 |
| 舜 | 尧禅让，孝德天下，命禹治水 |

## 绝地天通
颛顼命重（南正）管天、黎（火正）管地，断绝人神自由往来——从此凡人不能轻易上天，神也不能随意下凡。这是洪荒流与上古神话的分水岭之一。

## 总结
三皇五帝奠定了人族文明的基础，从此人族不再是洪荒弱族，而是天地主角。
