# 紫霄宫分圣位与分宝

鸿钧合道后于紫霄宫第二次讲道的重要内容——分配六道圣位（鸿蒙紫气）与分宝岩分宝。这是洪荒"圣人时代"的开启时刻。

## 一、紫霄宫三讲
鸿钧合道后于天外混沌紫霄宫开讲大道，洪荒众生皆可听道：
- **第一讲**：传授大道三千（听者三千客）——初步奠定诸仙根基；
- **第二讲**：分圣位——宣示天道之下将有六圣（天道圣人）；
- **第三讲**：分宝——分宝岩上分发先天灵宝（圣人之下诸仙得宝，见[大事件/鸿钧紫霄宫讲道]）。

## 二、六圣位与鸿蒙紫气
- **圣位凭证**：六道**鸿蒙紫气**（大道之基/证道之引）——得紫气者方有资格证圣；
- **六圣名单**（紫霄宫钦定）：
| 圣位 | 圣人 | 证道方式 |
|---|---|---|
| 1 | **太上老君（老子）** | 立人教（开天功德+立教功德） |
| 2 | **元始天尊** | 立阐教 |
| 3 | **通天教主** | 立截教 |
| 4 | **女娲** | 造人功德（后天灵气） |
| 5 | **接引道人** | 立西方教宏愿 |
| 6 | **准提道人** | 立西方教宏愿 |

## 三、红云让座（圣位第7之争）
- 红云老祖与鲲鹏在紫霄宫争**第七个蒲团**（一说第六/七之位）——红云让座给准提/接引（或先让给接引）——"红云让座"成为洪荒最大因果之一（见[大事件/红云让座]）。
- 红云因此得罪鲲鹏等，后被劫杀——"让座之因、陨落之果"（鸿钧以紫气诱鲲鹏——红云之死版本各异）。

## 四、分宝岩分宝（第三讲）
- 分宝岩上，鸿钧将开天以来收藏的**先天灵宝**分给诸圣与听道大能：
| 得宝者 | 法宝 |
|---|---|
| 太上老君 | 太极图、天地玄黄玲珑塔（功德至宝）等 |
| 元始天尊 | 盘古幡、玉如意等 |
| 通天教主 | 诛仙四剑+诛仙阵图（"非四圣不可破"）等 |
| 女娲 | 山河社稷图、红绣球、招妖幡 |
| 接引 | 十二品功德金莲、接引神幢 |
| 准提 | 七宝妙树、六根清净竹 |
| 其他大能 | 河图洛书（帝俊/太一）、乾坤鼎、弑神枪等 |

- 分宝后诸仙实力大增——为封神大劫"法宝大战"埋下伏笔（见[法宝/至宝体系]）。

## 五、意义
- 六圣确定→洪荒进入"圣人为尊"的时代（圣人之下皆蝼蚁）；
- 分宝不均/圣位之争埋下阐截矛盾、西方教东扩的种子——封神大劫的远因。
