# 紫霄宫分圣位与分宝

鸿钧合道后于紫霄宫开讲的**第二次讲道**——分配六道圣位（鸿蒙紫气）与**分宝岩分宝**。这是洪荒"圣人时代"的开启时刻：圣位钦定（六圣格局）、法宝分发（诸圣成型的装备基础）——自此洪荒从"准圣混战"进入"圣人坐庄"的新秩序。来源：洪荒流设定（《佛本是道》体系）、[大事件/鸿钧紫霄宫讲道]。

## 一、紫霄宫三讲
鸿钧合道后于天外混沌紫霄宫开讲大道——洪荒众生皆可听道（"紫霄宫三千客"）：
| 讲次 | 内容 | 意义 |
|---|---|---|
| **第一讲** | 传授大道三千（听者三千客——[宇宙/三千大道]） | 初步奠定诸仙根基（紫霄宫中客=洪荒第一批顶尖大能） |
| **第二讲** | 分圣位——宣示天道之下将有六圣（天道圣人） | "圣人时代"的宣示——六圣格局确定 |
| **第三讲** | 分宝——分宝岩上分发先天灵宝 | 诸仙得宝——实力大进（[法宝/至宝体系]） |

## 二、六圣位与鸿蒙紫气
- **圣位凭证**：六道**鸿蒙紫气**（大道之基/证道之引）——得紫气者方有资格证圣（[境界/斩三尸与证道]证道三法）；
- **六圣名单**（紫霄宫钦定）：
| 圣位 | 圣人 | 证道方式 |
|---|---|---|
| 1 | **太上老君（老子）** | 立人教（开天功德+立教功德——[人物/三清]） |
| 2 | **元始天尊** | 立阐教 |
| 3 | **通天教主** | 立截教 |
| 4 | **女娲** | 造人功德（后天灵气——[人物/女娲]造人） |
| 5 | **接引道人** | 立西方教宏愿（[人物/西方二圣]） |
| 6 | **准提道人** | 立西方教宏愿 |

> 六圣证道方式分两类：三清+接引准提以"立教宏愿"（教化功德）、女娲以"造人功德"（创生功德）——"功德证道"的两大形态（[概念/气运功德香火业力]）。

## 三、红云让座（第七圣位之争）
- 红云老祖（[人物/镇元子与红云]红云）与鲲鹏在紫霄宫争**第七个蒲团**（一说六/七位）——红云让座给准提/接引——"红云让座"成为洪荒最大因果之一（[大事件/红云让座]）；
- 红云的"好人"之名与"失圣位之殇"——让座之因、陨落之果（红云后被劫杀——鲲鹏记恨——鸿钧以紫气诱鲲鹏——版本各异）——"洪荒第一好人"的悲歌（[人物/镇元子与红云]红云陨落）。

## 四、分宝岩分宝（第三讲）
分宝岩上——鸿钧将开天以来收藏的**先天灵宝**分给诸圣与听道大能：
| 得宝者 | 法宝 |
|---|---|
| 太上老君 | 太极图、天地玄黄玲珑塔（功德至宝）等（[法宝/至宝体系]太极图） |
| 元始天尊 | 盘古幡、玉如意等 |
| 通天教主 | 诛仙四剑+诛仙阵图（"非四圣不可破"）等（[阵法/诛仙剑阵]） |
| 女娲 | 山河社稷图、红绣球、招妖幡（[法宝/十大先天灵宝榜]） |
| 接引 | 十二品功德金莲、接引神幢 |
| 准提 | 七宝妙树、六根清净竹（[法宝/十大先天灵宝榜]） |
| 其他大能 | 河图洛书（帝俊/太一）、乾坤鼎、弑神枪等 |

- 分宝后诸仙实力大增——为封神大劫"法宝大战"埋下伏笔（（[法宝/总览]——封神=法宝斗法的战争）。

## 五、意义
| 意义 | 说明 |
|---|---|
| **圣人时代开启** | 六圣确定→洪荒进入"圣人为尊"的时代（圣人之下皆蝼蚁——[境界/境界详解]） |
| **因果伏笔** | 分宝不均/圣位之争埋下阐截矛盾、西方教东扩的种子——封神大劫的远因（[大事件/封神之战始末]） |
| **势力成型** | 圣人各据道场立教——人教/阐教/截教/西方教四教格局（[教派/道门三教]、[教派/西方教与佛教]） |
| **法宝体系** | 分宝岩=洪荒法宝"第一次分配"——先天灵宝各归其主（[法宝/至宝体系]开天三宝+帝俊河图洛书） |
