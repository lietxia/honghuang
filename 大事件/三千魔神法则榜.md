# 三千魔神法则榜

混沌时期三千混沌魔神及其执掌法则——洪荒流"三千大道"的人格化设定。盘古开天时斩杀三千魔神，其法则散落洪荒成为宇宙运行之基。

## 一、概念
- 混沌未分时，随大道衍化诞生**三千混沌魔神**——每一位魔神的诞生即对应一条法则（"三千大道"）的显化（见[宇宙/混沌魔神]、[宇宙/三千大道]）。
- 盘古开天必须"斩尽三千魔神"——因为混沌法则（清浊不分）与开天（清浊分明）相悖；魔神阻挠开天，被盘古以力证道横扫。
- 魔神陨落后：法则散入洪荒（成为天地规则）、怨气化先天灵宝/血海（冥河）、部分转世重生（洪荒流常见"魔神转世"设定）。

| 魔神 | 执掌法则 | 说明 |
|---|---|---|
| **盘古** | 力之大道（创始） | 创世主——非三千魔神之一，而是"开天者"（斩众魔） |
| **罗睺** | 魔之大道 | 魔祖——开天后转西方，龙汉初劫幕后黑手（[人物/罗睺]） |
| **杨眉大仙** | 空间大道 | 空心杨柳化形——鸿钧道友，空间神通第一（"袖里乾坤"级） |

| **命运魔神（苦厄）** | 命运大道 | 掌众生命运线 |
| **造化魔神** | 造化大道 | 掌创造与生命力（与女娲相关） |
| **毁灭魔神** | 毁灭大道 | 掌破坏与终结 |
| **阴阳老祖** | 阴阳大道 | 与鸿钧联手战罗睺（"阴阳二气"） |
| **乾坤老祖** | 乾坤大道 | 与鸿钧联手战罗睺（"乾坤"二仪） |
| **五行魔神（五尊）** | 金木水火土 | 或分或合（五行法则化身） |
| **雷之魔神 / 电之魔神** | 雷/电大道 | 雷霆法则 |
| **因果魔神** | 因果大道 | 掌因果业力网 |
| **轮回魔神** | 轮回大道 | 掌生死轮回（后土化轮回相关） |

## 三、法则散落与受益者
| 法则去向 | 受益者 | 说明 |
|---|---|---|
| 鸿蒙紫气（大道之基） | 六圣 | 紫霄宫分圣位（[大事件/紫霄宫分圣位与分宝]） |
| 先天灵宝 | 诸仙 | 魔神怨气/精血化宝（太极图/盘古幡/诛仙剑等） |
| 血脉传承 | 巫族等 | 祖巫承盘古精血（魔神血脉） |
| 天地法则 | 洪荒 | 三千大道成天道运行规则（[宇宙/三千大道]） |

## 四、洪荒流设定差异
- 部分设定"魔神=混元大罗金仙级"（圣人战力）——盘古一斧一个横扫（实力碾压）；
- 亦有设定三千魔神为"混沌生灵"而非"法则化身"（法则=其力量来源）；
- "魔神转世/后裔"：洪荒流常见主角背景（如"某魔神转世重修"）——见[参考/各小说设定差异]。
