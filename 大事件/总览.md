## 事件间因果链
```
混沌 → 开天（盘古） → 道祖（鸿钧合道） → 三族（龙汉初劫）
→ 巫妖（巫妖大劫） → 人族（三皇五帝） → 封神（阐截之争）
→ 西游（佛门东扩） → 洪荒格局定型
```
每个纪元以一场量劫为终点、以气运转移为因果——洪荒史即"天道清算+气运洗牌"的历史（见[量劫/量劫机制]）。
