# 西游取经与佛门东扩

西游量劫的核心事件——唐僧师徒西天取经（九九八十一难）背后，是佛门东扩、佛道格局洗牌的大棋局。

## 一、背景（佛道暗争）
- 封神大劫后：西方教演变为佛教（如来为佛祖），佛门势力大兴于西牛贺洲；
- **佛门东扩需求**：欲向中土（东胜神洲/南赡部洲）传法——但天庭（道门）固守中土、佛道气运之争暗流涌动；
- **气运博弈**：佛门需要一场"天庭默许的东扩仪式"——取经正是佛道妥协的产物：道教（天庭/太上老君）参与布局（坐骑童子下凡作妖）、佛门完成传播。

## 二、取经布局（佛门的"剧本"）
| 环节 | 佛门安排 | 说明 |
|---|---|---|
| 取经人 | 金蝉子（如来二弟子）转世唐僧 | 十世修行、元阳未泄（[人物/唐僧]） |
| 徒弟 | 悟空（大闹天宫被镇）、八戒（天蓬贬凡）、沙僧（卷帘贬凡）、白龙马（龙族） | 皆天庭"弃子"→佛门收编（[人物/西游记妖怪全录]） |
| 磨难 | 九九八十一难（多为天庭/佛门内部人士下凡） | "有后台的活、没后台的死"（西游潜规则） |
| 终点 | 灵山雷音寺取经、五圣成真 | 佛门各封佛位（斗战胜佛等） |

## 三、八十一难结构
- 一难一劫：每难对应"业力消解/气运转移"（[量劫/西游量劫]）；
- 妖怪来源统计：天庭神仙坐骑/童子（金角银角/青牛/奎木狼/九灵元圣/白鹿/玉兔等）、佛门内部（黄眉/大鹏/老鼠精）、野妖（白骨精/蜘蛛精/车迟国三妖）；
- 关键大战：大闹天宫（前传）、三打白骨精、车迟国斗法、金兜山青牛（金刚琢）、狮驼岭三魔、火焰山牛魔王。

## 四、佛门东扩完成
1. **取经成功**：真经东传（"经不可轻传"——阿难迦叶索"人事"名场面）；
2. **五圣成真**：唐僧（旃檀功德佛）、悟空（斗战胜佛）、八戒（净坛使者）、沙僧（金身罗汉）、白龙马（八部天龙马）；
3. **佛教中土大兴**：寺院林立、信徒遍及——"南朝四百八十寺"之盛（现实对应）；
4. **格局定格**：佛道鼎立（佛门东扩完成、道门天庭仍主导）——洪荒进入平稳期（[时间线/西游量劫]）。

## 五、深层解读
- **西游=佛道博弈的隐喻**：天庭"奉命"派出妖怪（老君坐骑/童子、寿星白鹿）制造磨难——实为两教在"规则内"的势力交锋；
- **悟空=大闹天宫的自由意志 vs 取经的体制收编**：从"齐天大圣"到"斗战胜佛"——洪荒流常解为"天道收编妖性"；
- 与封神对比：封神以战争完成量劫、西游以"取经"完成量劫——"软量劫"模式（[量劫/西游量劫]）。
