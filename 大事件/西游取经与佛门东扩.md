# 西游取经与佛门东扩

封神后天庭已定，佛教需要扩大影响力，取经大计由此展开。

## 起因
- 封神后佛教收获大量截教弟子（三千红气），但佛教影响力仍在西方
- 如来（释迦牟尼）欲将佛法东传至南赡部洲（大唐中原）
- 道教在中原势力根深蒂固，需以"取经"形式合法介入

## 经过
1. 金蝉子（如来二弟子）转世为唐僧
2. 孙悟空（女娲补天石所化）大闹天宫，被压五行山
3. 孙悟空、猪八戒（天蓬元帅）、沙僧（卷帘大将）、白龙马（西海龙王三太子）组成取经团队
4. 西行十万八千里，历经九九八十一难
5. 各路妖魔涌现，多为天庭/佛教/道教的坐骑或童子下凡

## 八十一难分类
| 类型 | 代表 |
|---|---|
| 山妖水怪 | 黑熊精、白骨精、牛魔王 |
| 天界坐骑下凡 | 青牛精（太上老君）、金毛犼（观音）、黄眉大王（弥勒） |
| 佛道童子 | 金角银角（老君）、红孩儿（牛魔王之子） |
| 国家之难 | 女儿国、灭法国、车迟国 |
| 天庭之难 | 昴日星官、四木禽星、二十八宿 |

## 后果
- 佛教东传，大唐佛教大兴
- 佛门势力扩展到中原，形成"佛道并立"格局
- 取经五人皆成正果（唐僧成佛、悟空成斗战胜佛等）
- 妖族势力进一步被镇压/收服

## 洪荒流观点
西游量劫是洪荒最后一次大劫。此后三界格局定型：天庭、道教、佛教三足鼎立，人间进入有史可考的时代。
