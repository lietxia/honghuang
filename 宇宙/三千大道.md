# 三千大道

洪荒世界最本源的法则总称。洪荒流设定中，混沌未判之时，天地间共有**三千大道法则**，每一条法则化为一尊**混沌魔神**执掌。盘古开天斩尽三千魔神，但大道法则本身不灭，散入洪荒，成为后世修士可领悟、可证道的根本力量。

> 与"天道"的关系：盘古开天前为"大道"显化（三千法则并存）；开天后大道隐、天道生，天道统御万法，但三千大道仍为最底层逻辑。圣人掌"法则"之一角，准圣悟"大道"之一缕。

---

## 一、前十大道（最强法则）

多方资料（搜狐、起点、知乎洪荒圈）一致认定前十排名如下。掌握者皆为开天前的顶级混沌魔神，各有伴生混沌至宝：

| 排名 | 大道 | 执掌魔神 | 伴生至宝 | 结局 |
|:---:|---|---|---|---|
| 1 | **力道** | 盘古 | 开天斧（后化太极图/盘古幡/混沌钟） | 开天身化万物，以力证道 |
| 2 | **时间** | 时辰道人（青石所化） | 时间轮盘 | 被盘古斩杀，仅余残魂遁走 |
| 3 | **空间** | 杨眉大仙（空心杨柳所化） | 空心杨柳枝 | 战败逃走，后隐世，曾助鸿钧 |
| 4 | **混沌** | 混沌老祖（混沌石所化） | 混沌珠 | 重伤而逃，不知所终 |
| 5 | **仙道** | 鸿钧（一缕正气所化） | 正气拂尘/造化玉碟 | 幸存，合身天道成道祖 |
| 6 | **魔道** | 罗睺（一缕魔气所化） | 诛仙四剑+阵图 | 与鸿钧争道，败亡，魔道不灭 |
| 7 | **生命** | 灵木道人（灵木所化） | 灵木法杖 | 残灵遁走，化十大灵根之绿柳等 |
| 8 | **五行** | 五行道人（五行气所化） | 五行塔 | 五气失智逃散，化五行本源 |
| 9 | **阴阳** | 阴阳道人（阴阳气所化） | 混沌阴阳镜 | 留两道阴阳之气遁走 |
| 10 | **毁灭** | 毁灭魔神 | 毁灭权杖 | 被盘古斩杀 |

### 民间口诀（洪荒圈流传）
> **时间为尊，空间为王；命运不出，因果称皇；造化无双，轮回无限。**

这句口诀点出几条"虽不一定进前十、却极其特殊"的大道：
- **命运大道**：高于因果，可改定数，最神秘，常被设定为"大道之上"
- **因果大道**：牵动万物报应，圣人亦忌
- **造化大道**：无中生有、点化万物（女娲补天造人即含造化）
- **轮回大道**：掌生死转世（后土化轮回即承此道）

## 二、其他知名大道（按类别）

除前十外，三千大道中常被提及者：

### 元素类
- **火之大道** / **水之大道** / **雷之大道** / **风之大道** / **土之大道** / **冰之大道**
- 多对应十二祖巫所掌法则（祝融火、共工水、强良雷、翕兹电、天吴水、奢比尸风等）

### 规则类
- **杀戮大道**：以战证道，煞气冲天（一些魔修、阿修罗道近之）
- **吞噬大道**：吞天食地，壮大自身
- **剑之大道**：以剑入道，杀伐第一（通天教主截教核心）
- **阵之大道**：布阵困敌，演化天地
- **音律大道**：以乐入道，惑心乱神
- **幻之大道**：制造虚妄，迷惑心神

### 生命/灵魂类
- **生死大道**：掌生杀大权
- **灵魂大道**：炼魂役鬼
- **因果大道**（见上）
- **轮回大道**（见上）
- **命运大道**（见上）

### 时空衍生
- **时间大道**（前十第二）
- **空间大道**（前十第三）
- **速度大道**：极速位移
- **预知大道**：窥探未来片段

### 本源类
- **混沌大道**（前十第四）
- **阴阳大道**（前十第九）
- **五行大道**（前十第八）
- **太极大道**：阴阳调和之极致
- **乾坤大道**：天地之纲

## 三、大道与修炼体系

| 境界 | 与大道的关系 |
|---|---|
| 凡修（炼气→大乘） | 感悟法则碎片，借法施术 |
| 天仙→金仙 | 初步合一某类法则 |
| 大罗金仙 | 法则圆满，可创小世界 |
| 准圣 | 悟透一条大道之一缕，言出法随 |
| 混元大罗金仙（圣人） | 掌大道之一角，以力/功德/鸿蒙证道 |
| 道祖（鸿钧） | 合天道，统御万道 |

### 三大证道法门
1. **以力证道**：盘古专属，最强但开天即陨，后无人能成
2. **功德证道**：女娲（造人补天）、三清（开宗立教）等，借天道功德成圣
3. **鸿蒙证道**：鸿钧以身合道，与天道合一

### 斩三尸
圣人以下，斩善尸、恶尸、执念尸，三尸尽斩即可窥混元——这是"借大道法则圆满"的捷径，非以力破天。

---

## 四、三千大道的去向

盘古斩尽三千魔神后：
- **魔神身陨**：法则碎片散入洪荒，化为先天灵宝、灵根、道韵
- **残魂幸存**：盘古、杨眉、鸿钧、罗睺、灵木等少数携大道本源遁走
- **法则沉淀**：开天后，天道统御，但三千大道仍为底层逻辑，可被后世圣人/准圣领悟
- **十大灵根**：多被认为是生命、木、水、火等大道魔神的残灵所化（如绿柳=杨眉/灵木化身）

## 五、参考设定差异

| 来源 | 前十说法 |
|---|---|
|| 主流洪荒流（搜狐/起点） | 力>时间>空间>混沌>仙道>魔道>生命>五行>阴阳>毁灭 |
|| 部分小说变体 | 把"命运""因果"排入前三，力道仍居首 |
|| 《佛本是道》（经典源头） | 未明确排名，但盘古力道、鸿钧仙道、罗睺魔道为三大主轴 |

> 注：三千大道的具体名单各书略有出入，但"力道第一、时空次之、仙魔对立"是共识。本篇取最主流说法。

## 六、中下位大道（较弱法则）

"三千大道无高下，但修者有强弱"——在洪荒流小说中，有部分大道因**领悟门槛低、攻击力偏弱、或偏辅助/生活系**，被视为"中下游"法则。但修炼到极致同样可成圣。

### 辅助/生活类（战力偏弱）
| 大道 | 特点 | 典型代表 |
|---|---|---|
| **丹之大道** | 炼丹炼药，以丹入道，可炼九转金丹、起死回生 | 太上老君（丹道第一人） |
| **阵之大道** | 布阵为核心，战力依赖阵法 | 通天教主（诛仙剑阵）、各路阵修 |
| **符箓大道** | 以符箓引动天地之力 | 道教符箓一脉 |
| **器之大道** | 炼器造宝，以器证道 | 多宝天尊（器修） |
| **茶之大道** | 以茶入道，悟道静心（极冷门，偶尔出现） | 某些洪荒同人设定 |
| **酒之大道** | 以酒入道，醉中悟法（偏门但有趣） | 济公、酒中仙 |
| **香之大道** | 以香气悟道、化香为神通 | 个别洪荒女修设定 |
| **书/画大道** | 以书画入道，笔墨化形 | 文曲星君、文昌帝君 |

### 自然元素类（中等偏弱）
| 大道 | 特点 | 弱在何处 |
|---|---|---|
| **风之大道** | 御风而行、风暴攻敌 | 攻击力不如雷火，偏辅助（速度、遁术） |
| **云之大道** | 聚云化形、隐遁藏身 | 几乎没有正面战力，纯辅助/遁术 |
| **雾之大道** | 迷雾困敌、幻化 | 隐蔽性强但杀伤力弱 |
| **雨之大道** | 御水成雨、润物 | 偏治愈/辅助，非攻伐 |
| **冰之大道** | 寒冷冻结（水之变体） | 比水火略弱，上限低 |
| **木之大道** | 生命生长（非生命大道） | 不擅攻伐，偏治疗/恢复 |

### 灵魂/情感类（偏门、看作者设定）
| 大道 | 特点 |
|---|---|
| **梦之大道** | 入梦杀敌、编织梦境——攻击力有限但诡异，多在准圣斗法作为辅助 |
| **情之大道** | 以情证道，七情六欲皆可成法——佛门斥为"情劫"，魔门偶有修习，极难圆满 |
| **欲之大道** | 七情六欲的暗面，勾动心魔——与魔道接近，但位格远不及魔道 |
| **音律大道** | 以乐入道，惑心乱神——攻击力有限，多用于辅助/迷惑 |
| **幻之大道** | 制造虚妄——正面强攻弱，但战术价值高 |

### 武道/技艺类
| 大道 | 特点 |
|---|---|
| **剑之大道** | 杀伐虽强，但属"专精之道"，不涉本源，位格低于仙魔时空等上位法则 |
| **刀之大道** | 同剑道，偏刚猛 |
| **枪之大道** | 枪术入道，攻击力中上 |
| **弓之大道** | 远程攻击，一箭定乾坤（后羿射日可视为弓道极致） |
| **毒之大道** | 用毒杀人，偏门但杀伤力可观 |

### 中下位大道修炼口诀（洪荒圈调侃）
> **丹符阵器，傍身之技；风云雾雨，遁隐之资；梦情欲幻，惑心之术；茶酒书画，闲情之趣。**

### 设定说明
- 在洪荒流中，**没有真正"弱"的大道**——任何大道修到极致都能成圣。
- 之所以"弱"，是因为：① 领悟门槛低（风、云、雨等）→上限不高；② 偏辅助/生活系（丹、符、阵、茶、酒）→正面战力不如杀伐道；③ 在小说中多为配角修炼，非主角专属。
- 部分小说设"**大道压制**"：上位大道（力道、时空等）对下位大道有天然压制力，下位大道修士面对上位大道几乎无法反抗。
