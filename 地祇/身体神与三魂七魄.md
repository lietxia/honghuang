# 身体神与三魂七魄（道教身神体系）

道教内修理论中，人体各部位皆有神灵主宰——"身神"体系。出自《黄庭经》《太上老君内观经》等经典，是道教内丹术与存思法的理论基础，也被后世仙侠、洪荒流借用为"内景之神"。来源：百度百科、道教典籍、《云笈七签》。

## 一、身神体系概述（《黄庭经》）
《黄庭经》以"存思身神"为核心，认为人身有三部八景二十四神（一说三百六十神）：

### 五官神（《黄庭经》）
| 神 | 名/字 | 部位 |
|---|---|---|
| 发神 | 苍华·太元 | 头发 |
| 脑神 | 精根·泥丸 | 脑（泥丸宫） |
| 眼神 | 明上·英玄 | 双眼 |
| 鼻神 | 玉垄·灵坚 | 鼻 |
| 耳神 | 空闲·幽田 | 双耳 |
| 舌神 | 通命·正伦 | 舌 |
| 齿神 | 锷峰·罗千 | 牙齿 |
| 心神 | 丹元·守灵 | 心 |

### 五脏神（五行五脏对应）
| 脏 | 神 | 五行 |
|---|---|---|
| 肝 | 龙烟 | 木 |
| 心 | 丹元 | 火 |
| 脾 | 常在 | 土 |
| 肺 | 皓华 | 金 |
| 肾 | 玄冥 | 水 |

> 存思术：修真者"存神服气"，默想身中诸神形象，神安则身健——道教内丹"守一"思想来源。

## 二、三魂七魄
道教认为人由"魂"（阳，属天）与"魄"（阴，属地）构成：

### 三魂
| 魂 | 说明 |
|---|---|
| **胎光** | 主生命，太清阳和之气；胎光不失则长寿 |
| **爽灵** | 主智慧、神识，与生俱来 |
| **幽精** | 主情欲、生殖；幽精衰则欲念消 |

### 七魄
**尸狗、伏矢、雀阴、吞贼、非毒、除秽、臭肺**——主肉体感官欲望（"魄"与肉身同在，人死魄散）。

## 三、三尸神（三尸虫）
- 三尸神（又名三彭：彭琚、彭质、彭矫），居人体上中下三丹田：
  - **上尸**（彭琚）：居脑，好宝物；
  - **中尸**（彭质）：居心腹，好五味；
  - **下尸**（彭矫）：居腹，好色欲。
- 三尸以人之欲念为食，每逢庚申日上天向天帝禀报人之罪过，缩减其寿——故道教有"守庚申"（庚申日不睡，防三尸上天告状）之俗。
- 修仙须"斩三尸"：除尽三尸，方得清净——洪荒流"斩三尸成圣"即化用此说。

## 四、魂魄与生死
- 人死魂升天（归于天界/等待转世）、魄归于地（随肉身入土）。
- 道教存思、招魂仪式（招魂幡、喊魂）——基于"魂魄可离体"信仰。
- 受惊"丢魂"：民间以"叫魂"收回魂魄（婴儿夜啼、受惊皆叫魂）。

## 五、洪荒流中的身神
- 洪荒流内丹文：修士结丹、元婴、阳神——"元婴"即身神之壮大；
- "斩三尸"成圣（善尸、恶尸、执念尸）与道教三尸神有概念渊源（见[境界/斩三尸与证道]）；
- 身神体系常被设定为人体"内天地"的法则具象（如洪荒流"内景二十四神"）。
