# 五显大帝、五通神与地方财神

民间信仰中一类特殊神祇：由"山魈/精怪"崇拜演化而来的五显大帝（五通神），以及各地特色财神。来源：台湾内政部宗教知识、机核（封神小榜）、民间信仰研究。

## 一、五显大帝（五通神）
- **五显大帝**，又称五行大帝、五显灵光大帝、五灵官大帝——福建、台湾、江西地区的重要神明。
- 源流：一说由宋朝"五通神"历代受封成为五显；一说"五通"前身为**山魈**（独角山怪）。
- 演变：宋代五通曾受封侯爵（故称五显/五圣）；明清江南流行的五通神常被文人斥为"淫祀"（传能使人得"不义之财"，亦有'五通神掳妇女'传说）；而五显大帝在闽台为正祀神明，护佑一方。
- 职能：掌财运（偏财）、驱邪、保平安——五显宫香火鼎盛。

### 五通神诸说
| 别名 | 说法 |
|---|---|
| 五郎神、五猖神 | 江南流传，五兄弟神 |
| 五显神 | 宋代受封后的正名 |
| 五圣庙 | 江南五圣（五通）祭祀 |
| 五府千岁 | 闽台"王爷"信仰（唐代武将化身） |

## 二、地方财神与"偏财神"
- **正财神**：赵公明（武）、比干/范蠡（文）——见[道教神佛/地方与俗神]与[人物/比干]。
- **偏财神**：五路财神（玄坛+招宝萧升、纳珍曹宝、招财陈九公、利市姚少司）、五通神（不义之财）、刘海蟾（撒钱）、善财童子（供奉）。
- **五显=财神之一**：民间将五显大帝作"求财"之神祭拜（"五显进宝"）。

## 三、闽台王爷信仰
- **五府千岁**（李、池、吴、朱、范五府王爷）：闽南"瘟神→保境神"演变，各地"代天巡狩"，王船祭典。
- 王爷神被视为"天帝派遣巡狩"之神，管一方瘟疫、灾祸、财运。
- 孤魂信仰：有应公（灵验逝者）、水流公（溺亡孤魂）、大众爷（无主亡魂）——南方设庙祭祀，属于"人鬼"信仰延伸。

## 五、信仰特点
- 财神信仰是**中国最普及的神明崇拜**之一：求财是民间第一诉求（"财神到、好运到"）。
- 财神体系"文武正偏"分层：正财神讲"公道生财"，偏财神讲"横财机遇"——反映民间对财富兼具"正道"与"偶然"的双重理解。
