# 自然神补遗（霜雪云雾·火神·祥瑞）

气象、时辰、祥瑞类自然神的补充专篇。此前已述[自然神与气象神](自然神与气象神.md)（风伯雨师雷公电母、四时方位神），本篇补其余自然神与祥瑞神。来源：维基百科（中国神话人物列表）、古籍。

## 一、霜雪云神
| 神 | 司职 | 出处/说明 |
|---|---|---|
| **青女** | 霜神 | 神话中的降霜女神（李商隐"青女素娥俱耐冷"）；一说青女=霜神，九月降霜 |
| **滕六** | 雪神 | 与巽二（风神）并称"滕六巽二"——"滕六降雪、巽二起风"（《幽怪录》） |
| **丰隆** | 云师/雷师 | 云神丰隆（《离骚》"吾令丰隆乘云兮"），一说即雷神 |
| **商羊** | 雨兆神鸟 | 一足神鸟，起舞则大雨将至（《孔子家语》）——天候预兆神 |
| **屏翳** | 雨师/云神 | 黄帝雨师屏翳（一作雨师名） |

## 五、时辰与方向自然神
- **四时神**：春句芒、夏祝融、秋蓐收、冬玄冥（见[地祇/自然神与气象神]）。
- **六戊神/六丁六甲**：护法神将体系（见[道教神佛/护法神将]）——值日、值时的"时间神"。
- **风神别称**：风伯（飞廉）、箕伯（箕星）、封姨（风姨，女性风神，《聊斋·绛妃》即"封家"）。

## 六、自然崇拜的意义
- 自然神信仰是"万物有灵"的体现：天地日月、风雨雷电、山川草木皆有神主——构成中国民间信仰最底层的宇宙观。
- 与其他神系区别：自然神源于"现象崇拜"（不依赖历史人物），是道教神谱中最古老的一层。
- 洪荒流中自然神多为"先天神灵"（风伯雨师雷公电母皆为先天神），或为封神后正神。
