# 水神与河神

水神是地祇体系中掌管江河湖海的神灵。中国水域众多，水神系统庞大：四渎（长江、黄河、淮河、济水）之神、河伯、洛神、湘君湘夫人、水官大帝、龙王等。

## 四渎水神
"四渎"即四条独流入海的大河，古礼以四渎配天，《史记·封禅书》："四渎者，江、河、淮、济也。"

| 渎 | 水神封号 | 说明 |
|---|---|---|
| **江渎**（长江） | 广源王 | 长江之神，庙在四川 |
| **河渎**（黄河） | 灵源王（河伯） | 黄河之神，历代祭祀 |
| **淮渎**（淮河） | 长源王 | 淮河之神 |
| **济渎**（济水） | 清源王 | 济水之神，庙在河南济源 |

## 著名水神

### 河伯
- 黄河之神，名冯夷（冰夷），"以庚日溺河，天帝署为河伯"。
- 形象：人面鱼身（或乘两龙）。
- 传说：河伯娶妇（西门豹治邺典故——河伯娶妻恶俗被破除）；冯夷得道成水仙。
- 与洛神、嫦娥等并称上古水仙。

### 洛神（宓妃）
- 洛水之神，传说为伏羲之女宓妃，溺洛水而死，为洛神。
- 曹植《洛神赋》："翩若惊鸿，婉若游龙。"——洛神为最美水神，千古绝唱。
- 又一说洛神为宓羲氏之女洛嫔。

### 湘君与湘夫人
- 湘水之神：湘君指舜（帝舜南巡崩于苍梧），湘夫人指舜之二妃娥皇、女英（泪洒斑竹，即湘妃竹）。
- 屈原《九歌》有《湘君》《湘夫人》两篇。
- 湘江流域祭祀极盛，洞庭湖君山有湘妃祠。

### 水官大帝
- 三官大帝之一：上元天官赐福、中元地官赦罪、**下元水官解厄**——水官大帝（禹）掌解厄、管江河。

## 水神祭祀
- 古代帝王祭四渎（如同祭五岳），朝廷派使臣投玉简金龙于水（"金龙玉简"）。
- 渔民、船夫、航运者祭水神保平安；端午节赛龙舟即祭水神之俗。
- 妈祖信仰为世界级水神崇拜（联合国教科文组织人类非遗）。

## 水神与洪荒流
- 洪荒流中水系由四海龙王+四渎水神+河伯等共同管理，隶属天庭水部。
- 水神多以龙族或后天册封正神为主；江河湖海各有权责。
- 西游中泾河龙王与袁守诚赌雨，违逆玉帝旨意被斩——"水神触犯天条"的著名案例（魏征梦斩泾河龙王）。
