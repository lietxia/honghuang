# 土地与城隍

土地神与城隍神是地祇体系中最贴近百姓的两位守护神——"一方水土养一方人，一方土地护一方民"。

## 土地神（福德正神）

### 身份与地位
- 土地神，俗称"土地公""土地爷""社公"，道教尊为"**福德正神**"，是**最基层**的地祇——一村、一巷、一宅皆有土地。
- 位格虽低，香火极广，被戏称"县官不如现管"——百姓凡婚丧嫁娶、建房动土、丰收欠收、求子求寿皆祭土地。
- 神诞：二月初二（龙抬头之日，亦称土地公诞）。

### 形象与职能
- 形象：白发白须、慈眉善目的老翁，手持金元宝或龙头拐杖（福）、提葫芦（禄），坐于土地庙中。
- 职能：
  1. 守护乡土、宅基，驱邪避祸；
  2. 掌管一方农事、五谷丰登；
  3. 记录乡民生死善恶（向城隍汇报）；
  4. 保一方平安，调解纠纷。

### 土地公传说
- 周朝有个叫张福德的人（一说周代税官），生前爱民如子、乐善好施，死后百姓设庙祭祀，天帝封其为"福德正神"。
- 另有"汤圆祭土地"民俗：冬至/二月初二吃汤圆祭土地。

### 土地婆
- 土地公之妻"土地婆"，掌管家庭和睦；民间常塑土地公土地婆并列像。

## 城隍

### 身份与地位
- 城隍是**一城之主神**（城隍=城池的守护神），职司高于土地，管一城冥司行政。
- 道教尊为"城隍本命守护之神"，唐代封王、宋代加封爵位，明代朱元璋大封天下城隍（京都/府/州/县四级）。
- 城隍为阴官，直接向阎罗/东岳大帝负责，是"冥界行政系统"在城市中的代理。

### 职能
1. 护城安民、保境平安；
2. 执掌一城生死簿、录善恶；
3. 缉捕亡魂、审判鬼魂（冥司初审）；
4. 惩恶扬善，显灵报应；
5. 城隍出巡（清明、七月半、十月初一三巡）。

### 城隍庙
- 城隍庙多建于城市中心，前殿供城隍、后殿供城隍夫人，两侧配十殿阎罗、善恶司官。
- 城隍出巡日：府城隍诞辰、三巡（清明/中元/十月朝），抬神像巡城，场面盛大。

## 土地与城隍的上下级关系
```
城隍（一城） → 管辖各坊土地（一坊/一村） → 宅基土地（一家）
```
- 土地向城隍汇报，城隍向阎罗/东岳汇报；
- 人死后先由土地注销户籍、点卯，再由鬼差押经城隍初审，最后入地府审判。
