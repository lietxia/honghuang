# 星辰之神与命运神（星命信仰）

古人把星辰神格化，形成庞大的星神体系——星神被视为玉帝的臣子，司人间战乱、风雨、疾病、水旱。源自天体崇拜的"星命信仰"是中国自然神体系中最大的一支。来源：维基百科（中国神话人物列表）、百度百科、道教典籍。

## 一、日月星君
| 星神 | 尊号 | 信仰 |
|---|---|---|
| **太阳星君** | 日宫太阳帝君 | 二月初一诞，拜日祈福；形象戴冕旒、红袍 |
| **太阴星君** | 月宫太阴皇君（月光娘娘） | 八月十五拜月；嫦娥、素娥、望舒、常羲、蟾蜍皆与其相关 |
| **太白星君** | 太白金星 | 金星之神——最著名星神之一，为天庭使者（西游记中招安悟空的大臣） |
| **水德星君** | 水德（辰星） | 封神中鲁雄，掌水域 |
| **火德星君** | 火德（荧惑） | 封神中罗宣 |
| **木德星君** | 木德（岁星） | 太岁同源 |
| **金德星君** | 金德（太白） | 与太白金星合一 |
| **土德星君** | 土德（镇星） | 掌中央 |

## 二、北斗与南斗（注死/注生）
- **北斗星君**（北斗七星）：贪狼、巨门、禄存、文曲、廉贞、武曲、破军——"**北斗注死**"，掌人寿命；道教拜斗（礼斗）祈福延寿，九皇大帝（北斗九皇，含辅弼二隐星）。
- **南斗星君**（南斗六星）：司命、司禄、延寿、益算、度厄、上生——"**南斗注生**"。
- 民间"南斗注生，北斗注死"成星命信仰核心；《搜神记》管辂算命故事即南斗北斗改寿。
- 封神斗部：金灵圣母（坎宫斗母）统东斗四星、西斗五星、中斗三星、南斗六星、北斗七星、二十八宿、天罡地煞、九曜星官。

## 三、魁星与文昌（文运星神）
- **魁星（大魁夫子）**：二十八宿奎宿之神格化，掌文运——形象为一鬼蓝面赤发、执笔点斗（"魁星点斗，独占鳌头"），读书人供奉。
- 文昌帝君：梓潼神（张亚子）与文昌六星（上将、次将、贵相、司命、司中、司禄）合流，掌功名利禄（见[道教神佛/地方与俗神]）。

## 五、命运神（司命）
- **大司命、少司命**（《楚辞·九歌》）：掌管命运之神——大司命主生死，少司命主幼少福祉（一说大司命为男神掌寿、少司命为女神掌子嗣）。
- 司命信仰与灶神融合：灶神"九天司命灶君"——司命（掌寿）与灶（掌食）合一，反映古代"命中注定+日常监察"的命运观。
- 福禄寿三星：福星（天官）、禄星（文昌/员外郎）、寿星（南极仙翁/麻姑）。

## 六、太岁（值年岁神）
- 六十甲子各有太岁（殷郊为值年太岁，杨任为甲子太岁）；"太岁头上动土"禁忌，犯太岁之年化解（安太岁）。

## 七、二十八宿与天将
- 二十八宿星君：奎木狼（黄袍怪）、昴日鸡（蝎子精克星）、亢金龙（救悟空于阴阳二气瓶）等在《西游记》中各有登场——星君下凡/调用的经典案例。
- 天兵天将体系：六丁六甲、四值功曹、五方揭谛、九曜星官、二十八宿、十二元辰（见[天神谱]）。
