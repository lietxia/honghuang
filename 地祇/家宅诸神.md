# 家宅诸神

家宅诸神是守护家庭平安的神灵群体，属于地祇/人鬼信仰中最贴近日常的部分。古人祭"五祀"（户、灶、中霤、门、行/井），家宅神系历经演变，形成门神、灶神、井神、厕神、床神等体系。

## 五祀（古代家祭）
《礼记·月令》五祀：**户、灶、中霤（宅神）、门、行（井）**——古代家庭祭祀的五位家神。
- 春祭户、夏祭灶、季夏祭中霤、秋祭门、冬祭行（井）。

## 门神
- 职责：镇守门户、驱邪避鬼。
- 起源：汉代画神荼、郁垒于门（《山海经》度朔山鬼门二神）。
- 唐代以后：**秦琼（叔宝）、尉迟恭（敬德）**——唐太宗因梦中鬼魅，令二将守门，后世画为门神。
- 武门神：秦琼、尉迟恭、赵云、马超、岳飞等武将；文门神：福禄寿、状元及第、加官进爵。
- 其他：钟馗门神、关公门神、哼哈二将门神。
- 春节贴门神、贴春联（门神信仰的春节化）。

## 灶神（灶王爷）
- 职责：监察一家善恶，一年一度上天汇报（"上天言好事，下界保平安"）。
- 身份说法：灶神即"炎帝/祝融"（火神主灶），或为"张单"（民间传说）。
- 神诞：腊月二十三（北方）/腊月二十四（南方）送灶神上天，除夕接灶神回位。
- 祭灶：糖瓜黏住灶神嘴（"二十三，糖瓜粘"），祈其上天多说好话。
- 灶君像：贴于灶台旁，配对联"上天言好事，下界保平安"。

## 井神
- 职责：守护水井，供水清洁。
- 井龙王：井中之龙（西游中悟空唤井龙王捞乌鸡国国王尸体）。
- 除夕封井祭井神（"封井"习俗），正月初三"开井"。

## 厕神（紫姑）
- 厕神名紫姑（子姑），为厕中女神，主占卜、女红。
- 正月十五迎紫姑（请厕神占蚕桑、问吉凶）——古代妇女的占卜习俗。

## 床神（床公床母）
- 床公（床神公公）、床母（床神娘娘），护佑睡眠安稳、生子健康。
- 祭床神：新婚铺床、婴儿满月祭床母。

## 其他家宅神
| 神 | 司职 |
|---|---|
| **户神** | 门户出入平安 |
| **中霤神** | 宅中土地（中堂之神），镇宅 |
| **宅神** | 住宅守护（宅基土地延伸） |
| **石敢当** | 镇宅辟邪（泰山石） |
| **太岁** | 值年岁神（"太岁头上动土"） |
| **土地公** | 宅基所在的一方土地（见[土地与城隍]） |

## 家宅诸神与民俗
- 春节"祭祖祀神"：门神、灶神、井神、床神、宅神统称"家神"，过年一并祭祀。
- "上天述职"系统：灶神腊月二十三上天、土地年终汇报、门神镇守不动——构成家庭层面的"天界监察网"。
