# 十殿阎罗与地府诸神（原型考）

十殿阎罗是中国佛道融合后形成的冥界审判体系。其原型多出自历代忠臣名将、地方名人——"人死为神、忠义成阎君"的典型。来源：维基百科、民间信仰研究（机核封神小榜）、佛教典故。

|---|---|---|---|
| 一殿 | **秦广王** | 蒋子文（东汉秣陵尉，南京蒋子文崇拜） | 专司人间寿夭生死，接引亡魂 |

## 关键原型人物
- **蒋子文**：东汉秣陵尉，追贼伤额而死，三国时显灵护城，孙权封"中都侯"，南京钟山神（蒋王庙）——中国"人鬼成神"典型，为秦广王原型。
- **包拯**：北宋清官，铁面无私，被民间奉为阎罗王最著名的化身（"关节不到，有阎罗包老"生前就称"阎罗包老"）。
- **陆游**：南宋爱国诗人，民间因"放翁"刚直而封平等王。
- **薛仁贵**：唐代名将，转轮王原型（掌轮回转世）——武将入冥司。

## 地府审判流程
1. 人死 → 黑白无常勾魂 → 鬼门关 → 黄泉路 → 望乡台
2. 一殿秦广王初审（善恶分路）
3. 有罪者逐殿受审、受刑（地狱罚）
4. 善者/刑满者 → 十殿转轮王 → 孟婆汤 → 六道轮回

## 佛道融合
- 阎罗原为印度佛教（Yama）死神，与中国"泰山治鬼"能说融合，唐末定型十殿体系，宋元后佛道共信。
- 十殿本「中国化」：历代忠臣良将皆为阎君，反映"阴司公正"的民间期望。
