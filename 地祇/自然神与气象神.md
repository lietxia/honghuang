# 自然神与气象神

先民将自然现象人格化的神明体系。源于原始天体崇拜、气象崇拜，是"万物有灵"信仰的体现。来源：民间信仰研究、百度百科、维基百科。

## 一、气象四神（风伯雨师雷公电母）
| 神 | 司职 | 形象/传说 |
|---|---|---|
| **风伯（飞廉）** | 风神 | 上古神兽飞廉（鹿身鸟首蛇尾）、能致风气；《离骚》"前望舒使先驱兮，后飞廉使奔属"。道教以"风伯方道彰"为名 |
| **雨师（赤松子/屏翳）** | 雨神 | 赤松子为神农时雨师（服水玉）；屏翳为黄帝雨师。道教号"雨师玄冥" |
| **雷公（雷神）** | 雷神 | 雷州雷神陈文玉（一说）、《山海经》雷泽神"龙身人头"。道教"雷公江天君"；天王李靖持塔亦可布雷 |
| **电母（闪电娘娘）** | 电神 | 雷公之配，持镜放光；封神中闪电神金光圣母（十天君之一）同源 |

> 民间"风调雨顺"之祭即祀此四神；龙王爷行雨亦需风雨雷电相伴。

## 二、日月星神（天体崇拜）
| 神 | 司职 | 信仰 |
|---|---|---|
| **太阳星君（日神）** | 日神 | 二月初一太阳星君诞，民间日出设案祭日（清代犹盛）；道教"日宫太阳帝君" |
| **太阴星君（月神/月光娘娘）** | 月神 | 又称太阴星主、月姑、月光菩萨；八月十五拜月；嫦娥奔月为月亮信仰核心故事 |
| **北斗星君** | 星辰 | 掌寿命、命运（"南斗注生，北斗注死"）；道教拜斗祈福 |
| **南斗星君** | 星辰 | 掌生籍，六司延寿；南斗六星 |
| **二十八宿** | 星区 | 四方七宿（见[宇宙/星辰星宿]）；星神皆玉帝臣子，司人间战乱风雨疾病水旱 |
| **太岁（值年太岁）** | 岁星 | 六十甲子各有太岁；"太岁头上动土"禁忌，犯太岁之年要化解 |

## 三、四时与方位神（上古五行神）
| 神 | 季节/方位 | 司职 |
|---|---|---|
| **句芒** | 春/东方 | 木神、春神，人面鸟身乘两龙；《吕氏春秋》"其帝太皞，其神句芒" |
| **祝融** | 夏/南方 | 火神、夏神，兽身人面乘两龙；楚人之祖 |
| **蓐收** | 秋/西方 | 金神、秋神、刑戮之神，人面虎爪执钺（原型后稷） |
| **玄冥（禺强）** | 冬/北方 | 水神、冬神，人面鸟身珥两蛇 |
| **后土** | 中央 | 土神、社神（原型句龙）——大地之母 |

## 四、虹神与云神等
- **虹霓神**：虹为"阴阳交会之气"，《山海经》"虹虹"两首之神；民间称"彩虹娘娘"。
- **云神（云中君）**：楚辞《九歌·云中君》——云神丰隆。
- **河汉诸星**：牛郎织女（牵牛/织女星），七夕鹊桥会。

## 五、气象神与天庭
- 气象神隶属天庭：雷部（雷公电母）、水部（风伯雨师）、斗部（日月星君）——"风调雨顺"是玉帝调剂气象的行政职能。
- 民间祈雨：求龙王（见[地祇/龙王体系]）＞求雨师＞求雷公，各地龙王庙、雷神庙遍布。
- 封神中：雷部正神闻仲（雷祖）、电母金光圣母、风伯菡芝仙、雨师（水德星君鲁雄）——气象神在小说话本中皆有正神之位。
