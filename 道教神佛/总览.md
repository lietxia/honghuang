```
        └─ 先天尊神（太乙·三官·斗姆·西王母·东王公·五方五老·雷祖——道气所化）

              ├─ 得道仙真（八仙·妈祖·关帝·吕祖……——凡人修炼成仙）
              └─ 冥府（酆都·十殿阎王·无常·孟婆——幽冥之政）
```

## 神系特点
1. **三清为尊**：太上老君/元始天尊/灵宝天尊——"道"的三种化身（[人物/三清]）；
2. **四御辅政**：玉帝（万天）、紫微（万星）、勾陈（万雷）、后土（万地）——分掌天政；
3. **先天后天之分**：先天尊神（道气所化——[先天尊神]）vs 得道仙真（凡人修炼——[得道仙真]）——道教独有的成神两途；
4. **神职分工**：雷部（主刑罚）、斗部（主星命）、冥府（主生死）、地方神（主一方）——"神道设教"的分工体系；
5. **与佛教对应**：道教神系与佛教神系（[佛教/总览]）在护法/冥府/俗神层面大量融合（四大天王=魔家四将、伽蓝=关公、十殿阎罗=佛道共构）。
