# 先天尊神（道教神系顶层）

道教神系中由"大道/道气所化的自然之神"——与后天得道者（仙真）相对。先天尊神是道教世界观的最高层：三清、玉皇、四御、五方五老、三官、太乙救苦天尊、东王公西王母、雷祖等（《度人经》）。来源：道教文化中心资料库、武当山道教协会、维基百科。

## 一、什么是先天尊神
- **定义**：先天尊神指各类大道、道气所化的自然之神——"道"的化身，先于万物存在，非人修炼而成。
- **与仙真区别**：先天尊神=道之本体神格化（开天辟地即有）；得道仙真=凡人/异类通过修炼证道（如八仙、关帝）。
- 主要成员：三清、玉皇、四御、五方五老、扶桑大帝（东王公）、西王母、三官大帝、青华帝君（太乙救苦天尊）。

## 二、顶层架构
| 层级 | 尊神 | 说明 |
|---|---|---|
| 最高 | **三清**（元始/灵宝/道德） | 大道之化身，道教最高尊神（见[道教神佛/三清与四御]） |
| 辅佐 | **四御**（玉皇/紫微/勾陈/后土） | 三清之下主宰天地（见[道教神佛/道教神谱详录]） |
| 同列 | **五方五老** | 青/赤/黄/白/黑五帝（三清未成主流前地位最高） |
| 重神 | **三官大帝**、**太乙救苦天尊**、**东王公西王母**、**雷祖** | 各掌一域（赐福/救苦/阴阳/雷霆） |

## 三、各尊神详述
### 三清（见专篇）
- 元始天尊（玉清境清微天）：道之始——"生于太无之先，禀自然之气"；
- 灵宝天尊（上清境禹余天）：道之枢；
- 道德天尊（太清境大赤天，太上老君）：道之成——传道授业，老子化身。

### 四御（见[道教神佛/道教神谱详录]）
- 玉皇大帝：万天帝主（总执天道）；
- 中天紫微北极大帝：万星帝主；
- 勾陈上宫天皇大帝：万雷帝主；
- 承天效法后土皇地祇：万地帝主。

### 五方五老
| 五老 | 全称 | 职 |
|---|---|---|
| 东方青帝 | 青灵始老九炁天君 | 木、春 |
| 南方赤帝 | 丹灵真老三炁天君 | 火、夏 |
| 中央黄帝 | 玄灵黄老一炁天君 | 土、长夏 |
| 西方白帝 | 皓灵皇老七炁天君 | 金、秋 |
| 北方黑帝 | 五灵玄老五炁天君 | 水、冬 |

（早期帝王祭五方上帝；与四象星宿亦有对应）

### 太乙救苦天尊（东极青华大帝）
- 东方长乐世界大慈仁者；"寻声救苦"——念名号即随声应化；
- 黄箓超度主神（破狱拔度、水火交炼亡魂）；骑九头狮子（西游记九灵元圣）；
- 九天尊之首（太乙救苦/十方救苦/九幽拔罪/朱陵度命/火炼丹界/法桥大度/金阙化身/逍遥快乐/宝华圆满）。

### 东王公与西王母（阴阳二气之父母）
- 东王公（东华帝君/扶桑大帝）：男仙领袖——升仙者先拜东王公；
- 西王母（王母娘娘）：女仙之宗——后拜西王母（见[人物/西王母]）；
- 共理阴阳二气、育养天地、陶钧万物。

### 三官大帝（见[地祇/三官大帝与三元节]）
天官赐福（上元）、地官赦罪（中元）、水官解厄（下元）——源于上古祭天地水，东汉张陵天师道"三官手书"之始。

### 雷祖（九天应元雷声普化天尊）
居神霄玉清府，雷部最高神——主发生万物、录善罚恶（见[道教神佛/雷部]、[道教神佛/道教神谱详录]雷部谱系）。

## 四、先天尊神与洪荒流
- 洪荒流中"先天神圣/先天魔神"概念源自先天尊神体系：盘古、女娲、三清、鸿钧等为"开天前即有"的先天存在（与后天修炼者区分，见[境界/境界详解]"先天vs后天"）。
- 先天尊神的"道气所化"设定→洪荒流"大道法则化身"（三千大道，见[宇宙/三千大道]）。
- 四御/五方五老/十方天尊等为[天神谱]天庭体系顶层官僚。
