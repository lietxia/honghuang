# 冥府

道教地府体系，掌死后审判、轮回、幽冥秩序。

## 一、最高神
**酆都大帝（北阴酆都大帝）** — 地府冥界最高神灵，居罗酆山（酆都），统辖幽冥万鬼、十殿审判。

## 二、五方鬼帝
东方鬼帝、西方鬼帝、北方鬼帝、南方鬼帝、中央鬼帝，分镇五方幽境。

## 三、十殿阎王（十殿阎君）
| 殿 | 阎王 | 职掌 |
|---|---|---|
| 第一殿 | 秦广王 | 初审善恶 |
| 第二殿 | 楚江王 | 寒冰地狱 |
| 第三殿 | 宋帝王 | 黑绳地狱 |
| 第四殿 | 仵官王 | 血池地狱 |
| 第五殿 | 阎罗王（森罗王） | 叫唤地狱，最知名 |
| 第六殿 | 卞城王 | 大叫唤地狱 |
| 第七殿 | 泰山王 | 焦热地狱 |
| 第八殿 | 都市王 | 大焦热地狱 |
| 第九殿 | 平等王 | 阿鼻地狱 |
| 第十殿 | 转轮王 | 核定轮回、发往六道 |

## 四、判官
酆都审判官，录善恶、定刑期（著名崔珏）。

## 五、勾魂使者
- **牛头、马面**：拘魂押送
- **白无常（谢必安）、黑无常（范无救）**：专捉恶鬼，民间称"七爷八爷"

## 六、孟婆
常驻奈何桥边，以"忘魂汤"使转世鬼魂忘却前世与地狱一切。

## 七、与后土/平心的关系
后土化六道轮回、称平心娘娘（见幽冥篇），是轮回机制的开创者；道教酆都体系是轮回之下的行政审判机构，二者互补。
