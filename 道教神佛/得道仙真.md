# 得道仙真

由凡人修道成真、或受敕封的道教仙真与俗神。

## 一、八仙（道教民间最著名）
| 仙 | 法物 | 特色 |
|---|---|---|
| 铁拐李 | 葫芦、铁拐 | 八仙之首，跛足 |
| 汉钟离 | 芭蕉扇 | 原汉将，坦腹 |
| 张果老 | 渔鼓、毛驴 | 倒骑驴 |
| 何仙姑 | 荷花 | 唯一女仙 |
| 蓝采和 | 花篮 | 少年仙童 |
| 吕洞宾 | 纯阳剑 | 剑仙，全真北五祖之一 |
| 韩湘子 | 笛 | 韩愈侄孙 |
| 曹国舅 | 玉板 | 皇亲 |

## 二、妈祖（天上圣母）
原名林默，福建湄洲人，海上保护神，历代敕封至"天后"。台湾、东南沿海香火极盛。

## 三、关圣帝君（关羽）
忠义神武，伏魔大帝，武财神。佛道儒三教共尊。

## 四、吕祖（吕洞宾）
纯阳真人，全真道尊为北五祖之一，剑仙代表，度人之师。

## 五、九天玄女
兵法、术数、符箓之祖，授黄帝兵符破蚩尤，亦为房中、丹道之神。

## 六、其他仙真 / 俗神
- 骊山老母：女仙长老，授徒传艺
- 百花仙子：掌百花
- 临水夫人（陈靖姑）：护妇幼、催生
- 三茅真君：茅山祖师
- 黄大仙：华南、港澳香火
- 慈航真人：即观音菩萨道教化身
- 保生大帝、开漳圣王、三山国王、清水祖师、五府千岁等各地乡土神
