# 道教神谱详录（先天尊神·四御六御·五方五老·十方天尊）

道教神仙体系的完整谱系——从三清到十方天尊，从先天尊神到得道仙真。来源：道教文化中心资料库、维基百科（四御）、武当山道教协会、道教研习资料。

## 一、先天尊神（大道道气所化的自然之神）
"先天尊神"指各类大道、道气所化的自然之神——三清、玉皇、四御、五方五老、扶桑大帝（东王公）、西王母、三官、青华帝君（太乙救苦天尊）等（《度人经》）。

### 三清（道教最高尊神）
| 尊神 | 居所 | 象征 |
|---|---|---|
| **元始天尊**（玉清） | 清微天玉清境 | 道之始，生于太无之先 |
| **灵宝天尊**（上清） | 禹余天上清境 | 道之枢，开天立极 |
| **道德天尊**（太清，太上老君） | 大赤天太清境 | 道之成，传道授业（《道德经》） |

### 四御（辅佐三清的四位尊神）
四御为三清之下主宰天地万物的四位尊神（道教文化中心资料库/《崆峒问答》）：
| 尊神 | 职掌 |
|---|---|
| **玉皇大帝** | 万天帝主（总执天道，三清之下、众神之上） |
| **中天紫微北极大帝** | 万星帝主——掌天经地纬、日月星辰、四时气候（"万星之宗主，三界之亚君"） |
| **勾陈上宫天皇大帝** | 万雷帝主——掌南北极与天地人三才，主持人间兵革 |
| **承天效法后土皇地祇** | 万地帝主——掌阴阳生育、万物之美、大地山河（后土，唐前男像、唐后女像） |

> 宋代后玉帝地位提升出"四御"，另以四极大帝充数：北紫微、南长生、太极天皇、东青华；后世又恢复古说。另有"六御"说（加玉皇大帝、太乙救苦天尊）。

### 四极大帝（宋代四御变体）
- 北极紫微大帝：总御万星；
- 南极长生大帝（玉清真王）：总御万灵、主寿夭（执掌雷霆权柄）；
- 太极天皇大帝：总御万神；
- 东极青华大帝（太乙救苦天尊）：总御万类、主救度众生。

## 二、重要的先天尊神

### 太乙救苦天尊（东极青华大帝）
- 又称太一救苦天尊、寻声救苦天尊、十方救苦天尊——天庭东方长乐世界的大慈仁者。
- 职能：至圣至仁、接引浮生——念其名号即随声应化、解忧排难、化凶为吉；黄箓超度道场主神，主持"水火交炼亡魂、清荡血湖地狱、破狱拔度罪魂"。
- 形象：天尊骑狮子（九头狮子，西游记九灵元圣即其坐骑）。
- 神诞：十一月初一。

### 西王母与东王公（女仙之首/男仙之首）
- 西王母（王母娘娘）：女仙之宗，瑶池蟠桃（见[人物/西王母]）；
- 东王公（东华帝君/扶桑大帝）：男仙领袖（见[地仙谱]）。
- 凡升仙者先拜东王公、后拜西王母；二神共理阴阳二气、育养天地、陶钧万物。

### 五方五老（三清之前地位最高的古神）
三清未成主流前地位最高的五位神仙（历代帝王祭祀对象）：
| 五老 | 全称 |
|---|---|
| 东方青帝 | 东方青帝青灵始老九炁天君 |
| 南方赤帝 | 南方赤帝丹灵真老三炁天君 |
| 中央黄帝 | 中央黄帝玄灵黄老一炁天君 |
| 西方白帝 | 西方白帝皓灵皇老七炁天君 |
| 北方黑帝 | 北方黑帝五灵玄老五炁天君 |

### 三官大帝（天官/地官/水官）
见[地祇/三官大帝与三元节]——天官赐福（紫微大帝）、地官赦罪（清虚大帝）、水官解厄（洞阴大帝），正月十五/七月十五/十月十五三官诞。

### 雷祖（九天应元雷声普化天尊）
- 居神霄玉清府，雷部最高神，主发生万物、录善罚恶（见[道教神佛/雷部]）。
- 五方雷王：东方神运雷王严阜、南方神化雷王卓滨、西方神威雷王高辉、北方动伟雷王吴希、中央动捷雷王赵坚；
- 五方雷帝：东方轰天震门雷帝、南方赤天火光震煞雷帝、西方大暗坤伏雷帝、北方倒天翻海雷帝、中央黄天崩烈雷帝；
- 五雷部署：天雷、地雷、水雷、神雷、社雷。

## 三、十方天尊与斗部诸神

### 十方天尊
东方玉宝皇上天尊、南方玄真万福天尊、西方太妙至极天尊、北方玄上玉宸天尊、东北方度仙上圣天尊、东南方好生度命天尊、西南方太灵虚皇天尊、西北方无量太华天尊、上方玉虚明皇天尊、下方真皇洞神天尊。

### 六司七元（南斗北斗）
- **六司**（南斗六星）：司命、司禄、延寿、益算、度厄、上生星君（见[地祇/星辰之神与命运神]）。
- **七元**（北斗七星）：天枢阳贪狼、天璇阴精巨门、天玑真人禄存、天权玄明文曲、玉衡丹元廉贞、开阳北极武曲、瑶光天冲破军星君。

### 九曜星官
计都、火德、木德、太阴、土德、罗睺、太阳、金德、水德九星君（罗睺计都为"蚀星"，与[佛教/罗汉与天龙八部]毗邻）。

### 斗姆元君与六十甲子神
- 斗姆（斗姥）：北斗众星之母，掌斗部（见[人物/金灵圣母]斗母之说）；
- 六十甲子神（六十元辰/太岁）：六十位大将军轮流值年（见[地祇/星辰之神与命运神]）。

## 四、护法与仙真
- **护法太保**：托塔李天王（李靖）、中坛元帅（哪吒）、二郎真君（杨戬）、驱魔真君钟馗、关圣帝君、四大元帅（马赵温关/马赵温周）、王灵官、五营神将、法主公。
- **得道仙真**：观音（道教称慈航真人）、八仙（纯阳祖师吕洞宾）、妈祖（天上圣母）、关帝、吕祖、王灵官、临水夫人（陈靖姑）、三茅真君、保生大帝、开漳圣王、三山国王、黄大仙。

## 五、道教神谱架构图
```
大道 → 三清（元始/灵宝/道德）
     → 四御（玉皇/紫微/勾陈/后土）〔或六御+长生+太乙救苦〕
     → 五方五老、三官大帝、雷祖、东王公西王母、太乙救苦天尊（先天尊神层）
     → 星君（北斗南斗九曜二十八宿）、山川河海神（五岳四渎龙王）、冥府神（酆都十殿）
     → 得道仙真（八仙/妈祖/关帝等）、护法神将（四大元帅/王灵官）、民间俗神
```
