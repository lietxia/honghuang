# 护法神将（道教护法体系详录）

道教护法、降魔、驱邪的神将体系——从北极四圣到四大元帅、王灵官、六丁六甲、四值功曹，构成道教"武力"班底。来源：武当山道教协会、道教文化中心资料库。

## 一、北极四圣（北方荡魔）
镇守北方、荡除邪魔的四位天君：
| 圣号 | 说明 |
|---|---|
| **天蓬大元帅真君** | 四圣之首，掌天罡三十六将；"天蓬神咒"（北帝煞鬼咒）护身 |
| **天猷副元帅真君** | 辅天蓬元帅 |
| **翊圣保德储庆真君** | 护驾、导从（保德真君） |
| **真武灵应佑圣真君（真武大帝）** | 披发仗剑、足踏龟蛇，镇北方、主水火、荡魔（见[人物/真武大帝]） |

## 二、四大元帅
| 元帅 | 俗称 | 说明 |
|---|---|---|
| **马元帅** | 马天君/华光天王/华光大帝 | 三只眼，火神（南方火之精）；南游记主角（见[参考/四游记与神魔小说]） |
| **赵元帅** | 赵公明/玄坛真君 | 武财神，黑面持鞭（见[人物/赵公明]） |
| **温元帅** | 温琼 | 东岳大帝部将，青面獠牙 |
| **关元帅** | 关羽/关圣帝君 | 忠义神武，伏魔大帝（见[人神谱]） |

## 三、王灵官（道教第一护法）
- 即玉枢火府天将、隆恩真君——额上**火眼金睛**、手持金鞭，护镇山门、辨识真伪。
- 道观山门第一殿镇殿神（"三眼灵官"）——"上山不上山，先拜灵官殿"；
- 与[人物/孙悟空]之"火眼金睛"设定有关（道教护法火眼）。

## 四、三十六天将 / 七十二地煞
- **三十六天将**：天庭三十六员武将（版本众多，含殷郊、关羽、马胜、温琼、王善、赵公明、康应、朱彦夫等）——常与二十八宿联合降妖；
- **七十二地煞**：主变化、布阵（见[神通/天罡地煞详解]）；
- 封神斗部：天罡星三十六位+地煞星七十二位（见[大事件/封神榜三百六十五位正神]）。

## 五、六丁六甲（守护传递之神）
| 六丁（阴神玉女） | 六甲（阳神玉男） |
|---|---|
| 丁卯司马卿、丁巳崔巨卿、丁未石叔通 | 甲子王文卿、甲戌展子江、甲申扈文长 |
| 丁酉臧文公、丁亥张文通、丁丑赵子玉 | 甲午卫玉卿、甲辰孟非卿、甲寅神明文章 |

- 道教科仪"六甲秘祝"即召六丁六甲神将护身遣用（见[道教神佛/道教经典与传统历法]护身咒语）。

## 六、四值功曹
天庭值班神：值年神（李丙）、值月神（黄承乙）、值日神（周登）、值时神（刘洪）——记录人神功绩、传递表文（斋醮"上表"由功曹转呈）。

## 七、其他护法
- **雷部五元帅**：邓元帅（邓忠）、毕元帅、刘天君（刘甫）、辛元帅（辛环）、庞元帅（见[道教神佛/雷部]）；
- **哼哈二将**：郑伦（哼）、陈奇（哈）——佛教金刚/密迹金刚（封神榜受封，见[大事件/封神榜三百六十五位正神]）；
- **千里眼、顺风耳**：高明、高觉（封神）——天庭耳目神；
- **五营神将**（台湾）：东营张、南营萧、西营刘、北营连、中营李——地方护法军阵。

## 八、护法神将体系与洪荒流
- 护法神将为天庭武力班底（[天神谱]军部）；四大元帅（马赵温关）与[人物/魔家四将]（佛教四大天王）构成佛道护法双轨；
- 王灵官、天蓬等为道教实战护法——洪荒流"雷部天将/护法神将"设定原型。
