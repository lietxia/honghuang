# 护法神将

道教护法、降魔、驱邪的神将体系。

## 一、北极四圣
镇守北方、荡除邪魔的四位天君：
| 圣号 | 说明 |
|---|---|
| 天蓬大元帅真君 | 四圣之首，掌天罡三十六将 |
| 天猷副元帅真君 | 辅天蓬 |
| 翊圣保德储庆真君 | 护驾、导从 |
| 真武灵应佑圣真君（真武大帝） | 北极端坐、披发仗剑、踩龟蛇，镇北方、主水火、荡魔 |

## 二、四大元帅
| 元帅 | 俗称 | 说明 |

| 马元帅 | 马天君 / 华光天王 / 华光大帝 | 三只眼，火神，南方火之精 |
| 赵元帅 | 赵公明 / 玄坛真君 | 武财神，黑面持鞭 |
| 温元帅 | 温琼 | 东岳大帝部将，青面 |
| 关元帅 | 关羽 / 关圣帝君 | 忠义神武，伏魔 |

## 三、王灵官
即玉枢火府天将、隆恩真君，额有火眼金睛、手持金鞭，护镇山门、辨识真伪，为道教第一护法。

## 四、三十六天将 / 七十二地煞
常与二十八宿联合降妖。三十六天将含殷郊、关羽、马胜、温琼、王善、赵公明等（版本众多）；七十二地煞主变化、布阵。

## 五、六丁六甲
道教守护、传递之神：
- **六丁（阴神玉女）**：丁卯司马卿、丁巳崔巨卿、丁未石叔通、丁酉臧文公、丁亥张文通、丁丑赵子玉
- **六甲（阳神玉男）**：甲子王文卿、甲戌展子江、甲申扈文长、甲午卫玉卿、甲辰孟非卿、甲寅神明文章

## 六、四值功曹
天庭值班神，记录人神功绩兼守护：值年神李丙、值月神黄承乙、值日神周登、值时神刘洪。
