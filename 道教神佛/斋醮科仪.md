# 斋醮科仪（道教法事体系）

斋醮科仪是道教法事活动的总称，俗称"道场""法事"——通过设坛摆供、焚香化符、念咒上章、诵经赞颂，配以烛灯罡步和音乐，祭告神灵、祈求消灾赐福。斋法内持、醮法外显。来源：中国道教协会、武当山道教协会、茅山道院《斋醮科仪概况》。

## 一、源流
- 古已有之：东汉以前即有"斋戒""醮""坛"之说（《礼记》《易经》《高唐赋》《史记》）——道教斋醮源于中国古代祈祷仪式。
- 东汉：太平道有向天祈祷仪式；五斗米道有"涂炭斋"（黄土涂面、反缚悬头）和"三官手书"（书病人姓名罪状，一通上山、一通埋地、一通沉水，是科仪表章雏形）；张道陵传《天宫章本》为最早科仪书。
- 东晋南北朝：上清派、灵宝派推演成整套科教仪范（茅山"上清法坛"、阁皂山"灵宝玄坛"）；北魏寇谦之改"直诵"为"音诵"，诵经始有音乐。
- 唐宋：唐玄宗亲教道士步虚声韵；唐末五代**杜光庭**为斋醮科仪集大成者（编订《道门科范大全集》等）；宋真宗/徽宗颁科仪于天下。
- 金元：茅山、龙虎山、阁皂山诸名山为国设醮；丘处机、王处一主醮事。
- 明清至今：科仪广泛流传民间（清娄近垣整编《黄箓科仪》12卷）。

## 二、醮坛（法坛）
- **醮坛**：建醮必先设坛——"坛"为平坦土地上的高台，祭天神和祖先（《道书授神契》："古醮坛在野，今于屋下，从简"）。
- 大型斋醮设若干坛：主坛为**都坛**，其余为分坛。
- 经典范例：1993年北京白云观**罗天大醮**——供奉一千二百诸神牌位，设都坛、皇坛、度人坛、三官坛、报恩坛、救苦坛、济幽坛、青玄坛，诵经拜忏、日夜香灯。
- 各派醮坛：全真派"混元宗坛"（用"道经师宝"印）、方丈传戒坛"玄都律坛"；正一派"万法宗坛"（用天师"阳平治都功"印）。

## 三、醮坛执事（法事人员）
| 执事 | 职守 |
|---|---|
| **高功** | 各执事之首——"道德内充，威仪外备，天人归向，鬼神具瞻"；蹑景飞晨、承颜宣德、惠周三界 |
| **监斋** | 位次高功——总握宪章、典领科禁、纠正坛职、振肃朝纲（高功副手） |
| **都讲** | 与高功、监斋合称"三法师"——主管唱赞导引、升座讲说 |
| 其他 | 炼师、摄科、正仪、监坛等（《太清玉册》） |

## 四、醮坛陈设与法器
- **供器**：香炉、烛台、花瓶、香筒。
- **供养**：香、花、灯、水、果（五供养）。
- **法器**（镇邪驱恶类）：朝简（圭简）、如意、玉册、玉印、宝剑（法剑）、令旗、令箭、令牌（召遣神将之牌）、天蓬尺（桃木法尺）、镇坛木等。
- **乐器类**：铙、铛、镲、铃、鼓、钟、螺、磬。
- 幢幡、符简（黄表纸符）、章表（表文）、法水（净坛用水）、手炉。

## 五、科仪运作（咒诀罡步）
外在形式 + 内在修功结合：

| 仪元 | 说明 |
|---|---|
| **咒** | 通于神灵之语（"咒"通"祝"），以"急急如律令"结尾；请神、驱邪、保命、护身 |
| **诀（掐诀）** | 手指按法盘结捏掐成形状——通真制邪、役将治事；不同神明不同诀（灵官诀、斗姆诀等） |
| **步（踏罡步斗）** | 相传创自夏禹，故称"禹步"——"罡"指天罡、"斗"指北斗；高功在方丈之地假为九重天，按星辰斗宿方位踏步，神驰九霄、启奏上天；罡有三宝罡、二十八宿罡、交泰罡等 |
| **灯** | 上照天庭、下彻地狱、拔度亡灵（"法天象地，燃灯告符"） |
| **礼拜** | 叩头作揖——入道首学"过叩头关"；稽首、作礼、遵作、心礼 |
| **诵经** | 心诵、形诵、神诵、心祝、密祝、微祝；一人独诵或众人合诵；上消天灾、下禳毒害 |
| **步虚（步虚声）** | 讽诵词章的曲调行腔，如众仙步行虚空——";步虚词"；杜甫赞"此曲本应天上有" |
| **存想（存思）** | 闭目内观事物/神真形貌——建醮不存想无法沟通人神；对象：天象（日月星辰）、景物（气/炎火）、人体（五脏丹田）、神真（身内/身外神），多师徒秘传 |
| **叩齿** | 上下齿相叩以集神驱邪——鸣天鼓（左叩）、击天磬（右叩）、鸣法鼓（当门齿相叩） |
| **进表（上表）** | 道士将表文（青词表章）上奏天庭——启坛、请圣、拜表；最高神呈进称"上大表"、一般神称"上疏"；焚表为"化表" |

## 六、主要斋醮类型
- **金箓斋/金箓道场**：帝王设醮祈福（唐武宗三清殿修金箓道场）。
- **黄箓斋/黄箓道场**：超度亡魂（太乙救苦天尊为主神，水火交炼亡魂、破狱拔度）。
- **罗天大醮**：规格最高的斋醮（如1993白云观，1200神位）。
- 普天大醮（帝王专属最高规格）、周天大醮。
- 常见法事：祈福消灾、求雨（祈雨醮）、度亡（超度）、安宅镇煞、开光、还愿。

## 七、斋醮与洪荒流
- 斋醮科仪是洪荒流"道门法术"的现实原型：掐诀念咒（斗姆诀/灵官诀）、踏罡步斗（禹步）、符箓表文（青词）、召请神将（令牌/令旗）——都是洪荒流斗法桥段的道教实学来源。
- 罗天大醮常为洪荒流"圣人讲道/祭天"场景取材；"三官手书"与[地祇/三官大帝与三元节]呼应。
