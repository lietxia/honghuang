# 四灵与神鸟

## 一、四灵（四方守护神兽）
| 灵 | 方位 | 形象 | 五行 |
|---|---|---|---|
| 青龙（苍龙） | 东 | 龙 | 木 |
| 白虎 | 西 | 虎 | 金 |
| 朱雀 | 南 | 火凤 | 火 |
| 玄武 | 北 | 龟蛇合体 | 水 |

四灵镇四方，常见于墓葬、建筑、军旗。玄武主北方、主水、主冥，后为真武大帝之象。

## 二、凤凰与神鸟
| 神鸟 | 说明 |
|---|---|
| 凤凰 | 百鸟之王，雄为凤、雌为凰，五采备举，非梧桐不栖；见则天下安宁 |
| 朱雀 | 四灵之南方神鸟，与凤凰同源异流，主火、主夏 |
| 毕方 | 一足之鸟，形如鹤，青身赤纹白喙，见则有怪火；黄帝战蚩尤时曾现身 |
| 精卫 | 炎帝少女女娃溺于东海所化，衔石填海（见神话典故篇） |
| 青鸟 | 西王母信使，三足，传信神鸟 |
| 三青鸟 | 为西王母取食，居三危山 |
| 重明鸟 | 双瞳如鸡，驱邪神鸟（见神兽图谱） |

## 三、太阳神鸟
- **三足金乌**：日中神禽，帝俊羲和所生"十日"之灵，后羿射日陨其九
- **金乌负日**：古人以金乌载日而行天
