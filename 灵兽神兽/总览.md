# 灵兽神兽总览

祥瑞、护佑、通灵的上古神兽与神物，与"凶兽"相对。来源：《山海经》、百度百科、知乎神兽榜、《神异经》。

## 神兽等级简表
```
祥瑞至上：麒麟、凤凰、白泽、龙
护法神兽：青龙、白虎、朱雀、玄武（四灵）
通灵瑞兽：貔貅、獬豸、重明鸟、九尾狐、三足金乌
战兽/祖兽：应龙、烛龙（烛照）、祖龙、元凤、始麒麟
```

## 一、祥瑞神兽

中华神兽文化源远流长，以《山海经》《神异经》等古籍为渊薮。居于神兽谱系顶端的，是象征吉祥、太平、仁德的祥瑞之兽。**麒麟**含仁怀义，出没则天下安宁；**凤凰**五采备举，见则祥和；**白泽**通晓万物之情，能言人语，传说黄帝曾得其图而识天下精怪；**龙**则为鳞虫之长，变幻莫测。这些神兽往往与圣王、贤君、盛世相系，是政治与道德理想的隐喻。

## 二、护法四灵

**四灵**（青龙、白虎、朱雀、玄武）镇守东西南北四方，源自古人观察星象、以二十八宿连缀想象而成的"天之四灵，以正四方"。四灵各配五行、四季与方位，常见于墓葬壁画、建筑装饰与军旗之上，兼具天文、地理、风水、护法的多重意义，是中国古代宇宙观的形象化表达。

## 三、通灵瑞兽

此外尚有众多通灵护宅的瑞兽。**貔貅**只进不出，主招财纳福；**獬豸**能辨曲直，主司法公正；**重明鸟**双瞳如鸡，可驱邪辟恶；**九尾狐**在先秦本为祥瑞，后世才演为魅惑之象；**三足金乌**则为太阳神鸟。它们或镇宅、或护法、或纳福，深入民间信仰与日常器物。

## 四、战兽祖兽

在洪荒流设定中，另有一类神通盖世的始祖级战兽：**应龙**有翼善战，助黄帝、大禹；**烛龙（烛照）**视为昼、瞑为夜，吹为冬、呼为夏，乃创世级古神；**祖龙、元凤、始麒麟**更是一族之祖，曾于龙汉初劫中争霸洪荒。灵兽神兽之谱，由祥瑞而护法、由通灵而祖兽，层层递进，构成中华神话中瑰丽奇幻的生灵图景。

> 神兽之谱，由祥瑞而护法、由通灵而祖兽，蔚为大观。
