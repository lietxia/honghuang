# 神兽图谱

## 一、顶级祥瑞
| 神兽 | 形象 | 寓意/出处 |
|---|---|---|
| 麒麟 | 麏身、牛尾、狼蹄、独角，全身鳞甲 | 仁兽，麒麟出没必有祥瑞；始麒麟为洪荒先天祖兽 |
| 凤凰 | 鸡头、燕颔、蛇颈、鱼尾，五色 | 百鸟之王，祥瑞；元凤为洪荒先天祖兽 |
| 白泽 | 狮身、独角、虎眼，通人语 | 知天下万物之情，能言人语、驱邪；黄帝巡至东海得之 |
| 龙 | 九似之形（驼头、鹿角、兔眼、牛耳、蛇项、鲤鳞、鹰爪、虎掌、鱼尾） | 鳞虫之长，能幽能明、能细能巨；祖龙为洪荒先天祖兽 |
| 貔貅 | 龙头、马身、麟脚，形似狮子，无肛门 | 招财纳福、只进不出；天禄、辟邪为其二名 |

## 二、通灵瑞兽
| 神兽 | 说明 |
|---|---|
| 獬豸（xiè zhì） | 独角神羊，能辨曲直，触奸邪；司法公正之象征 |
| 九尾狐 | 青丘之兽，音如婴儿，食人亦祥瑞（太平则现）；封神中为妲己所化 |
| 三足金乌 | 日中之灵，帝俊羲和所生十日之精 |
| 重明鸟 | 状如鸡，鸣如凤，一目双瞳，能驱猛兽妖邪 |
| 乘黄 / 腾黄 | 神马，骑之寿二千岁 |
| 当康 | 形如豚而有牙，鸣叫自呼其名，兆丰年 |
| 英招 | 马身人面、虎纹鸟翼，槐江山神，帝俊下属 |

## 三、知名神兽
| 神兽 | 出处/说明 |
|---|---|
| 应龙 | 有翼之龙，黄帝战蚩尤时蓄水、杀蚩尤夸父；助大禹治水以尾画地 |
| 烛龙（烛阴） | 钟山之神，人面蛇身，赤色，睁眼为昼闭眼为夜，吹为冬呼为夏 |
| 夔（kuí） | 单足怪兽，黄帝以其皮为鼓、骨为槌，声闻五百里 |
| 犼（hǒu） | 似犬，食龙脑，形如马而有鳞，上古极强之兽 |
| 诸犍 / 蛊雕 / 蠃鱼 | 见凶兽篇对照 |
| 甪端（lù duān） | 形似犀牛，独角，日行一万八千里，通晓四方语言 |
| 鲲鹏 | 北冥之鲲化而为鹏，怒而飞其翼若垂天之云（见先天三族篇） |
