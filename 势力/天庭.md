# 天庭（封神后天庭）

封神大战后，昊天上帝（玉皇大帝）借封神榜重整天庭，麾下八部三百六十五位正神分掌三界。此天庭与巫妖时期的妖庭不同，是三教共立、统辖神道的行政中枢。

| 尊号 | 人物 | 说明 |

| 昊天上帝 / 玉皇大帝 | 昊天 | 万天之主、众神之皇，总执天道（宋真宗加封"太上开天执符御历含真体道昊天玉皇上帝"） |
| 瑶池金母 / 王母娘娘 | 西王母 | 女仙之首，掌蟠桃园、瑶池 |

## 三、八部正神（详见天神谱）
- **雷部**：九天应元雷神普化天尊 闻仲 + 二十四天君
- **火部**：南方三气火德星君 罗宣 + 五正神
- **瘟部**：瘟㾮昊天大帝 吕岳 + 六神
- **斗部**：坎宫斗母 金灵圣母 + 五斗群星
- **太岁部**：殷郊、杨任 + 日直众星
- **水部**：北斗五气水德星君 鲁雄 + 四神
- **财部**：玄坛真君 赵公明 + 四财神
- **痘部**：主痘碧霞天君 余化龙 + 五痘神

## 四、天庭建筑（据《西游记》《封神》传说）
- 三十六天宫、七十二宝殿
- 南天门（四大天王守）、接引殿、朝会殿、**凌霄宝殿**（玉帝朝臣）、通明殿、兜率宫（太上老君，悬离恨天）

## 五、天庭与道教的关系
天庭是三界神道行政机构；道教神仙（三清、四御）位在天庭之上，玉帝亦需礼敬三清。民间常将二者混同，但体系上"道"高于"天庭"。
