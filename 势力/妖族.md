# 妖族（广义·散妖体系）

巫妖大战后，妖庭崩溃——妖族不再有统一的"天庭"，而是分散为各方妖王、精怪、洞府妖仙。封神与西游时期，妖族多归附截教或为祸人间。"妖"是中国神话体系中最庞大的非人智慧种族——从先天大妖（帝俊/太一/鲲鹏）到草木禽兽修炼成精（狐/蛇/树精）。来源：洪荒流设定、《西游记》《封神演义》、[人物/妖族天庭]。

## 一、妖族源流
| 类别 | 代表 |
|---|---|
| **先天妖族** | 帝俊、太一、鲲鹏、凤凰、麒麟等混沌/先天生灵（[人物/妖族天庭]、[先天三族/凤族]） |
| **后天妖族** | 禽兽草木修炼成形（狐、蛇、虎、树精等——"妖修"主流） |
| **混血/半妖** | 梅山七怪（猿、猪、牛等——[人物/梅山七怪]） |

## 三、妖族与教派
- **截教"有教无类"**：多收妖族为徒（羽翼仙大鹏、乌云仙金须鳌鱼——[人物/截教群仙]）——封神截教万仙来朝多妖仙；
- **阐教视妖族为异类**：多斩杀（"炼气士正统"vs"披毛戴角湿生卵化"）；
- **西方教以度化妖族扩充教众**：孔雀明王（孔宣）、大鹏、虬首仙/灵牙仙/金光仙（坐骑三仙——[人物/赤精子与清虚道德真君]）——"渡妖入佛"。

## 四、妖族修行特点
| 特点 | 说明 |
|---|---|
| 重肉身/血脉/妖丹 | 妖修体系（[功法/妖修巫修散修]）——凝妖丹、血脉神通 |
| 化形劫 | 妖化人形需渡天劫（雷劫是妖族晋升大关卡——"化形雷劫"） |
| 借法宝阵法补短 | 妖多借法宝阵法补元神短板（周天星斗大阵——妖庭镇族大阵） |
| 吞噬修炼 | 吞日月精华/精气（妖丹吞元法——[功法/功法总览]） |

## 五、妖族结局
- 封神后：天庭八部亦有妖族正神（马元帅华光、二十八宿部分——奎木狼等星君本属妖族星宿）——"妖入神职"；
- 西游时期：妖族多被收服或镇压——残余散于四方洞天（"有后台的收了、没后台的打死"——[人物/西游记妖怪全录]）；
- 妖族地位演变：先天大妖（混沌巨头）→妖庭时代（天地主角之一）→巫妖大劫后衰落（散妖时代）→封神/西游被收编——妖族的气运曲线是洪荒史主线之一（[概念/气运功德香火业力]）。
