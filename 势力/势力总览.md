# 势力总览（洪荒势力版图）

洪荒世界的主要势力图谱——从至高道祖到天地主角，各路势力分分合合，构成洪荒史的主线。每个势力都有独立专篇详述。

## 〇、势力层级总览
```
创始元灵 → 鸿钧（道祖·合道）
   ├─ 道门三清（人教/阐教/截教）
   ├─ 西方教 → 佛教（接引/准提 → 如来）
   ├─ 妖族天庭（帝俊/太一 → 天庭）
   ├─ 巫族（十二祖巫）
   ├─ 人族（女娲造人/火云洞三皇）
   ├─ 幽冥（冥河血海/后土轮回）
   └─ 散修（镇元子/陆压/菩提祖师等）
```

## 一、至高势力

### 鸿钧老祖（道祖）
- 紫霄宫讲道三千客，分六圣位（六道鸿蒙紫气）；
- 以身合天道——"鸿钧即天道，天道不是鸿钧"（合道后超脱众生）；
- 见[人物/鸿钧老祖]、[大事件/鸿钧紫霄宫讲道]。

### 创始元灵一脉
- 创始元灵四大弟子：鸿钧（玄清气）、混鲲祖师（玄灵气，妖教）、女娲（玄空气）、陆压（玄明气）——超脱宇宙的存在（见[创始元灵/创始元灵与四大弟子]）。

## 二、道门（三清）
| 教主 | 道场 | 教派 | 教义 |
|---|---|---|---|
| **太上老君**（太清） | 三十三天兜率宫/首阳山八景宫 | 人教 | 清静无为、炼丹长生（太上道经/金丹大道） |
| **元始天尊**（玉清） | 昆仑山玉虚宫 | 阐教 | 顺天而行、练就法力（玉虚道经/护道降魔）——十二金仙 |
| **通天教主**（上清） | 金鳌岛碧游宫 | 截教 | 截取一线天机、有教无类（通天剑道/万仙来朝） |

- 三清同出盘古元神（"一气化三清"）——封神前因教义分歧分家（见[人物/三清]、[教派/阐教与截教]）。

## 三、西方教 → 佛教
| 阶段 | 教主 | 说明 |
|---|---|---|
| 西方教 | 接引道人、准提道人 | 西方贫瘠二圣，发宏愿立教（"西方极乐"） |
| 佛教 | 如来（多宝道人/释迦牟尼） | 封神后西方教演变为佛教，佛门大兴（见[教派/西方教与佛教]） |

- 西方教以"渡人"为业——封神中大量渡走截教门人（孔宣、乌云仙、毗卢仙等，见[人物/西方二圣]）。

## 四、妖族天庭
- **创立者**：帝俊（天帝）、东皇太一（东皇）；妖师鲲鹏辅之；
- **大阵**：周天星斗大阵（河图洛书为基）、混元河洛大阵——妖族镇族大阵（见[阵法/周天与都天神煞]）；
- 妖庭建立于巫妖纪元，统御万妖掌天界；
- **结局**：巫妖大劫（后羿射日/共工触山）两败俱伤——帝俊太一陨落，残部守天庭，妖庭衰败（见[人物/妖族天庭]）。
- 后续：巫妖退场后天庭（昊天上帝/玉帝）重建，妖族分散（[势力/天庭]）。

## 五、巫族
- **始祖**：十二祖巫（盘古十二滴精血所化，掌十二法则）——共工/祝融/后土/帝江/烛九阴等；
- **大阵**：都天神煞大阵（十二祖巫合一召唤盘古真身，圣人级战力）；
- 巫族不修元神、只修肉身——善战好武，掌大地；
- **结局**：巫妖大劫中十二祖巫除后土（化轮回）外全部战死，巫族散落人间（见[人物/十二祖巫]、[势力/巫族]）。

## 六、人族
- **创造者**：女娲（抟土造人，见[人族/起源与女娲造人]）；
- **守护**：火云洞三皇（伏羲/神农/轩辕，人道三圣）；
- **崛起**：巫妖两败俱伤后人族成天地主角；三皇五帝治世（[人族/三皇五帝]）；
- 人族特点：无先天神通，胜在智慧繁衍与气运（见[人族/总览]）。

## 七、幽冥势力
- **幽冥血海**：冥河老祖（元屠阿鼻剑/十二品业火红莲），阿修罗族（见[人物/冥河老祖]、[幽冥/血海冥河]）；
- **六道轮回**：后土娘娘（平心娘娘）以身化轮回（见[人物/后土娘娘]、[幽冥/幽冥体系]）；
- 地府：酆都十殿阎罗（[道教神佛/冥府]）；
- 幽冥独立于天庭体系，为亡魂归处。

## 八、散修与隐仙
- **镇元子**（地仙之祖，五庄观人参果）、**陆压道君**（神秘散仙，斩仙飞刀/钉头七箭书）、**菩提祖师**（悟空之师，佛道之谜）、**冥河/鲲鹏**（妖师）等——超然世外的顶尖散修（见[人物/镇元子与红云]、[人物/陆压道君]、[人物/菩提祖师]）。

## 九、势力演变主线（洪荒简史）
1. **龙汉初劫**：龙/凤/麒麟三族（[教派/先天三族]）衰败 → 鸿钧合道；
2. **巫妖纪元**：妖庭 vs 巫族双雄并立 → 巫妖大劫同归于尽；
3. **人族纪元**：三皇五帝 → 人族主角；
4. **封神纪元**：阐教 vs 截教（商周之战）→ 截教覆灭，天庭充实，西方教东扩；
5. **西游纪元**：佛门大兴，佛道共治（[量劫/西游量劫]）。
