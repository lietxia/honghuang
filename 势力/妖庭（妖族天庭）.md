# 妖庭（妖族天庭）

巫妖大战前由妖族建立的统御洪荒的天庭，与巫族共分天下。大帝俊、东皇太一为首，立天庭于三十三天外（一说三十六天），统御天下妖族。

## 一、最高统治
| 尊号 | 人物 | 说明 |
|---|---|---|
| 妖皇（天帝） | 帝俊 | 先天妖神，与太一同为混沌妖族始祖，执掌妖族天道 |
| 东皇 | 太一 | 帝俊之弟，执掌混沌钟（东皇钟），妖族战力第一 |
| 妖后 | 羲和 | 帝俊之妻，生十日（金乌） |
| 常羲 | 帝俊之妻 | 生十二月（月精） |

## 二、核心高层
- **妖师 鲲鹏**：妖族唯一圣人级战力（准圣），执妖族阵图，掌时空遁法，妖庭军师
- **十大妖帅**（辅佐帝俊）：
  1. 白泽（知万物之名）
  2. 英招
  3. 计蒙
  4. 呲铁
  5. 九婴
  6. 飞诞
  7. 飞鹿
  8. 噬石
  9. 孟极
  10. 陆吾（昆仑守兽）
- **十大金乌**：帝俊羲和所生十日之灵，化为十只三足金乌，行太阳巡天之职（后羿射日陨其九）

## 三、妖族军团
- 天下飞禽以凤凰为长，走兽以麒麟为长，皆归妖庭统辖
- 二十八宿星君早期多为妖族担任（后被天庭接管）
- 周天星斗大阵：帝俊以混沌钟为主阵眼所布，引周天星辰之力，威力堪比圣人

## 四、覆灭
巫妖大战（第三次量劫）中，不周山倒、天柱折，妖庭崩解。太一以混沌钟补天一战陨落，帝俊身死道消，残余妖族散入天下，妖师鲲鹏远遁北海。妖族自此退出统治舞台，残部在封神时期为截教所收。

## 五、与天庭的区别
| | 妖庭 | 天庭 |
|---|---|---|
| 建立者 | 帝俊、太一（妖族） | 昊天上帝（封神后） |
| 时代 | 巫妖时期 | 封神之后 |
| 成员 | 妖族为主 | 人神仙佛混合（八部正神） |
