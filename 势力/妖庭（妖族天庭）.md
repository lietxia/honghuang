# 妖庭（妖族天庭·巫妖纪元）

巫妖大战前由妖族建立的统御洪荒的天庭——与巫族共分天下。帝俊（妖皇/天帝）、东皇太一为首，立天庭掌天界、统御天下妖族。周天星斗大阵（混沌钟镇阵）+十日金乌+十大妖帅——巫妖纪元最强战力集团。巫妖大劫中与巫族同归于尽——妖族自此退出统治舞台。来源：洪荒流设定（《佛本是道》体系）、[人物/妖族天庭]。

## 一、最高统治
| 尊号 | 人物 | 说明 |
|---|---|---|
| **妖皇（天帝）** | 帝俊 | 先天妖神——与太一同为混沌妖族始祖——执掌妖族天道（太阳星金乌） |
| **东皇** | 太一 | 帝俊之弟——执掌混沌钟（东皇钟——开天三宝之一）——妖族战力第一（[法宝/至宝体系]） |
| **妖后** | 羲和 | 帝俊之妻——生十日（十只金乌——太阳） |
| **常羲** | 帝俊之妻 | 生十二月（月精——太阴） |

## 二、核心高层
| 高层 | 说明 |
|---|---|
| **妖师鲲鹏** | 妖族唯一圣人级战力（准圣级）——执妖族阵图、掌时空遁法——妖庭军师（创妖文妖典——[人物/鲲鹏]） |
| **十大妖帅** | 白泽（知万物之名）、英招、计蒙、呲铁、九婴、飞诞、飞鹿、噬石、孟极、陆吾（昆仑守兽）——辅佐帝俊 |
| **十大金乌** | 帝俊羲和所生十日之灵——化十只三足金乌——行太阳巡天之职（后羿射日陨其九——[大事件/后羿射日与夸父逐日]） |

## 三、妖族军团
- 天下飞禽以凤凰为长、走兽以麒麟为长——皆归妖庭统辖（[先天三族/凤族]、[先天三族/麒麟族]呼应）；
- 二十八宿星君早期多为妖族担任（后被天庭接管——奎木狼等星宿本妖族[人物/奎木狼]）；
- **周天星斗大阵**：帝俊以河图洛书+混沌钟为主阵眼所布——引周天星辰之力——威力堪比圣人（[阵法/周天与都天神煞]）。

## 四、覆灭（巫妖大劫）
- 巫妖大战（第三次量劫）中：不周山倒、天柱折——妖庭崩解（[时间线/巫妖大劫]）；
- 太一以混沌钟参战（一说补天）陨落——帝俊身死道消（东皇钟传陆压——[人物/陆压道君]）；
- 残余妖族散入天下——妖师鲲鹏远遁北海（[人物/鲲鹏]）；
- 妖族自此退出统治舞台——残部在封神时期为截教所收（[势力/妖族]）。

## 五、与天庭的区别
| | 妖庭 | 天庭 |
|---|---|---|
| 建立者 | 帝俊、太一（妖族） | 昊天上帝（封神后——[人物/玉皇大帝]） |
| 时代 | 巫妖时期 | 封神之后 |
| 成员 | 妖族为主 | 人神仙佛混合（八部正神——[大事件/封神榜三百六十五位正神]） |
| 阵法 | 周天星斗大阵 | 无顶级镇庭大阵（以神职编制立制） |
| 气运 | 妖族气运（弑杀过重） | 天道正统（三教共立） |
