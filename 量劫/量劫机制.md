# 量劫机制（杀劫·天地大劫详解）

量劫——亦称"杀劫"或"天地大劫"——洪荒流设定的核心概念之一。天地万物顺势而生、因果业力逐步积累——到一定程度后天道自然降下劫数——通过大规模杀戮与毁灭来清算因果、重启轮回。这是洪荒流"天道循环"的宇宙引擎——没有量劫就没有洪荒流的冲突与故事。来源：洪荒流设定（《佛本是道》体系）、[量劫/总览]。

## 一、量劫的成因
| 成因 | 说明 |
|---|---|
| **因果积累** | 修道者逆天而行、以万物为刍狗——每一次杀伐、每一次突破都在积累因果——积累到天道无法承受时量劫降临 |
| **业力沉淀** | 天地间煞气、戾气沉淀——达到临界点即为量劫（"杀伐业力"说——[概念/气运功德香火业力]业力） |
| **天道平衡** | 万物繁衍、强者愈强——天道需要平衡天地气运——量劫即为天道的"重启机制"（气运清算——[概念/气运功德香火业力]） |
| **大道之争** | 不同大道体系（道与魔、仙与妖）之间冲突激化——量劫为其唯一解决方式 |

## 二、量劫的分类
| 类型 | 特点 | 案例 |
|---|---|---|
| **开天量劫** | 盘古开天辟地时斩杀三千混沌魔神——最原始的量劫 | 盘古开天（[大事件/盘古开天与三千魔神之战]） |
| **龙汉初劫** | 先天三族（龙/凤/麒麟）争霸——天道不允许一族独大 | 龙汉初劫（[量劫/龙汉初劫]） |
| **巫妖大劫** | 妖族天庭与巫族争天地主角——两败俱伤、人族崛起 | 巫妖大劫（[量劫/巫妖大劫]） |
| **封神大劫** | 阐截两教之争——杀劫将修士送上封神榜、天庭充实 | 封神大劫（[量劫/封神大劫]） |
| **西游量劫** | 佛道气运之争——以取经为引、佛门东扩、道门退守 | 西游量劫（[量劫/西游量劫]） |

## 三、量劫的周期
- 洪荒流通常设定：**量劫每元会（约12万9600年）一次**——**无量量劫每无量量会（约4亿1000万年）一次**；
- 量劫由小到大：小劫→大劫→量劫→无量量劫（[境界/境界详解]劫数体系）；
- **圣人之下皆在量劫中应劫**；圣人亦需避劫——若量劫过重圣人亦难免陨落（如通天教主在封神中几乎被废——[人物/三清]"圣人不过量劫"的反例）；
- 应劫本质："劫数难逃"（命数——[地祇/星辰之神与命运神]命运——"劫"与"命"的关联）。

## 四、量劫与封神榜
- 封神榜的本质是量劫的一种**缓冲机制**：将应劫者死后封神——既完成杀劫、又充实天庭——使量劫危害可控（"把杀劫变成封神"——[大事件/封神榜三百六十五位正神]）；
- 封神榜上有名者：死后一缕真灵封神——虽得正神之位——但修为不再进步、受天道约束（"神道"vs"仙道"——[概念/气运功德香火业力]香火神道）；
- 封神榜vs肉身成圣：上榜者受天规（神职）、肉身成圣者逍遥（李靖/哪吒/杨戬等7人——[大事件/封神之战始末]）——"两条出路"。

## 五、量劫与功德
- **积攒功德是避劫/渡劫的重要方式**：女娲造人、补天，三清立教——皆有大功德——得以成圣避劫（[概念/气运功德香火业力]功德）；
- 无功德护身的修士在量劫中最易应劫（如截教万千散仙即因无功德而应劫上封神榜——[人物/截教群仙]"万仙来朝"反噬）；
- 量劫与功德的关系："功德=护身符、业力=催命符"——修真宇宙的因果法则（[概念/天道与因果]）。

## 六、量劫在洪荒流中的意义
- 量劫是洪荒流小说推进剧情发展的**核心动力**——没有量劫就没有冲突、没有冲突就没有故事；
- 量劫也是"因果报应"在宇宙层面的体现——天道至公、万物皆在劫中（[概念/天道与因果]）；
- 量劫的"规律"：旧主角退场→新主角崛起（龙汉三族→巫妖→人族→佛道格局）——"天地不仁以万物为刍狗"的叙事化（[概念/气运功德香火业力]气运转移）；
- 四大量劫对照：龙汉（三族）、巫妖（巫妖）、封神（阐截）、西游（佛道）——量劫=洪荒史的骨架（[时间线/总览]）。
