# 量劫总览

量劫是洪荒流世界观的核心理念——天道定期清算因果、洗牌气运的"重置机制"。每场量劫以大规模杀伐清算业力，淘汰旧势力、催生新格局。洪荒史公认四大量劫。

## 一、量劫机制（见[量劫/量劫机制]）
- **量劫本质**：天地积累的杀伐、因果、业力达到临界点，天道降劫清算——"劫运"显化；
- 量劫形式：大规模战争（龙汉初劫三族大战/巫妖大战/封神之战）或路线争夺（西游佛门东扩）；
- 量劫主角：上一纪元的天地主角（失败者退场）——三族→巫妖→截教→佛道格局。

## 四、量劫的共同规律
1. **因果积累**：上一纪元杀伐/业力积累（如三族大战、巫妖对峙）→ 劫运将至；
2. **大能布局**：圣人们（鸿钧/三清/西方二圣）顺应或推动量劫（封神榜为三教共议）——"量劫是大能的棋局"；
3. **旧势力退场**：每场量劫淘汰一个"天地主角"（三族→巫妖→截教）；
4. **气运转移**：量劫结束即新一轮气运分配（人族崛起/佛门东扩）；
5. **时代定格**：量劫后天道规则更完善（轮回建立、天庭充实、佛道制衡）。
