# 道门三教（人教·阐教·截教）

鸿钧道祖门下三清各立一教——"一道传三友，二教阐截分"。人教（太上老君）、阐教（元始天尊）、截教（通天教主）三教并立，封神大劫中阐截之争构成主线。三教既同出盘古元神（一气化三清），又有教义/门人/立场的根本分歧。

## 一、人教 · 太上老君
| 项目 | 内容 |
|---|---|
| 教主 | 太上老君（老子，太清） |
| 道场 | 三十三天兜率宫（离恨天）、首阳山八景宫 |
| 教义 | 无为、顺天、清静无为——重炼丹与内外丹道（太上道经/金丹大道） |
| 门人 | **玄都大法师**（唯一亲传，八卦紫金炉）；"人教"以人族为教众（教义上） |
| 立场 | 三教中最超然——门人最少、老子常"无为"；封神中出手极少（破诛仙阵/黄河阵） |
| 结局 | 封神后化胡为佛/留人教正统——道教化的老子一脉（《道德经》） |

## 二、阐教 · 元始天尊
| 项目 | 内容 |
|---|---|
| 教主 | 元始天尊（玉清） |
| 道场 | 玉虚宫（昆仑山） |
| 教义 | 重根脚（资质）、重内丹、重心性——"顺天而行、练就法力"，门人多为"仙种"（根脚不凡） |
| 门人 | 首徒**南极仙翁**；核心**十二金仙**（广成子/赤精子/太乙/玉鼎/道行天尊/清虚道德真君/黄龙真人/普贤/慈航/文殊/惧留孙/灵宝大法师）；三代：杨戬/哪吒/雷震子/韦护/土行孙等 |
| 立场 | 封神中**助周**（顺天应人）；教义与截教"有教无类"根本对立 |
| 结局 | 封神主力获胜——但十二金仙被削三花（三霄黄河阵）后重修；文殊/普贤/慈航转佛门 |

## 三、截教 · 通天教主
| 项目 | 内容 |
|---|---|
| 教主 | 通天教主（上清） |
| 道场 | 碧游宫（东海金鳌岛）——"万仙来朝" |
| 教义 | **"有教无类"**——收万物成精（妖族/异类多投截教），重外丹、法宝法术、不拘戒律 |
| 门人 | 首徒**多宝天尊**（后多宝如来）；四大弟子：多宝/金灵圣母/无当圣母/龟灵圣母；随侍七仙（虬首仙/灵牙仙/金光仙/乌云仙/毗芦仙/金箍仙马遂/长耳定光仙）；外门：赵公明/三霄/闻仲/罗宣/吕岳/九龙岛四圣/十天君等（[人物/截教群仙]） |
| 立场 | 封神中**助商**（闻仲求援不断）；"有教无类"使其门人鱼龙混杂、气运不纯 |
| 结局 | 诛仙阵+万仙阵两战大败——**十损其九**；残部被西方教渡走（或入封神榜）——截教覆灭 |

## 四、三教关系与封神
- **同源**：三清同出盘古元神（一气化三清，[人物/三清]）——"师兄弟"；
- **分家**：封神前因教义分歧（顺天vs无类）、气运分配（封神榜）分道扬镳；
- **封神之战**：阐教（助周）vs 截教（助商）——两教大战（十绝阵/九曲黄河阵/诛仙阵/万仙阵），人教老君居中劝和（实际偏阐）；
- **鸿钧调和**：封神后鸿钧召三清——"三教一家"训诫，通天被禁足紫霄宫（[大事件/封神之战始末]）；
- **结局格局**：截教灭、阐教衰（转佛门）、人教无为——后演化儒释道三教合一格局（佛门大兴、道教正统、儒家治世——[参考/经典书目与流派沿革]）。
