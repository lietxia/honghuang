# 白骨精（白骨夫人·三打白骨精）

西游八十一难中"三打白骨精"的主角——白虎岭上一具女尸白骨修炼成精，号白骨夫人。以狡诈善变化闻名——唯一不以武力取胜、纯以智计挑拨离间的妖，"三打"成为《西游记》最经典的章节之一。来源：《西游记》第27回。

## 身份
- **白骨夫人**：白虎岭上一具女尸白骨修炼成精（尸妖）——号"白骨夫人"；
- "三打白骨精"的主角——以连环变化挑拨唐僧与悟空的师徒关系；
- 洪荒流中为尸妖/骨妖之首——常被设定为"旱魃余气"或冥界怨气所生（[志怪精怪篇]尸类妖怪）。

## 神通
| 神通 | 说明 |
|---|---|
| **三变三骗** | 一变村姑、二变老妇、三变老翁——连环设计挑拨唐僧与悟空师徒关系 |
| **白骨遁** | 本体是一堆白骨——被打死后散成骨粉逃遁（金蝉脱壳） |
| **变化易容** | 变化之能——猪八戒沙僧皆不能识，唯孙悟空火眼金睛可辨 |
| **尸气迷魂** | 散发尸瘴、惑人心智 |

## 故事（西游记·三打白骨精）
1. **一打**：白骨精变村姑送饭（内有虫蚁）——唐僧要收，悟空识破一棒打死——白骨精元神遁走；
2. **二打**：又变老妇"寻女儿"——悟空再识破打死；
3. **三打**：再变老翁"寻妻女"——悟空请土地神、山神作证，三棒打死——白骨精现原形（白骨上刻"**白骨夫人**"四字）；
4. **关键转折**：唐僧肉眼凡胎——见悟空连杀"三人"（村姑/老妇/老翁），念紧箍咒、怒逐悟空回花果山；
5. **后果**：悟空被逐后——唐僧在宝象国遇黄袍怪（奎木狼，[人物/奎木狼]）之难——才知错怪悟空——八戒去花果山请回悟空——自此师徒信任大增（"三打白骨精"=师徒信任考验名篇）。

## 洪荒流设定
- 白骨精是"三打白骨精"一难中被唐僧驱逐悟空——全书"人性的考验"——肉眼凡胎的信与不信（主题：眼见为实vs耳听为虚）；
- 其狡诈程度在妖怪中罕见（唯一不以武力取胜、纯以智计的妖——"智慧型反派"）；
- 部分洪荒流设定其为冥界/尸修一脉（白骨道、尸仙）——与幽冥有渊源（[幽冥/总览]）；
- "白骨夫人"成白骨精/尸妖代名词——影视游戏（《大话西游》等）经典角色。
