# 烛龙（烛九阴·钟山之神·时间神龙）

《山海经》中掌管昼夜、季节的创世级神龙——人面蛇身而赤、身长千里，"视为昼、瞑为夜，吹为冬、呼为夏"。洪荒流中为时间法则/阴阳大道的化身，与时辰道人、十二祖巫之烛九阴同源，是龙族至强者之一。来源：《山海经·大荒北经》、纬书、洪荒流设定。

## 身份
- **钟山之神**：居西北钟山（章尾山）——"天不足西北，故有烛龙衔火精以照天门"（北方极地/幽冥的照明者）；
- **创世级神兽**：掌管昼夜、四时——睁眼为白昼、闭眼为黑夜（"烛龙行昼"）；
- **洪荒流**：时间法则/阴阳大道的化身——与时辰道人（时间之神）一体两面；十二祖巫之**烛九阴**（时间祖巫）即其化身/后裔（[人物/十二祖巫]）；
- 人面蛇身而赤、身长千里——上古龙族最神秘的存在。

## 神通
| 神通 | 说明 |
|---|---|
| **昼夜之眼** | 睁眼为昼、闭眼为夜——掌日月交替、时光流转 |
| **息吹四季** | 呼气为冬、吸气为夏——不饮不食不寝、掌四时更替 |
| **烛龙之光** | 以烛照幽冥、照亮九幽之地（地府照明者——"烛阴"之名） |
| **时间之道**（洪荒流） | 时间法则执掌者之一——眼开眼合即时间流逝、岁月加身 |
| **风雨神通** | 能致风雨（行云布雨龙族本命） |

## 法宝
- 无（本体即神通）——烛龙身长千里，其精魄可化时间至宝（部分设定）；
- "烛龙珠/时间之心"：洪荒流中烛龙之珠为时间系顶级宝物（常见设定）。

## 故事与设定
1. **开眼闭眼**：不食不寝不息、呼吸成风云、睁眼闭眼成昼夜（《山海经·大荒北经》）；
2. **日照所不及**：烛龙是"北方极地/幽冥"的照明者——"天不足西北，故有烛龙衔火精以照天门"（纬书）；
3. **洪荒流**：烛龙为混沌魔神/先天神龙（掌时间法则）——与时辰道人一体两面；十二祖巫烛九阴为其化身/后裔；
4. 常与盘古、应龙并列为龙族至强者（应龙=空间/战斗、烛龙=时间/法则、祖龙=血脉始祖——[人物/应龙]、[先天三族/龙族]）。

## 相关设定
- 烛龙与"永夜/白昼"神话：北方极夜、极昼现象的神话化解释；
- 洪荒流"时间系"顶级存在——时间法则三巨头：时辰道人（时间魔神）、烛龙（神龙）、烛九阴（祖巫）；
