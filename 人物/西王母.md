# 西王母（王母娘娘·瑶池金母·金母元君）

上古女神之首——道教尊为"金母元君、瑶池金母、王母娘娘"，与东王公（东华帝君）并列为男仙/女仙之首。居昆仑山瑶池、蟠桃园之主，掌不死药与女仙统御。洪荒流中为先天女神，与女娲、后土并列的女仙巨擘。来源：《山海经》（西王母原始形象）、《穆天子传》《汉武帝内传》、道教神系。

## 身份
- **上古女神**：原始形象（《山海经》）为"豹尾虎齿而善啸、蓬发戴胜"的凶神——司天之厉及五残（掌灾厉刑罚）；
- **道教女仙之首**：金母元君/瑶池金母/王母娘娘——与东王公并列男仙/女仙之首（[道教神佛/先天尊神]）；
- 居**昆仑山瑶池**（后设定天庭瑶池）——蟠桃园之主；
- **玉皇大帝之妻**（民间/天庭设定）——"天之圣母"（[人物/玉皇大帝]）；
- **洪荒流**：先天女神（混沌时期即存在）——天庭女仙之首，地位与女娲、后土并列。

## 神通
| 神通 | 说明 |
|---|---|
| **不死药/蟠桃权柄** | 掌蟠桃园（三千年/六千年/九千年一熟）——食之与天同寿——王母的"造寿命"权柄 |
| **天罚权柄** | 司天之厉及五残——掌灾厉刑罚（原始凶神职能） |
| **瑶池圣水** | 瑶池之水洗练仙体——凡人饮之成仙 |
| **统御女仙** | 以瑶池统御女仙——广寒宫、太阴星君为其麾下 |

## 法宝
- **昆仑镜**：可照前世今生、过去未来、穿梭时日（民间传说/洪荒流幻境之宝）；
- **蟠桃**：十大先天灵根之首级（[法宝/十大先天灵根]）——镇园之宝；
- **九曲瑶池**（道场设施）：洗涤仙根圣水；
- **玉簪**（部分设定）：划天河（银河）——牛郎织女传说（[上古神话典故/四大民间传说]）。

## 故事
1. **蟠桃盛会**：天庭蟠桃会——三界仙家皆以受邀为荣（"蟠桃宴"神话核心）；孙悟空偷桃闹会——大闹天宫导火索之一（[人物/孙悟空]）；
2. **周穆王相会**：周穆王西游昆仑——与西王母宴于瑶池（《穆天子传》）；
3. **汉武帝相会**：西王母降于汉宫——赐蟠桃与汉武帝（《汉武帝内传》——"王母蟠桃"传说）;
4. **牛郎织女**：王母划天河隔断牛郎织女——只许七夕鹊桥相会（民间传说）；
5. 西游：蟠桃会主角——太上老君兜率宫、王母瑶池并称天庭两大"资源中心"。

## 洪荒流设定
- 与玉帝（昊天）共同执掌天庭——"天后"（天庭资源总管）；
- **蟠桃=妖族/仙人延寿关键**——保天庭气运（[概念/气运功德香火业力]）——"蟠桃会"的气运笼络功能；
- 西王母与东王公（男仙之首）——阴阳二气之父母（先天尊神体系，[道教神佛/先天尊神]东王公西王母）；
- 不死药（嫦娥奔月）——王母掌"长生资源"的延伸（[人物/嫦娥]）。
