# 真武大帝（玄天上帝·荡魔天尊·武当山主神）

道教重要大神——北方玄武七星的人格化（宋代起），武当山主神。号"玄天上帝、荡魔天尊"，与雷电/水神/北帝信仰融合；明成祖大修武当（"北修故宫、南修武当"）使真武信仰达巅峰。来源：道教文献、武当山道教协会、[灵兽神兽/四灵详考]。

## 身份
- **玄武的人格化**：北方七宿（斗牛女虚危室壁）之龟蛇合体神兽玄武——宋代起人格化为真武大帝（四象北宫黑帝之精——[灵兽神兽/四灵详考]）；
- **道教大神**：真武大帝/玄天上帝/荡魔天尊——武当山主神；
- 与紫微大帝、勾陈大帝、长生大帝并列为"四极大帝"之一（部分体系——[道教神佛/道教神谱详录]）；
- 明代尊为"玄天上帝"——与雷电/水神/北帝信仰融合（[道教神佛/护法神将]北极四圣：真武灵应佑圣真君）。

## 神通
| 神通 | 说明 |
|---|---|
| **龟蛇二将** | 玄武本相龟蛇合体——人格化后龟蛇为部将（龟将/蛇将）——象征镇水 |
| **北方水神** | 掌天一之水（玄武属水）——涤荡妖邪（北方水德） |
| **荡魔除妖** | 号"荡魔天尊"——统摄北方诸魔、镇守幽冥/北方——道教驱邪大神之最 |
| **真武剑/真武旗** | 荡魔法器（披发仗剑、足踏龟蛇形象） |

## 神话与传说
1. **太子修道**（静乐国太子说）：净乐国太子舍弃王位——入武当山（太和山）修行四十二年——功德圆满飞升（"真武修行"故事是武当山道场之源）；
2. **龟蛇收魔**：修行时精气化为龟蛇（或收伏龟蛇二妖）为将（龟蛇二将形象定型）；
3. **宋代地位抬升**：宋太祖有"真武、天蓬为天之大将"传说——真宗天禧元年营卒见蛇泉涌建真武堂（最早真武庙）——宋代帝王推波助澜——真武信仰大盛——逐渐成为北方最高神祇之一；
4. **明成祖大修武当**：朱棣大修武当山（"北修故宫、南修武当"）——真武信仰达巅峰（相传朱棣以真武自居）——武当山成道教第一名山（[洞天福地/佛道名山道场]）。

## 在各大作品中的形象
- 《西游记》：**荡魔天尊**（北方真武大帝）——悟空请其降妖（皂雕旗/北方真君体系）；
- 《封神演义》：真武大帝未直接出场——"玄武"四象与斗部相关（[道教神佛/斗部星君]四灵二十八宿）；
- 洪荒流：真武为四象玄武化身/北帝——天庭北方镇守（勾陈/紫微体系）——龟蛇二将为坐骑/护法（[灵兽神兽/坐骑谱]）；
- 南游记：《北游记》以真武大帝为主角（玉帝三魂之一转世修行——真武生平——[参考/四游记与神魔小说]）。
