# 赵公明（玄坛真君·武财神之首）

截教外门大弟子、封神核心人物、后世财神——"正月初五迎财神"迎的就是他。封神中持定海珠连败玉虚十二金仙、燃灯也不能敌——被陆压钉头七箭书暗算陨落（封神"最憋屈的强者之死"）。封神后封"金龙如意正一龙虎玄坛真君"——统招宝/纳珍/招财/利市四仙——**武财神之首**（[地祇/五显五通与财神信仰]财神谱）。来源：百度百科、维基百科、《封神演义》。

## 身份
- **截教通天教主外门大弟子**（天皇得道——修成玉肌仙体——[人物/截教群仙]）；
- **三霄娘娘之兄**（[人物/三霄娘娘]——金蛟剪即借自三霄）；
- 封神后封"**金龙如意正一龙虎玄坛真君**"——统招宝天尊、纳珍天尊、招财使者、利市仙官——**武财神之首**（[地祇/五显五通与财神信仰]四大财神——"正财神"）；
- 民间"正月初五迎财神"（破五——迎赵公明）——"赵公明"=中国财神第一符号。

## 法宝
| 法宝 | 说明 |
|---|---|
| **定海珠（二十四颗）** | 先天灵宝——原为混沌中二十四颗定海神珠——每颗珠内蕴一小世界——二十四颗珠化二十四诸天——珠光所照困敌于小世界——凭此珠连败玉虚十二金仙（燃灯亦不敢正面交锋）——后被燃灯以落宝金钱落去（[人物/燃灯古佛]化二十四诸天——成佛之基） |
| **缚龙索** | 捆仙擒将的绳索法宝——曾擒拿黄龙真人等阐教门人 |
| **金蛟剪**（借自三霄） | 两条太古金蛟所化先天灵宝——一剪之下断肢分身——圣人亦忌（[人物/三霄娘娘]） |
| **黑虎** | 坐骑——后随赵公明成**玄坛黑虎**——财神象征之一（"玄坛黑虎"） |
| **金鞭** | 护身兵刃——持鞭行法 |

## 神通
| 神通 | 说明 |
|---|---|
| **定海神珠神通** | 二十四颗珠化二十四诸天叠加镇压——珠光所照对手法宝失灵、神通受阻——曾连败玉虚十二金仙中的多位 |
| **缚龙索法** | 索出如龙——捆仙擒将——中者短时间内难以挣脱 |
| **金蛟剪神通** | 祭出二蛟交剪——可断灵宝、伤圣人肉身 |
| **玄坛罡气** | 玉肌仙体——肉身强横——刀枪不入、水火不侵 |

## 事迹
1. **下山助商**：应闻仲之邀下山助商（[人物/闻仲]）——败姜子牙、打伤哪吒、擒黄龙真人——玉虚诸仙束手（封神前期"无敌"战绩）；
2. **被落宝**：燃灯以落宝金钱（萧升曹宝所使——[法宝/后天灵宝详录]落宝金钱）落其定海珠与缚龙索——赵公明失宝后借金蛟剪（三霄）与定海珠再战；
3. **钉头七箭书**：陆压道人（[人物/陆压道君]）以**钉头七箭书**暗算——拜二十一日——赵公明魂魄被拜散——最终陨落（"不死于阵前、死于暗算"——封神最憋屈强者之死）；
4. **封神为财神**：封"金龙如意正一龙虎玄坛真君"——民间尊为武财神——正月初五迎财神即迎赵公明（[地祇/五显五通与财神信仰]"破五"）。

## 神话原型 vs 洪荒流设定
| 原型 | 洪荒流 |
