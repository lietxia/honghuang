# 奎木狼（黄袍怪·波月洞主·二十八宿之首）

二十八宿之**奎木狼**（西方白虎七宿之首宿）——天庭星君下凡，因与披香殿玉女有私情成妖（黄袍怪），据碗子山波月洞。取经八十一难"黄袍怪/宝象国"一难的主角——"星君下凡为妖"典型案例（有后台，被天庭收回）。来源：《西游记》第28-31回、[地祇/星辰之神与命运神]。

## 身份
- **二十八宿之奎木狼**：西方白虎七宿之首宿（奎宿，[地祇/星辰之神与命运神]二十八宿）——天庭星君；
- **下凡为妖**：因与天庭披香殿玉女（百花羞）有私情——下凡为妖（黄袍怪）——据碗子山波月洞；
- 取经八十一难"黄袍怪/宝象国"一难主角——与宝象国三公主百花羞（披香殿玉女转世）结为夫妻十三年（育有二子）；
- 有背景的妖怪——结局被天庭收回（"星君身份保命"）。

## 神通
| 神通 | 说明 |
|---|---|
| **星君神通** | 二十八宿星君（奎宿）——法力高强、肉身强横、能变化、能喷火（吐火之术） |
| **黄袍怪变化** | 容貌俊朗的黄袍怪（非狰狞妖怪）——宝象国驸马形象 |
| **武艺** | 与悟空大战——若非悟空请天庭，单靠取经团队难以取胜（沙僧被擒、八戒败退） |
| **吐火/变身虎** | 将唐僧变作猛虎（"变虎"法术）——宝象国大殿名场面 |

## 故事（西游记·宝象国一难）
1. **下凡成家**：奎木狼下凡为妖——与转世的披香殿玉女百花羞结为夫妻十三年（育有二子——后被八戒/沙僧摔死）；
2. **掳唐僧**：唐僧被黄袍怪掳入波月洞（因百花羞放走唐僧——黄袍怪怒）——宝象国请唐僧降妖；
3. **团队受挫**：沙僧被擒、八戒败逃（"黄袍怪"神通压团队）；
4. **关键转折**：悟空被逐回花果山后（"三打白骨精"的后续）——**白龙马**现身战黄袍怪（不敌）——八戒去花果山请回悟空（[人物/白龙马]救主一战）；
5. **悟空破敌**：悟空与黄袍怪大战——黄袍怪遁逃；悟空追至天庭查二十八宿名册——确认其为奎木狼；
6. **天庭收回**：玉帝派二十七宿收回奎木狼（被罚"为老君烧火"）——宝象国救出百花羞公主（一家团聚）。
