# 金角银角大王（平顶山莲花洞·老君二童子）

太上老君座下两个烧火童子（金炉童子、银炉童子）下界为妖——偷了老君五件宝物、占平顶山莲花洞，号金角大王、银角大王。西游八十一难"平顶山逢魔"的主角——"我叫你一声你敢答应吗"（紫金红葫芦）梗的出处。来源：《西游记》第32-35回。

## 身份
- **太上老君座下烧火童子**：金炉童子（金角）、银炉童子（银角）——兜率宫炼丹童子（[人物/三清]老君一系）；
- 下界为妖：偷了老君五件宝物私逃下界——占平顶山莲花洞；
- 西游八十一难之"平顶山逢魔"主角——老君亲口点明："那两童子是我看金炉的、看银炉的"——"有后台"妖怪（被收回天上）；
- "道门试探佛门"的设置——西游量劫中老君一系的重要关卡（[大事件/西游取经与佛门东扩]）。

## 神通
| 神通 | 说明 |
|---|---|
| **移山填海** | 银角大王以"移山法"搬来须弥山、峨眉山、泰山压孙悟空（悟空被压得七窍喷血——亏五方揭谛/土地相助） |
| **变化** | 金角化老道、银角化孩童——设计骗唐僧（装残疾老人骗悟空背——"背娘舅"名场面） |
| **喊名应声**（部分版本） | 一喊名、应者即被吸走（葫芦/净瓶的用法） |

## 法宝（老君五宝）
| 法宝 | 说明 |
|---|---|
| **紫金红葫芦** | 喊名应之即收——一时三刻化脓水（"我叫你一声你敢答应吗"出处——老君盛丹之宝） |
| **羊脂玉净瓶** | 同葫芦——装人即化（老君盛水之宝） |
| **幌金绳** | 捆仙绳——念咒即缚（老君勒袍带子） |
| **七星剑** | 锋利仙剑——劈石开山（老君炼魔之宝） |
| **芭蕉扇（至阳）** | 火扇——一扇起烈火（与铁扇公主的芭蕉扇阴阳相对——此扇纯阳至刚，老君扇火之宝） |

## 故事（西游记·平顶山）
1. **设局**：金角银角设计捉唐僧——银角变受伤老道骗悟空背（移山压悟空）、金角化老道骗师徒；
2. **斗智斗勇**：悟空识破后与二妖周旋——被幌金绳捆（挣断又捆）、被银角移山压住（"压了七个葫芦，悟空七窍喷血"）；
3. **反败为胜**：悟空以"按摩法"骗银角背自己（"你背我！"——"背一个凡人"名场面）——又用假葫芦"换"来真葫芦收银角——金角也被收（"我叫你一声你敢答应吗"——孙悟空报真名"孙行者"被吸，报假名反收银角）；
4. **老君收宝**：金角被收后——老君现身："这葫芦是我盛丹的，净瓶是我盛水的，宝剑是我炼魔的，扇子是我扇火的，绳子是我一根勒袍的带子"——五宝来历点明——二童子收回天上。

## 洪荒流设定
- 老君童子的身份使此一难充满"道门试探佛门"意味（老君五宝=道门家底展示）——西游量劫中道门（老君）一系重要关卡；
- 紫金葫芦、羊脂玉净瓶、幌金绳、七星剑、芭蕉扇皆收录于法宝谱（[法宝/后天灵宝详录]）；
- "喊名应声"法宝原型——红葫芦系（与[人物/陆压道君]斩仙葫芦、紫金红葫芦同源——葫芦法宝家族）。
