# 小青（青蛇·青鱼精·白娘子之妹）

白蛇传的主要配角——白素贞的结拜妹子/丫鬟。青蛇成精（早期版本为青鱼精），忠义果敢、快意恩仇——"姐姐"式姐妹情深的代表。现代改编（徐克《青蛇》、动画《白蛇2》）中形象愈发独立立体——从"绿叶"到"主角"的女妖成长史。来源：冯梦龙《白娘子永镇雷峰塔》、戏曲"双蛇斗"、现代影视。

## 身份
- **青蛇精**（早期版本为**青鱼精**：明冯梦龙《白娘子永镇雷峰塔》中"青青"为西湖青鱼精——后民间改编为青蛇——[上古神话典故/白蛇传专篇]形象流变）；
- **峨眉山（或青峰山光华洞）青蛇**修炼成精——戏曲"双蛇斗"设定：青蛇大仙（**男儿身**）欲与白蛇结侣——斗法不敌（白蛇七千九百余年道行）——化女身相随（"姐妹"关系的由来——性别转化的趣味设定）；
- 白素贞结拜妹子/丫鬟——许仙之妻妹（[人物/白素贞]）——"小青"（青色=青蛇）；
- 现代形象：徐克电影《青蛇》（王祖贤/张曼玉——"人生如此，浮生如斯"）、动画《白蛇2：青蛇劫起》（2021——小青独立成篇）。

## 故事
1. **结拜**：峨眉山青蛇（或青鱼）与白蛇结拜为姐妹——随白娘子下凡（"青儿"——丫鬟兼护卫）；
2. **助姐行善**：随白娘子保和堂行医——保护"姐姐"（端午现形后救许仙——盗仙草护送）；
3. **水漫金山**：助白娘子水漫金山（与法海斗法——"双蛇斗法"）——水漫金山后姐妹同进退（[人物/白素贞]水漫金山）；
4. **塔下守候/复仇**：白娘子被镇雷峰塔——小青苦修复仇（部分版本：勤修五百年——"剑挑法海"）；杨柳青年画"**小青掀塔**"版本（小青法力大成掀翻雷峰塔救姐）；
5. **结局**：大团圆版本——小青随白娘子许仙飞升（"姐妹同证"）；《白蛇2》现代改编——小青独闯修罗城救姐（"青蛇劫起"）。

## 形象与象征
- **忠义姐妹情**：小青="姐姐至上"的忠仆义妹——"姐妹情深"中国女性情谊的经典（与貂蝉/梁红玉等"义女"形象并列——[上古神话典故/白蛇传专篇]）；
- **快意恩仇**：比白娘子更"烈"（白蛇温婉、青蛇刚烈——"一温一烈"双蛇性格对照）；
- **独立化进程**：从丫鬟（冯梦龙）→义妹（戏曲）→主角（现代影视——《白蛇2》"青蛇独立成传"）——中国女性角色从附属到独立的文化投影；
- 青蛇=青春/野性/成长（与白蛇=成熟/深情对照——"双蛇"象征人生两阶段）。
