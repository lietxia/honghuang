# 小青（青蛇·青鱼精·白娘子之妹）

白蛇传的主要配角——白素贞的结拜妹子/丫鬟。青蛇成精（早期版本为青鱼精），忠义果敢、快意恩仇——"姐姐"式姐妹情深的代表。现代改编（徐克《青蛇》、动画《白蛇2》）中形象愈发独立立体。来源：冯梦龙《白娘子永镇雷峰塔》、戏曲"双蛇斗"、现代影视。

## 身份
- **青蛇精**（早期版本为**青鱼精**：明冯梦龙《白娘子永镇雷峰塔》中"青青"为西湖青鱼精——后民间改编为青蛇）；
- **峨眉山青蛇修炼成精**——戏曲"双蛇斗"设定：青蛇大仙（**男儿身**）欲与白蛇结侣——斗法不敌（白蛇七千九百余年道行）——变女身与白蛇结拜姐妹、终身侍奉；
- 白素贞之妹（丫鬟）——许仙之"姨姐"；白蛇传"三主角之一"（断桥相会三人组）。

## 神通
| 神通 | 说明 |
|---|---|
| **青鱼/青蛇变化** | 化人形（青衣女子形象） |
| **水族神通** | 随白娘子召虾兵蟹将水漫金山（"水斗"主力——淮剧/京剧名场面） |
| **九把飞刀**（后期版本） | 《白蛇全传》：水漫金山后逃脱——修炼成九把飞刀找法海报仇（"小青复仇"线） |
| **掀塔**（部分版本） | "小青掀雷峰塔"（杨柳青年画版本）——救姐姐 |
| **伶牙俐齿/泼辣** | 与小白的姊妹情名场面（"姐姐、姐姐"） |

## 故事
1. **西湖结拜**：西湖畔与白娘子结拜（"青儿"）——随侍白娘子寻许仙；
2. **盗银/盗宝**（早期版本）：牵连许仙（盗库银案）；
3. **水漫金山**：战斗主力之一（召水族、与法海斗法）；
4. **断桥重逢**："断桥"三主角——随白娘子寻夫；
5. **结局各版本不同**：
   - 明版：被镇雷峰塔（与白蛇同囚）；
   - 《白蛇全传》：修炼九把飞刀复仇——后配许仙为侧室生一子（武曲星）；
   - 现代改编：独立成主角（徐克《青蛇》——小青看破红尘的"看客"视角；《白蛇2：青蛇劫起》——小青闯修罗城救姐姐）。

## 现代演变
- **徐克《青蛇》（1993）**：小青从"配角"升为"主角"——以青蛇的视角看人间情欲（"姐姐，你总是说人间有情"经典台词）——看透红尘的蛇妖；
- **《白蛇2：青蛇劫起》（2021动画）**：小青修罗城历劫——"执念"主题——青蛇形象彻底独立（"小白，我来救你"）。
