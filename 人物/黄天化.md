# 黄天化（三山炳灵公·攒心钉）

武成王黄飞虎长子——阐教清虚道德真君弟子，周营三代猛将（与哪吒、杨戬并称"玉虚第三代之三杰"）。以**攒心钉**一人连钉死魔家四将（四大天王）立下封神大功，金鸡岭之战陨落，封"三山正神炳灵公"。来源：《封神演义》。

## 身份
- **黄飞虎长子**：武成王黄飞虎之子（一门忠烈——黄飞虎/黄天化/黄天祥/黄天禄，[人物/黄飞虎]）；
- **清虚道德真君弟子**：自幼被道德真君救上青峰山紫阳洞修道（黄飞虎一门被纣王逼反时，黄天化年幼在师门）；
- 封神后封"**三山正神炳灵公**"（管领三山，泰山神第三子之职——"炳灵公"）；
- 周营三代猛将——"三吒"（哪吒/黄天化/雷震子）之一（另有杨戬并列"四大天王杀手"）。

## 故事（封神演义）
1. **师门修行**：黄飞虎一门被纣王逼反（黄飞虎反五关）——黄天化年幼在师门（青峰山紫阳洞）修道；
2. **下山助周**：奉师命出山辅佐姜子牙——与杨戬、哪吒并肩；
3. **钉死魔家四将**：魔家四将（魔礼青/红/海/寿——青云剑/混元伞/琵琶/花狐貂）法宝纵横、姜子牙节节败退——杨戬变化盗宝——**黄天化以攒心钉接连将四将钉杀**（封神前期最大战功——"一人钉四天王"名场面）；
4. **金鸡岭之战**：战商将高继能——高继能**蜈蜂袋**放出毒蜂破法——黄天化被蜈蜂刺中（一说刺中面门）——战死金鸡岭（崇黑虎等为其报仇，后高继能被黄飞虎所杀）；
5. **封神**：封为三山正神炳灵公——司三山（泰山府君之下——[人物/黄飞虎]东岳大帝之子的"炳灵公"信仰真实存在）。

- **攒心钉**属后天灵宝（[法宝/后天灵宝详录]）——封神群仙法宝谱所收；
- 与[人物/杨任]（同门——道德真君另一弟子）——"青峰山紫阳洞一门两杰"；
