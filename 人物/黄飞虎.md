# 黄飞虎（武成王·东岳泰山天齐仁圣大帝）

商朝镇国武成王——七世忠良之后，因纣王逼死其妻贾氏、妹妹黄贵妃（妲己设局），反出朝歌、连闯五关投奔西岐。周武王麾下主帅，封神后封**东岳泰山天齐仁圣大帝**（五岳之首），执掌幽冥地府十八重地狱——"泰山治鬼"信仰的源头。来源：《封神演义》、泰山信仰。

## 身份
- **商朝武成王**：镇国武成王——商朝核心武将（七世忠良之后，"黄门忠烈"）；
- **反商投周**：因纣王逼死其妻贾氏（妲己设局轻薄）、妹妹黄贵妃撞死——反出朝歌，投奔西岐；
- 周武王麾下——前部先锋主帅（长期执掌军务）；
- 封神后封**东岳泰山天齐仁圣大帝**——五岳之首，执掌幽冥地府一十八重地狱（"泰山治鬼"，[地祇/五岳大帝]）。

## 神通
| 神通 | 说明 |
|---|---|
| **武艺超凡** | 使**金攥提芦枪**（一百零八斤）——枪法如神，凡间武将之首 |
| **五色神牛神力** | 坐骑五色神牛日行八百、冲锋陷阵（[灵兽神兽/坐骑谱]） |
| **统兵之才** | 周营前部先锋主帅——长期执掌军务（统帅型武将） |

## 法宝/装备
- **金攥提芦枪**：重一百零八斤的宝枪——枪出如龙、神鬼难挡；
- **五色神牛**：上古异兽坐骑——五色皮毛、力大无穷、刀枪不入；
- **金装锏**（防身）：近战锏法；
- **蟒龙甲/护心镜**：武将甲胄。

## 故事（封神演义）
1. **反五关**：黄飞虎反出朝歌——闻太师（闻仲）追剿、黄飞虎连闯五关（临潼关/潼关/穿云关/界牌关/汜水关）——一路血战（"黄飞虎反五关"名场面）；
2. **投周为帅**：投周后为周营主要大将——战张桂芳、破十绝阵（执掌先锋）、四圣阵等；
3. **渑池之战**：黄飞虎与子黄天祥、黄天禄等皆死于张奎（张奎杀黄家满门——[人物/土行孙]同役）；
4. **封神**：封东岳泰山天齐仁圣大帝——掌幽冥——与[人物/后土娘娘]幽冥体系相接；其子黄天化封"三山正神炳灵公"（泰山府君之子信仰）。
