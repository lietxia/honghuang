# 伏羲（天皇·人祖·八卦之祖）

三皇之首（天皇）——人文始祖：画八卦、结绳记事、教民渔猎婚姻——"伏羲一画开天"（八卦原点）。洪荒流中居火云洞（火云洞三皇之首——[人物/火云洞三皇]），以"人道"证圣；神话中为女娲之兄（伏羲女娲兄妹婚配传说——"人祖"）——中国人文启蒙第一人。来源：《周易·系辞》、[人族/三皇五帝]、伏羲女娲画像石。

- **人祖**：伏羲女娲（兄妹）为"人类始祖"（伏羲女娲画像石——人首蛇身交尾——[大事件/女娲造人]关联——"人祖"信仰——人类再生神话：洪水后兄妹成婚再造人类）；
- **八卦之祖**：画八卦（"仰观俯察"——[概念/周易八卦详解]先天八卦——"一画开天"——中国哲学原点）；
- **人文始祖**：教民渔猎、制嫁娶——"以通神明之德，以类万物之情"（《易·系辞》）；
- 洪荒流：人族圣皇（火云洞三皇之首）——人道护法（不涉量劫、镇人族气运——[概念/气运功德香火业力]）。
