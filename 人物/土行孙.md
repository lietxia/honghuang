# 土行孙（地行术·土府星君）

阐教惧留孙弟子——善**地行术**的矮个神仙，封神中"以小博大"的代表：靠钻地术戏耍高他数级的对手。先投商后归周，娶邓婵玉，封神后封土府星君（掌大地）。来源：《封神演义》。

## 身份
- **惧留孙弟子**：阐教玉虚宫十二金仙惧留孙之徒（夹龙山飞云洞）；
- 身矮貌丑却神通独特（地行术日行千里）；
- 封神中先投商（邓九公荐将）后归周（被擒后归顺）；
- 娶**邓婵玉**（五光石神射）——夫妻同为周将；
- 封神后封"**土府星君**"（兼土地神/地祇，掌大地——[地祇/总览]）。

## 神通
| 神通 | 说明 |
|---|---|
| **地行术** | 钻地而行、日行千里——地下作战几乎无敌（惧留孙所授绝学） |
| **指地成钢（克制法）** | 惧留孙的破解之法——将大地化为钢地、土行孙无法钻地（"指地成钢"见[神通/各家神通]） |
| **捆仙绳法** | 祭惧留孙之宝捆仙绳拿人（偷带下山） |
| 防御弱点 | 离地之后战力平平——地行术被破即败（"欺强不欺弱"的奇门神通） |

## 法宝
- **捆仙绳**：惧留孙法宝——念咒即缚仙（土行孙偷带下山，屡擒周营高手）；
- **混铁棍/铁棍**：近战兵器（冲锋陷阵）；
- 坐骑：无（本身钻地如飞——"地行"代步）。

## 故事（封神演义）
1. **助商**：姜子牙伐商——土行孙被邓九公（邓婵玉之父）荐为将助商；
2. **捆仙绳逞威**：以捆仙绳连擒周营高手（哪吒等被缚）——姜子牙头疼；
3. **被破归周**：杨戬探出其地行术——惧留孙亲临以"指地成钢"破之（地行术失效被擒）——归周；
4. **娶邓婵玉**：二人不打不相识（邓婵玉五光石专打面部）——归周后成婚、夫妻双双为周将；
5. **渑池之战**：渑池县夜探——被善地行术的张奎所杀（张奎地行术"日行一千五百里"快过土行孙）——夫妻皆陨（邓婵玉封"六合星君"）；
6. 封神：土行孙封"**土府星君**"（掌大地——[大事件/封神榜三百六十五位正神]）。

## 洪荒流设定
- 土行孙是封神"以小博大"代表——地行术使其可戏耍高数级的对手（"奇门神通胜于境界"的典型）；
- 惧留孙（十二金仙）之捆仙绳/指地成钢为标志法宝（[法宝/十二金仙法宝]）；
- 地行术为土系遁术高级应用（[神通/各家神通]五行遁术）——土行孙为"土遁第一人"；
- 土府星君：封神榜群星列宿之一（地祇/星君体系，[地祇/星辰之神与命运神]）。
