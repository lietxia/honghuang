# 道行天尊（金庭山玉屋洞·韦护之师）

阐教玉虚宫元始天尊座下**十二金仙**之一——居金庭山玉屋洞——**韦护之师**（[人物/韦护]——降魔杵传人）。封神中少出手（"弟子代劳"型金仙——韦护以降魔杵建功）——却与截教有过"粮草之争"（与惧留孙斗法救韩毒龙等）。十二金仙中"低调师父"的代表。来源：《封神演义》。

## 身份
- **十二金仙之一**：玉虚宫元始天尊座下（居金庭山玉屋洞——[法宝/十二金仙法宝]道行天尊）——玉虚十二仙；
- **韦护之师**：韦护（[人物/韦护]——周营降魔杵大将）的授业恩师——**降魔杵**的传法者；
- 弟子：韦护、韩毒龙、薛恶虎（三位弟子——"宝贝多"的金仙）；
- **"弟子代劳"型**：封神中极少亲自出手（韦护代师建功——"高徒即高师"）。

## 故事（封神演义）
1. **遣徒下山**：奉师命/应姜子牙之请——遣韦护下山助周（降魔杵——[人物/韦护]）；
2. **三弟子**：韩毒龙、薛恶虎先下山（曾被擒/阵亡——[大事件/封神之战始末]十绝阵中韩毒龙陷地烈阵、薛恶虎陷寒冰阵——"先遣弟子殒命"——道行天尊门下悲剧）；
3. **怒战救徒**：十绝阵中弟子阵亡——道行天尊怒而出战（与惧留孙等破阵——悲愤出手）；
4. **结局**：封神战后——与诸金仙同列（未上榜——[大事件/封神之战始末]）。
