# 沙僧（沙悟净·卷帘大将·金身罗汉）

取经团队三徒弟——前身天庭**卷帘大将**，因失手打碎琉璃盏被贬流沙河；忠厚老实、任劳任怨的"挑担者"。取经团队中沉默可靠的基石——"大师兄，师父被妖怪抓走了"梗的源头（老实人担当）。《西游记》中最"稳定"的角色——从戴罪之身到金身罗汉的"圆满弧线"。来源：《西游记》第8/22回等。

## 身份
- **卷帘大将**：玉帝驾前卷帘大将（掀帘侍卫长/仪仗统领）——蟠桃会上失手打碎**琉璃盏**（一说玻璃盏）——被贬下凡（"玉皇大帝便打八百，贬下界来"）——“戴罪修行”；
- 贬至**流沙河**为妖（"流沙河怪"）——吃人无数（项下挂**九个骷髅**——前九世取经人（唐僧前九世）的头颅——[人物/唐僧]"十世修行"设定呼应——骷髅项链成"取经宿命"的伏笔）；
- 观音点化、唐僧收为三徒弟——法名**悟净**、号**沙和尚**（"沙僧"——"悟净"=净心净性之意）；
- 取经团队"担担子"的苦力担当（通行版沙僧挑担——行李=经卷的象征）。

## 故事（西游记）
1. **流沙河收服**：唐僧师徒过流沙河——沙僧水中与八戒大战（"淌水"水战）——悟空不善水战请观音——沙僧皈依（骷髅化法船渡河——"九个骷髅"成就"十世取经"圆满）；
2. **取经路**：挑担、随行——水战担当（通天河灵感大王一难中下河探底——[人物/灵感大王]相关）；
3. **关键时刻**：黄袍怪战（沙僧被擒不屈）、红孩儿战（随行救主）——虽少高光但从不掉队（"从不缺席的可靠者"）；
4. **结局**：取经功成——**金身罗汉**（八宝金身罗汉——如来封——"五圣成真"）。
