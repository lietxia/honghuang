# 应龙（有翼之龙·雨神·黄帝大将）

中国神话中的有翼之龙（背生双翼）——龙之最高形态（与无翼的常规龙族相区别）。黄帝麾下大将、大禹治水功臣、雨师之祖——"应龙蓄水、应龙画地成江"——上古神话中战功赫赫的神龙。洪荒流中为先天祖龙族至强/巫妖大战参与者——"龙族战神"。来源：《山海经·大荒东经》《楚辞》《述异记》。

## 身份
- **有翼之龙**：《山海经·大荒东经》"应龙处南极，杀蚩尤与夸父，不得复上，故下数旱"——能兴云致雨的神龙（"应龙"=应时行雨之龙）；
- **黄帝（轩辕）麾下大将**——涿鹿之战助黄帝战蚩尤（蓄水攻之——[人物/蚩尤]涿鹿之战）；
- **大禹治水功臣**：以尾画地成江河（导水入海——[人物/大禹]治水——"应龙画地"）；
- **雨师之祖**：司雨之神（行雨龙祖——[地祇/自然神与气象神]雨师——"应龙致雨"）；
- 洪荒流：先天祖龙（[先天三族/龙族]）至强族裔——巫妖大战的龙族战神（后败退归隐）。

## 神通
| 神通 | 说明 |
|---|---|
| **蓄水行雨** | 掌水行雨（"应龙致雨"——索雨之龙——降雨神通） |
| **画地成江河** | 以尾画地——地裂成江（导水入海——大禹治水关键助力） |
| **杀蚩尤与夸父** | 涿鹿之战杀蚩尤（助黄帝）；后杀夸父（《山海经》"杀蚩尤与夸父"——大荒东经版本） |
| **龙之变化** | 有翼之龙——飞腾九天（"应龙于南极"——南方之龙） |

## 故事
1. **涿鹿之战**（黄帝战蚩尤——[人物/蚩尤]）：应龙蓄水攻蚩尤——"应龙杀蚩尤"（黄帝元勋）；
2. **大禹治水**（[人族/大禹治水]）：大禹治水——应龙以尾画地（"禹尽力沟洫，导川夷岳，黄龙曳尾于前"——应龙/黄龙画地）——江河水道成形；
3. **不得复上**：《山海经》"杀蚩尤与夸父，不得复上"——应龙助战后不得回天（"下数旱"——人间大旱——"应龙蛰伏"/"旱龙"意象——旱时请应龙行雨）；
4. 洪荒流：应龙为龙族战神（巫妖大战中龙族立场——部分设定应龙投妖庭/守南方赤水——"南极应龙"）。

## 形象与影响
- **有翼之龙=龙之最高形态**：应龙（双翼）>蛟龙>虬龙>螭龙（[灵兽神兽/龙生九子]龙族谱系——"龙有五形"）；
- **战功赫赫的神龙**：黄帝大将+大禹功臣——"功成弗居"（助战后归隐——洪范"应龙"）；
- **雨神信仰**：应龙=行雨之龙（与龙王（[地祇/龙王体系]）并列——"应龙蓄水"成语）；
- 古建筑"鸱吻"传说（龙生九子——[灵兽神兽/龙生九子]——应龙为九子之首之说）。
