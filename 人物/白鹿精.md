# 白鹿精（比丘国国丈·寿星座骑）

《西游记》中的白鹿精——南极仙翁（寿星）的坐骑白鹿下凡，化作**比丘国国丈**（献"小儿心肝"药引——欲取一千一百一十一个小儿心肝炼药）。被悟空识破、寿星收走（有后台——被主人领回的典型）。"白鹿国丈"是西游"坐骑下凡害民"群像中的一员。来源：《西游记》第78-79回。

## 身份
- **白鹿精**：南极仙翁（[人物/南极仙翁]寿星）的坐骑白鹿（寿星鹿——"仙翁座骑"）下凡为妖；
- **比丘国国丈**：化作比丘国国丈（老头形象）——迷惑国王（"药理献媚"——以"仙丹方"献媚）；
- **白鹿+狐狸**：带了一只狐狸精（后为妖精皇后/"美后"）——结伴为害（"国丈+妖后"组合）；
- **有后台**：寿星座骑——被南极仙翁收走（"主人来领"）。

## 神通
| 神通 | 说明 |
|---|---|
| **变化** | 化比丘国国丈（老道形象——"国丈"官身） |

| **争斗** | 与悟空动手（不敌——现白鹿原形逃） |
| 带狐狸精 | 狐妖为"美后"（妖后——惑主）——后被八戒打死 |

## 故事（西游记·比丘国一难）
1. 比丘国：国丈（白鹿精）迷惑国王——献"小儿心肝做药引"之说——欲取一千一百一十一个小儿（残忍妖行）；
2. 悟空查明：国丈是妖（火眼金睛——"妖气"）——设计救小儿（"小儿藏匿"——悟空调包）；
3. 悟空大战白鹿精——白鹿不敌（现原形遁逃）；
4. **寿星收妖**：南极仙翁驾临（"我的坐骑"）——收走白鹿精（鹿逃回寿星胯下——有后台必存）；
5. 结局：国王被救（"美后"狐狸精被八戒打死）、小儿归还——"药引"骗局揭破。
