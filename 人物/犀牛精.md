# 犀牛精（辟寒·辟暑·辟尘·金平府三犀）

《西游记》中的三只犀牛精（辟寒大王、辟暑大王、辟尘大王）——金平府青龙山玄英洞三妖。假冒佛祖偷香油（"假佛偷油"——每年元宵偷酥合香油），被悟空请二十八宿（井木犴等）擒杀——犀牛角成"贡品"结局。西游"冒充佛门"类妖怪的代表（假佛/假僧——与[人物/黄眉大王]假雷音对照）。来源：《西游记》第91-92回。

## 身份
- **三只犀牛精**：辟寒大王（寒犀）、辟暑大王（暑犀）、辟尘大王（尘犀）——青龙山玄英洞三兄弟；
- 金平府：假冒三尊佛像（现佛身收香油——"假佛"）——每年元宵节收**酥合香油**（"贡油"——三千年一次"佛爷现身"收油）;
- **有后台？** 无明确天庭后台——但被二十八宿（井木犴/角木蛟等）+四木禽星围剿——犀牛角被锯（"落角"结局）——属"被灭的野妖"群。

## 神通
| 神通 | 说明 |
|---|---|
| **假佛现身** | 化三尊佛像（金光佛身——"佛爷驾临"收香油）——骗百姓贡油 |
| **犀角神通** | 犀牛角（独角——"犀角"宝）——放光/攻击（三犀角各有一色"光明"） |
| **元宵收油** | 每年正月十五元宵节——收酥合香油（"三千年油"） |
| **金平府困局** | 掳唐僧（欲蒸食/索取——"佛爷"诱唐僧观灯） |

## 故事（西游记·金平府一难）
1. 金平府：元宵观灯——三"佛"现身（假佛——犀牛精）——唐僧被掳（"拜佛"反被掳）；
2. 悟空追至青龙山玄英洞——三犀牛法力不弱（犀角放光——悟空一时难破）；
3. 上天请**二十八宿**（井木犴等四木禽星/角木蛟等）——天兵围剿（"四木禽星"克犀牛——木克土/犀牛属土？——星宿相克设定）;
4. 三犀牛败——**犀牛角被锯**（"锯角"——犀角成宝进贡——"供品"结局）——三妖伏诛（野妖必死）；
5. 结局：香油案结——金平府平安（"假佛"揭破——百姓醒悟）。
