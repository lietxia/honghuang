# 余元与余化（化血神刀·一脉师徒）

封神演义中的截教师徒——**余元**（截教金墙山白龙潭炼气士——炼器大师）与**余化**（余元之徒——化血神刀的使用者）。余化以化血神刀（沾血即化）连伤周将（哪吒/雷震子——"化血神刀"之威）——被雷震子/杨戬等破（杨戬以八九玄功+变化解刀毒）——余元下山报仇亦败（被惧留孙捆仙绳擒/被斩）。师徒皆上封神榜（余元封"水府星"、余化封"冰消瓦解之神"——版本各异）。来源：《封神演义》第70-74回。

## 一、余化（化血神刀·七首将军）
### 身份
- **余元之徒**——余化——商朝汜水关守将（余元门下弟子——截教三代）；
- 号"七首将军"（"七首"=面有七窍/七条性命之说——封神人物称呼）；
- 封神后封"**冰消瓦解之神**"（一说——[大事件/封神榜三百六十五位正神]）或"化血星"（版本各异）。

### 神通（法宝）
| 神通/法宝 | 说明 |
|---|---|
| **化血神刀** | 至毒宝刀——沾血即化（"化血神刀"——伤者血化为水——无解之毒）——哪吒/雷震子皆中刀（几乎丧命） |
| **催毒咒** | 配合化血神刀的毒咒 |
| 火尖枪/坐骑 | 常规武艺（汜水关先锋） |

### 事迹
1. 汜水关守关——化血神刀连伤周将（哪吒、雷震子中刀——毒性无解——[人物/哪吒]几乎陨落）；
2. 杨戬破法（[人物/杨戬]）：杨戬以八九玄功变化（变为余化之师余元——骗得解药——"杨戬骗药"——亦以变化窃取）——解刀毒;
3. 余化败亡——被杨戬/雷震子等斩杀（汜水关被破）；
4. 封神后封"冰消瓦解之神"（一说）。

## 二、余元（金墙山炼气士·火灵圣母之义兄）
### 身份
- **截教炼气士**——余元——金墙山白龙潭修行（截教三代/四代——炼器之辈）；
- **余化之师**——为徒报仇下山（"师父复仇"）；
- 封神后封"**水府星**"（一说——[大事件/封神榜三百六十五位正神]水府星——"余元水府星"）。

### 神通（法宝）
| 神通/法宝 | 说明 |
|---|---|
| **金光遁（金光咒）** | 护身金光（刀枪不入——"金光护体"） |
| **五云驼** | 坐骑（驼类——行空） |
| 炼宝之术 | 化血神刀的炼制者（炼器大师） |

### 事迹
1. 余化败亡后——余元下山（汜水关）为徒报仇——以金光护体大战周将；
2. 被**惧留孙**（[人物/惧留孙]）以捆仙绳擒拿（金光不敌绳索——"捆仙绳擒余元"）;
3. 余元逃/"余元再战"——终被斩（一说被陆压斩仙飞刀/韦护降魔杵所杀——版本各异）；
4. 封神后封"水府星"（一说——[大事件/封神榜三百六十五位正神]星部）。

## 三、意义
- **化血神刀**：封神最毒的兵刃（"沾血化水"——无解之毒）——与吕岳瘟丹（[人物/吕岳]）、罗宣火烧（[人物/罗宣]）并列"封神三大毒术"；
- **杨戬破法**：化血神刀被杨戬以变化（骗解药）破解——"智力破局"（[人物/杨戬]八九玄功的智勇双全）；
- 师徒相续：余元（炼刀）→余化（用刀）——"师徒兵器传承"（与[人物/太乙真人]→[人物/哪吒]（九龙神火罩）等传承并列）；
- 封神星宿：余元（水府星）/余化（冰消瓦解神）——截教门人封神榜结局（[大事件/封神榜三百六十五位正神]）。
