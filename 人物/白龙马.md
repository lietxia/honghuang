# 白龙马（西海龙王三太子·八部天龙马）

取经团队的"脚力"担当——西海龙王敖闰三太子（小白龙），因烧毁殿上明珠被贬鹰愁涧，化身白马驮唐僧西行，功成后为八部天龙马。取经团队中最"沉默"的一员，却有关键一战（黄袍怪救主）。来源：《西游记》第8/15/30回等。

## 身份
- **西海龙王三太子**（敖烈/玉龙三太子）——西海龙王敖闰之子；
- 因纵火烧毁殿上明珠（忤逆之罪）——被玉帝贬至鹰愁涧（蛇盘山）受苦（"犯了天条"）；
- 吃唐僧白马后被观音点化——**锯角退鳞、化为白龙马**，为唐僧脚力；
- 取经五人组（师徒四众+白龙马）——佛祖钦定的取经团队配置。

## 神通
- **龙之真身**：真身白龙，能腾云驾雾、水中无敌（龙族本命）；
- **化马**：化白龙马——人不可见其真身（唐僧只当是凡马）——仅悟空/观音知其底细（"骑白马的不是王子是龙子"）；
- **关键时刻出手**：奎木狼（黄袍怪）之战——唐僧被变虎、师徒失散——白龙马**现原形战黄袍怪**（虽败，但不屈）——取经路上少数主动战斗的时刻（第30回）；
- 龙族血脉：西海龙宫三太子——与[地祇/龙王体系]（四海龙王）衔接。

## 故事（西游记）
1. **鹰愁涧**：唐僧师徒初遇小白龙（吞了唐僧的白马）——悟空与龙斗（"鹰愁涧"水战——悟空不善水战，唤龙王）——观音锯角退鳞、化白马（"白龙马"）；
2. **驮行**：驮唐僧西行十万八千里——任劳任怨（"白龙马蹄朝西"）；
3. **黄袍怪救主**：唐僧被黄袍怪（奎木狼）变作猛虎、八戒沙僧失散——白龙马夜间现原形与黄袍怪大战（爪抓不敌、被伤）——后劝八戒去请回被逐的悟空（"大师兄，是你误解了"——团队粘合剂的转折点）；
4. **结局**：取经功成——**八部天龙马**（如来：化龙归佛，盘绕灵山华表柱）——"马亦修成正果"。
