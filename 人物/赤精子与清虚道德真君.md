# 赤精子与清虚道德真君（十二金仙二仙）

两位玉虚十二金仙——太华山云霄洞**赤精子**、青峰山紫阳洞**清虚道德真君**。赤精子以阴阳镜照死姚天君、借太极图化殷洪；道德真君传黄天化攒心钉、救杨任、五火七禽扇破红水阵——封神中"借宝+传宝"两位典型金仙。来源：《封神演义》、[法宝/十二金仙法宝]。

## 一、赤精子（太华山云霄洞）
### 身份
- 元始天尊十二金仙之一——居太华山云霄洞——姜子牙师兄（[人物/广成子]十二金仙全表）。

### 神通
| 神通/法宝 | 说明 |
|---|---|
| **阴阳镜** | 至宝——镜有阴阳两面：阴面一晃使人死（魂魄离体）、阳面一晃使人活——落魂阵中照死姚天君（姚宾） |
| **太极图** | 借得开天至宝太极图（太上老君之宝）——殷洪背叛后以太极图化殷洪为飞灰（"太极图包藏天地"） |
| 八卦紫绶仙衣、水火锋、戮目珠等 | 全套金仙装备 |

### 故事
- **十绝阵落魂阵之战**：姚天君拜走姜子牙魂魄（落魂阵——[人物/十天君]）——赤精子以阴阳镜照死姚宾破阵；
- **收殷洪为徒**：殷洪（纣王之子）下山被申公豹所惑叛周——赤精子借太极图将其化灰（"太极图化殷洪"——封神虐心桥段，师门悲剧）。

## 二、清虚道德真君（青峰山紫阳洞）
### 身份
- 元始天尊十二金仙之一——居青峰山紫阳洞——**黄天化、杨任之师**（[人物/黄天化]、[人物/杨任]）。

### 神通
| 神通/法宝 | 说明 |
|---|---|
| **五火七禽扇（五火神焰扇）** | 空中火、石中火、木中火、三昧火、人间火五火齐发——红水阵搧死王奕（红水天君化红灰） |
| **攒心钉**（传黄天化） | 钉杀魔家四将（[人物/黄天化]） |
| **飞电枪**（传杨任） | 枪法如电 |
| **莫邪宝剑** | 传黄天化神剑 |
| **起死回生** | 以仙丹救活被剜目的杨任（眼中长手、手中长眼——[人物/杨任]） |

### 故事
- 收黄天化（黄飞虎之子）为徒（[人物/黄天化]）——黄门忠烈的师门线；
- 红水阵破王奕（五火扇之威）；
- 救杨任（剜目忠臣——"眼中长手、手中长眼"神眼）。

## 洪荒流设定
- 二人皆为玉虚十二金仙（[人物/广成子]篇全表）——金仙级战力；
- 赤精子"借太极图"事件反映十二金仙**借宝机制**（法宝在师尊处、用时借取）；清虚道德真君"五火七禽扇"为后天灵宝名品（[法宝/后天灵宝详录]）；
- 赤精子阴阳镜、道德真君五火扇在封神群仙法宝谱（[法宝/封神群仙法宝]）并列；
- "师门悲剧"（赤精子化殷洪）与"师门温情"（道德真君救杨任/护黄天化）——两位金仙的师生线对照。
