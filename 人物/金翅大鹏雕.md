# 金翅大鹏雕（迦楼罗·云程万里鹏）

上古神禽——凤凰之子（孔宣之弟），佛门护法神鸟（迦楼罗）。西游中占狮驼国称"云程万里鹏"——速度三界罕见（比筋斗云还快），如来亲临才收服。《西游记》战斗力最强的妖怪之一（"狮驼岭三魔"之三）。来源：《西游记》第74-77回、《山海经》大鹏意象、佛教迦楼罗信仰。

## 身份
- **凤凰之子**：上古神禽（一说凤育九雏之一——金翅大鹏即最大者），孔宣之弟（[人物/孔宣]）；
- **佛门护法（迦楼罗）**：金翅大鹏鸟=迦楼罗——佛门八部众之"迦楼罗"（[佛教/罗汉与天龙八部]天龙八部）；
- **如来的舅舅**：因其母=孔雀大明王菩萨（如来曾吞入腹中、认作母亲——"佛母孔雀"）——故大鹏是如来的"舅舅"（辈分之梗）；
- 西游中占**狮驼国**（一国妖怪）——号"云程万里鹏"。

## 神通
| 神通 | 说明 |
|---|---|
| **云程万里** | 一翅九万里、两翅十八万里——速度三界罕见（比孙悟空筋斗云还快——西游速度第一） |
| **食龙神通** | 迦楼罗以龙（大毒蛇/恶龙）为食——一日可啖五百毒龙（佛教迦楼罗本行） |
| **金翅钢爪** | 爪可裂山、擒拿万兽 |
| **化鹏真身** | 现大鹏金翅鸟本相——翼遮天日 |
| **阴阳二气瓶** | 其宝——瓶中阴阳二气、可将人炼化 |

## 法宝
- **阴阳二气瓶**：宝瓶内有阴阳二气——孙悟空被装入后几乎丧命（亏观音杨柳枝顶住+拔毛变金刚钻钻透逃出——"阴阳二气"炼化之威）；
- **金翅翎羽**：羽毛如刀剑（本体装备）。

## 故事（西游记·狮驼岭）
1. **狮驼国建国**：与青狮精（文殊坐骑）、白象精（普贤坐骑）结拜——占狮驼岭、狮驼国——吃尽一国之人（"八百里狮驼岭"最惨烈一难）；
2. **擒悟空**：孙悟空与其赌飞行——被其两翅追上擒拿（筋斗云不敌大鹏翅——"你纵筋斗云十万八千里，我两翅就是十八万里"）；
3. **终极一战**：如来亲临——以"你在此处"诱大鹏入掌（掌中佛国）——现金翅大鹏法相将其收服——大鹏皈依佛门、在如来头顶为护法（"飞禽走兽之王"成佛门护法）。

## 洪荒流设定
- 与孔宣并称"**凤凰二子**"——孔宣被准提收（五色神光）、大鹏后被佛门收（——凤族两大顶级战力归入西方教，[先天三族/凤族]）；
- 混沌初开的先天神禽之一——凤凰（元凤）所生（或凤育九雏）；
- 西游量劫中佛门战力代表——连如来也需亲自出马（"西游最强妖怪之一"）；
- 食龙设定与[地祇/龙王体系]（龙族天敌——迦楼罗食龙）关联。
