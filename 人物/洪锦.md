# 洪锦（五行遁术·龙吉公主之夫）

封神演义中的商降将——洪锦（商朝三山关将领）——后归周——娶**龙吉公主**（瑶池金母之女）为妻（"天定姻缘"——[人物/龙吉公主]）。擅**五行遁术**（旗门遁）——封神后封"**先天玄都护法**"（一说水德星君/护法神——版本各异）。来源：《封神演义》第65-66/87回。

## 身份
- **商朝三山关将领**——洪锦——后归周（被擒后归顺）；
- **龙吉公主之夫**：娶瑶池金母之女龙吉公主（"招洪锦为驸马"——天定姻缘——[人物/龙吉公主]）——夫妻同助周；
- 封神后封"**先天玄都护法**"（部分版本"水德星君"——版本各异——[大事件/封神榜三百六十五位正神]群星/护法）；
- **五行遁术高手**：以旗门遁（五行遁术）闻名——封神中极少数擅长"遁术战"的将领。

## 神通（法宝）
| 神通/法宝 | 说明 |
|---|---|
| **五行遁术（旗门遁）** | 以旗门施展五行遁（金木水火土遁——"旗门遁"——[神通/天罡三十六法]五行大遁的战场版）——可引水/设阵困敌（"旗门遁"布阵） |
| **遁术行军** | 善遁术战术（埋伏/突袭——以遁隐设伏） |
| **镇压水术** | 水系法术（旗门引水） |

## 故事（封神演义）
1. **助商讨周**：洪锦奉命征西（三山关——商军伐西岐）；
2. **龙吉公主招亲**：洪锦战败被擒——月老红线（天定姻缘——[人物/龙吉公主]"红鸾星"）——被招为驸马（与龙吉公主成婚——"天作之合"——[地祇/月老与婚恋神]）；
3. **归周**：自此为周营大将（夫妻同助姜子牙）；
4. **万仙阵陨落**：万仙阵中——洪锦/龙吉公主被金灵圣母（[人物/金灵圣母]）所杀（夫妻同亡——"阵亡鸳鸯"）；
5. **封神**：封"先天玄都护法"（版本各异——[大事件/封神榜三百六十五位正神]）。
