# 妲己（苏妲己·千年狐妖·红颜祸水）

中国文学史上最著名的"红颜祸水"——商纣王妃子，实为女娲派下乱商的轩辕坟三妖之首（九尾狐狸精附身）。封神演义第一妖妃，也是"女人误国"叙事的经典符号。来源：《封神演义》、历史原型考据（冀州苏氏之女苏妲己）。

## 身份
- **历史原型**：冀州侯苏护之女苏妲己——绝世美人，被商纣王纳入宫中为妃（《国语》《史记》有"妲己"记载）；
- **封神设定**：女娲娘娘派轩辕坟三妖（九尾狐狸精、九头雉鸡精、玉石琵琶精）入宫乱商——**九尾狐狸精附身妲己**，祸乱商朝；
- 中国古代"红颜祸水"的典型代表——"妲己亡商"叙事核心（[人物/纣王与商周群臣]）；
- 狐妖一脉：千年九尾狐——妖族顶级大妖。

## 神通
| 神通 | 说明 |
|---|---|
| **狐媚之术** | 千年九尾狐之魅惑——纣王言听计从、朝纲败坏 |
| **变化** | 附身妲己、可化他人形貌（惑主之变） |
| **法术蛊惑** | 设计酷刑（炮烙/虿盆）、谗言害忠——法术+权谋并施 |
| **九尾真身** | 被擒时现九尾狐原形（斩仙飞刀斩之） |

## 故事（封神演义）
1. **女娲之命**：纣王女娲庙题诗亵渎（[人物/女娲]）——女娲命轩辕坟三妖入宫"祸乱商朝"（原意让其乱商，但妲己行事太过、造无边杀孽——最终女娲亦弃之，"用妖反被妖噬"）；
2. **入宫惑主**：附苏妲己之身入宫——纣王言听计从；
3. **残害忠良**：害姜皇后（剜目炮烙）、逼黄飞虎之妻贾氏坠楼、设炮烙之刑、造虿盆、酒池肉林、比干挖心（[人物/比干]）、梅伯炮烙——商朝覆灭的最大推手；
4. **结局**：周军入朝歌——纣王自焚于摘星楼；妲己被擒——其妩媚令行刑者不忍下手——姜子牙以**斩仙飞刀**（陆压所赠）斩之（斩其狐妖真身）。

## 洪荒流设定
- 妲己为九尾狐妖（妖狐一脉）——九尾狐在妖族中为顶级大妖（与九尾天狐一脉相连）；
- 女娲派三妖乱商——"祸水"之说源此（女娲与狐妖的因果：女娲弃妲己→妲己怨女娲——洪荒流常见因果线）；
- 部分设定：妲己即九尾天狐/苏妲己转世——与妖庭（帝俊太一）的狐族一脉有渊源；或神化为"狐仙"之祖（[志怪精怪篇]狐仙文化——"狐狸精"意象之祖）。
