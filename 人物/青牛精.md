# 青牛精（独角兕大王）

太上老君的坐骑——一头青牛（独角兕），偷带金刚琢下界为妖，占金兜山金兜洞，号**独角兕大王**。西游中连如来都不敢硬接其法宝（怕老君面子），是"有后台妖怪"的顶级代表。来源：《西游记》第50-52回（金兜洞）。

## 身份
- **太上老君坐骑**：一头青牛（独角兕——上古异兽"兕"）——随老君修行多年；
- 下界为妖：见唐僧师徒西行（"金丹砂"诱因）——老君疏忽（看守童子睡着）——青牛偷**金刚琢**下界；
- 占金兜山金兜洞——号**独角兕大王**——八十一难大难之一（"金兜山"难）；
- **洪荒流**：老君门下灵兽——实力接近金仙（坐骑天团顶级）。

## 神通
| 神通 | 说明 |
|---|---|
| **金刚琢神通** | 祭出金刚琢**套万物**——刀枪剑戟、水火、法宝皆被套走——连金箍棒都被套去（"无物不套"） |
| **牛魔大力** | 青牛蛮力无边——与悟空斗武不落下风 |
| **变化** | 化道人形迷惑唐僧师徒（化村庄叟翁设局） |

## 法宝
- **金刚琢**：太上老君之物——老子"化胡为佛"时随身之宝（"过函谷关之宝"）——曾用其砸孙悟空（大闹天宫时老君抛琢砸悟空）、套金箍棒；
- 青牛偷此宝下界——天下法宝皆被套走——如来亦不敢硬接（说"我认得他"但不敢点破——老君坐骑）——只能以金丹砂相诱（金丹砂被套）；
- 最终老君亲临——以**芭蕉扇**（收放金刚琢之宝）一扇——金刚琢归位——青牛现原形收回（"芭蕉扇收金刚琢"——老君两宝配合）。

## 故事（西游记·金兜洞）
1. 唐僧师徒过金兜山——八戒化斋入洞被擒——悟空寻妖大战；
2. 金刚琢套走金箍棒——悟空上天请托塔天王、哪吒、火德星君、水德星君等——法宝兵器尽被套走（天兵法宝全灭）；
3. 如来识破是青牛——但不敢直说（怕老君面子——"这妖怪来历我知，但不可说"）——暗示悟空找太上老君；
4. 老君以芭蕉扇一扇——金刚琢归位——青牛现原形——收归兜率宫（"有后台的妖怪被救走"典型）。

## 洪荒流设定
- 老君坐骑——实力在"坐骑天团"（青狮/白象/大鹏/青牛/九灵元圣等）中靠前；
- **金刚琢**是老君顶级灵宝——青牛凭此宝连圣人之下的法宝都不惧（"圣人之宝vs圣人之宝"）；
- 西游量劫中：青牛一难表面为考验——实为**太上老君向佛门展示道门底蕴**（佛道暗争的缩影——[大事件/西游取经与佛门东扩]）；
