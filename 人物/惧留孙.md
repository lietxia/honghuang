# 惧留孙（夹龙山飞云洞·土行孙之师·拘留孙佛）

阐教玉虚宫元始天尊座下**十二金仙**之一——居夹龙山飞云洞——**土行孙之师**。善**捆仙绳**（捆仙索——缚敌至宝）。封神后入佛门为"**惧留孙佛**"（拘留孙佛——过去七佛之一——[佛教/佛]过去七佛）——"佛本是道"的十二金仙桥接人物之一（与文殊/普贤/慈航并列）。来源：《封神演义》、[佛教/佛]。

## 身份
- **十二金仙之一**：玉虚宫元始天尊座下（居夹龙山飞云洞——[法宝/十二金仙法宝]惧留孙）——玉虚十二仙；
- **土行孙之师**：土行孙（[人物/土行孙]——地行术）的授业恩师；
- **捆仙绳之主**：以**捆仙绳**闻名（缚敌至宝——捆仙绳/捆仙索——一掷即捆）；
- **惧留孙佛**：封神后入佛门——为**惧留孙佛**（拘留孙佛——过去七佛第一佛——[佛教/佛]过去七佛"拘留孙佛"——"惧留孙"即"拘留孙"音译）——佛道桥接人物（[教派/西方教与佛教]）。

## 故事（封神演义）
1. **土行孙下山**：土行孙（徒弟）下山助商（被申公豹说动——[人物/申公豹]）——地行术+捆仙绳闹周营（捆哪吒/杨戬）；
2. **惧留孙收徒**：惧留孙亲自出山——**指地成钢**破地行术（土行孙入地不得——被擒）——收回徒弟（"师父克徒弟"——土行孙归周）；
3. **捆仙绳定敌**：惧留孙以捆仙绳助周——捆敌将（捆马元/捆余元等——多场战役的"定盘"法宝）；
4. **结局**：封神后入佛门——惧留孙佛（拘留孙佛——过去七佛之首——[佛教/佛]过去七佛——"佛本是道"十二金仙入佛代表）。
