# 太乙真人（乾元山金光洞·哪吒之师）

阐教玉虚宫元始天尊座下**十二金仙**之一——居乾元山金光洞。哪吒之师（灵珠子投胎陈塘关的送子仙人）——封神中最"护短"的师父：二救哪吒、以莲花重塑其身。道教中与太乙救苦天尊（东极青华大帝）连系。来源：《封神演义》、道教太乙信仰。

## 身份
- **十二金仙之一**：玉虚宫元始天尊座下（居乾元山金光洞）——[法宝/十二金仙法宝]；
- **哪吒之师**：灵珠子转世→哪吒——太乙为护道人（[人物/哪吒]）；
- 封神中最"护短"的师父——二救哪吒（闹海杀敖丙、剔骨还父后莲花塑身）；
- 道教关联：太乙救苦天尊（东极青华大帝）——太乙真人被认为即其化身之一（[道教神佛/道教神谱详录]太乙救苦天尊）。

## 故事（封神演义）
1. **灵珠子转世**：太乙将灵珠子送至陈塘关李靖家——投胎为哪吒（"哪吒出世""师父送来"）；
2. **护短第一人**：哪吒闹海打死敖丙（[地祇/龙王体系]）、射杀石矶门人——太乙皆为其兜底——石矶娘娘来寻仇——太乙以九龙神火罩将其炼死（"护短护到门人无影"）；
3. **莲花化身**：哪吒剔骨还父、剔肉还母身亡后——太乙以莲藕莲花塑身——使其复活（"莲花化身"——无魂无魄、免疫摄魂，[人物/哪吒]）；
4. **传授三头六臂**：现三头六臂法身——赐多宝——使哪吒战力倍增；
5. 封神后随元始修行——为阐教中守护弟子的"师长"型金仙。

## 洪荒流设定
- 太乙真人为哪吒的"护道人"——地位在金仙中中上——胜在法宝多（九龙神火罩、乾坤圈等全套武装哪吒）；
- 与**乾元山金光洞**结缘——道门核心"教内护法"（哪吒全套装备的"武器库"师父）；
- 太乙救苦天尊关联：东极青华大帝（坐骑九灵元圣）——道教幽冥救苦与太乙真人的名号联动（[人物/九灵元圣]）。
