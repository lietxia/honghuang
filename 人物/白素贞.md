# 白素贞（白娘子·千年白蛇·义妖）

白蛇传女主角——千年白蛇修炼成人形，有情有义的"义妖"代表，中国人心目中"妖亦有情"的最高化身。从"害人蛇妖"到"至情女神"的形象演变（唐→宋→明→清），见证中国文化对"人妖恋"母题的态度变迁。来源：《白蛇传》各版本、[上古神话典故/白蛇传专篇]。

## 身份
- **千年白蛇精**（峨眉山/青城山得道）——道行七千九百余年（戏曲"双蛇斗"版本）；
- 白娘子白素贞——许仙之妻、许仕林之母、小青之姐（[人物/许仙]、[人物/小青]）；
- **形象演变**：
  - 唐代"美女蛇"（害人性命——原始形象）；
  - 宋代《西湖三塔记》（白蛇妖——镇塔）；
  - 明冯梦龙《白娘子永镇雷峰塔》（妖性未除但存善念——"妖本恶"仍为主）；
  - 清《义妖传》（"**义妖**"——至情至性——形象彻底翻案）；
  - 现代影视（"有情有义"女神——白娘子成爱情象征）。

## 神通
| 神通 | 说明 |
|---|---|
| **水漫金山** | 召东海龙宫虾兵蟹将、以法力发大水淹金山寺（"水漫金山"——故事最高潮） |
| **腾云变化** | 化人形（绝色女子）、驾云而行 |
| **盗仙草** | 上天庭盗取灵芝仙草（与白鹤童儿大战——昆曲"求草"）救许仙 |
| **悬壶济世** | 镇江开"保和堂"药铺——以法力行医（端午雄黄酒现形等情节） |
| **道行高深** | 与法海斗法前几日不落下风——惜产后虚弱被收 |

## 故事
1. **断桥借伞**：西湖同舟避雨与许仙定情（"游湖借伞"——[人物/许仙]）；
2. **镇江行医**：保和堂夫妻悬壶济世（"义妖"行善）；
3. **端午现形**：雄黄酒现蛇形吓死许仙→盗仙草救夫（"盗草"）；
4. **水漫金山**：法海扣留许仙（金山寺）→白娘子水漫金山（触犯天条——"水漫金山"）；
5. **断桥重逢**：断桥相会（戏曲经典）→产子许仕林→被法海金钵镇压雷峰塔下；
6. **结局**：许仕林中状元祭塔救母（文曲星下凡）——一家团圆（《雷峰塔奇传》《白蛇全传》）；杨柳青年画更有"小青掀塔"版本（[人物/小青]）。

## 象征
- **"义妖"**：妖而重情重义超越凡人——中国"人妖恋"母题最高代表（突破人妖二元对立的封建观念）；
- 许仙的"凡人视角"对照：妖的深情vs人的疑惧（[人物/许仙]"人妖殊途"）；
- 现代解读：白娘子成"女性自主/跨物种爱情"的象征（[上古神话典故/白蛇传专篇]影响）。
