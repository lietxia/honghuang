# 法海（金山寺禅师·卫道者）

白蛇传中的"卫道者"——拆散白许姻缘的金山寺高僧。从"降妖除魔"的正义形象到被民众嫌恶的反派（"法海你不懂爱"现代梗）——白蛇故事中最具争议的人物。历史原型为唐代金山寺开山祖师法海禅师（裴头陀）。来源：《白蛇传》各版本、金山寺史、[上古神话典故/白蛇传专篇]。

## 身份
- **镇江金山寺住持**（高僧）——金山寺开山祖师（"金山"之名源于法海开山得金）；
- **历史原型**：唐代**法海禅师**（裴头陀——唐宰相裴休之子——法名法海——建金山寺——开山得金"金山"得名）——民间故事将古德改编为"多管闲事"的卫道僧（名僧蒙冤的著名案例）；
- **《白蛇全传》设定**：法海前世为**蛤蟆精**（蟾蜍精）——其舍利子/仙丹被白蛇盗走——怀恨在心——转世报复白素贞（民间"因果报应"自洽叙事——给法海的"前世理由"）——后期版本恶意来源的合理化。

## 神通
| 神通 | 说明 |
|---|---|
| **金钵（法钵/紫金钵盂）** | 镇妖法宝——将白娘子收于钵中、镇压雷峰塔下 |
| **佛法高深** | 识破白蛇原形（"人妖殊途"）、扣留许仙、水漫金山时稳坐金山寺（袈裟护山不被水淹） |
| **禅杖/袈裟** | 降魔法器（戏曲"仇王府"等情节） |

## 故事
1. **识破蛇妖**：识破白娘子乃蛇妖——劝说许仙（端午雄黄酒之计）；
2. **扣留许仙**：许仙被骗至金山寺软禁（许仙"出家"假象）——白娘子相救引发"水漫金山"（[人物/白素贞]）；
3. **水漫金山大战**：白蛇小青召水族淹金山——法海以袈裟护寺（虾兵蟹将无功而返——"水涨塔高"）；
4. **收镇白蛇**：白娘子产子后被法海以金钵收服——镇压**雷峰塔**下；
5. **结局**：部分版本法海因私怨（前尘蛤蟆精）被贬/避入蟹壳（"法海躲进螃蟹壳"民间传说——蟹黄即法海所化！）；《青蛇》等现代改编重塑法海形象（"法海你不懂爱"梗——卫道vs真情的悖论）。

## 争议
- **早期（冯梦龙版）**：法海为"点醒世人"的正面人物（"奉劝世人休爱色"——封建卫道士视角）；
- **后期（清《义妖传》后）**：被民众嫌恶——"降妖"实为拆散真情（"法海不懂爱"现代梗——[上古神话典故/白蛇传专篇]形象演变）；
- **佛道与民间立场张力**：戒律（人妖不能通婚）vs真情（妖亦有情）——白蛇故事核心冲突——法海是"规则"的化身（[人物/白素贞]"义妖"的对立命题）。
