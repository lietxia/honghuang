# 伯邑考（文王长子·琴艺圣人·紫微星君）

西伯侯姬昌（周文王）嫡长子——伯邑考——著名的"孝子"与"琴圣"。为救父（文王被纣王囚禁羑里）携宝进贡朝歌——因妲己陷害被纣王残忍杀害（做成肉饼赐文王——文王忍痛食子）。封神后封"**中天紫微大帝**"（紫微星——四御之一——[道教神佛/三清与四御]紫微）——"孝子感动天"与"天命之子"的双重象征。来源：《封神演义》第19-22回。

## 身份
- **周文王（姬昌）嫡长子**——伯邑考（"邑考"=封邑之名——文王长子、太子——[人物/纣王与商周群臣]姬昌）；
- **琴艺圣人**：善琴（"琴艺通神"——七弦琴——抚琴有"凤凰来仪"之象——[上古神话典故/治水与发明]礼乐文化）；
- **孝子典范**：为救被囚羑里的父亲——携"七香车、醒酒毡、白面猿猴"三宝进贡朝歌（"献宝救父"）；
- 封神后封"**中天紫微大帝**"（紫微星——四御之一——万星帝主——[道教神佛/三清与四御]紫微北极大帝——"紫微垣"之主的封神版）；
- 周朝"天命正统"的牺牲者——"长兄之殇"成周兴商亡的关键节点。

## 故事（封神演义）
1. **献宝救父**：文王被囚羑里七年——伯邑考携三宝进京（"七香车/醒酒毡/白面猿猴"）——请求代父受罪/释放文王；
2. **妲己学琴**：妲己见伯邑考俊美且琴艺绝世——以"学琴"为名接近——意图勾引（"妲己戏伯邑考"）——伯邑考正色拒绝（琴艺止于礼）；
3. **构陷**：妲己恼羞成怒——诬伯邑考调戏（"纠僵"）——纣王怒——将伯邑考剁成肉酱；
4. **文王食子**：纣王以伯邑考肉做成肉饼赐文王——文王早知是子（占卜）/咽泪食下（"食子之痛"）——纣王以为文王昏聩——释放文王（文王归周——忍辱负重成兴周根基）；
5. **封神**：封神后封"**中天紫微大帝**"——紫微星君（万星帝主——四御之一——[道教神佛/三清与四御]）。

- **孝道极致**：伯邑考="以死全孝"（献宝救父→代父受难→忍辱而死）——"孝子"楷模（与[人物/沉香]救母、[人物/许仕林]祭母并列"孝道三子"）；
