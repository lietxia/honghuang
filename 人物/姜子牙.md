# 姜子牙（姜太公·飞熊·封神执掌者）

封神核心人物——元始天尊门下弟子，持**封神榜**代天封神、辅佐武王伐纣兴周灭商。渭水垂钓"愿者上钩"、姜太公在此"百无禁忌"——中国民间影响最深的神话人物之一。来源：《封神演义》、真实历史（齐国始祖，西周开国功臣）。

## 身份
- **阐教玉虚宫元始天尊座下弟子**——七十二岁上山修道、三十二年后下山（"七二上山、三二下山"——大器晚成）；
- **封神执掌者**：持封神榜、打神鞭——代天封三百六十五位正神（[大事件/封神榜三百六十五位正神]）；
- **西周丞相**——辅佐武王伐纣——开周朝八百年基业；
- 封神后未位列正神（一说"姜太公在此，百无禁忌"）——封齐侯、为齐国始祖（真实历史：姜太公吕尚）。

## 法宝
| 法宝 | 说明 |
|---|---|
| **封神榜** | 代天封神之名册——榜上有名者死后封神——姜子牙执掌权柄（八部正神，[大事件/封神榜三百六十五位正神]） |
| **打神鞭** | 专打八部正神——封神榜上有名者皆受鞭挞；对未上榜仙神威力大减（[法宝/后天灵宝详录]） |
| **四不相** | 始麒麟之子的神兽坐骑——元始天尊所赐——冲锋陷阵（[灵兽神兽/坐骑谱]） |
| **杏黄旗**（中央戊己杏黄旗） | 先天五方旗之一——防御至宝——展开万法不侵、诸邪退避（[法宝/十大先天灵宝榜]五方旗） |

## 事迹
1. **渭水垂钓**：渭水直钩垂钓（"愿者上钩"）——遇文王——拜为丞相——号"太公望"（文王访贤）；
2. **辅周伐纣**：辅佐周武王伐纣——遭三十六路兵马征讨（商军/截教轮番来攻）——以封神榜招揽天下英才（杨戬/哪吒/雷震子/黄天化等）；
3. **封神大战**：亲自上阵——虽有打神鞭但法力不及截教仙家——常需杨戬、哪吒等保护（"凡人之躯、神仙之命"）；
4. **封神台**：灭商后封神台封**三百六十五位正神**（[大事件/封神榜三百六十五位正神]）——自封齐侯、归国享人间富贵；
5. **后世**：尊为"姜太公在此，百无禁忌"的镇宅神（民间门神/镇宅符）。
