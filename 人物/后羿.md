# 后羿（大羿·射日英雄）

上古射日英雄——帝尧时期的神射手，箭射九日、为民除害，嫦娥之夫（嫦娥奔月的男主角）。洪荒流中常设为巫族大巫（射日弓），射日之仇是巫妖大战的导火索。来源：《淮南子》《山海经》、[大事件/后羿射日与夸父逐日]。

## 身份
- **上古射日英雄**：五帝时（帝尧时期）的神射手——善射无敌；
- **有穷氏首领**：嫦娥之夫（嫦娥奔月的男主角）；
- 神话中的"**大羿**"（射日）与夏代"后羿"（代夏政）常被混同——本文以神话大羿为主（考据见[上古神话典故/英雄与征战]）；
- **洪荒流**：巫族大巫（射日弓）——与夸父并列为巫族英雄。

## 神通
| 神通 | 说明 |
|---|---|
| **射日神箭** | 一箭接一箭射落天上九日（十日金乌）——箭法通神 |
| **神射** | 百步穿杨、箭无虚发——弓术三界罕见 |
| **巫族肉身**（洪荒流） | 巫族大巫——力大无穷、肉身强横 |
| **射术通神** | 箭可射日月星辰——惊天地泣鬼神 |

## 法宝
- **射日弓（彤弓）**：帝俊赐予的神弓（一说后羿自炼）——一弓可射日；
- **射日箭（素箭/金箭）**：箭矢锋利无匹——一箭一日；
- **昆仑不死药**：射日功成后西王母所赐（后被嫦娥偷吃——[人物/嫦娥]）。

## 故事
1. **十日并出**：帝俊之子十日金乌（太阳）同时升空——大地焦枯、草木皆焚（[人物/妖族天庭]十日）；
2. **后羿射日**：帝尧命后羿射日——连射九箭射落九日（第九日箭被尧偷偷撤下，故留一日）——万民得救（"射日"神话核心，[大事件/后羿射日与夸父逐日]）；
3. **除害**：射杀凿齿、九婴、大风、封豨、修蛇等凶兽（《淮南子》"上射十日而下杀猰貐"）——为民除害（[凶兽/其他凶兽]）；
4. **嫦娥奔月**：西王母赐不死药——嫦娥偷吃飞升月宫——后羿自此与妻永隔（部分版本：逄蒙逼迫）。

## 洪荒流设定
- 后羿为**巫族大巫**——射日射的是妖庭金乌（帝俊之子）——射日之仇直接引爆巫妖大战（[时间线/巫妖大劫]）；
- 嫦娥奔月的悲剧——被赋予"巫妖之战下的人妖悲歌"色彩；
- 射日弓、射日箭为顶级神兵——后羿陨落后遗失（或被收归天庭）；
- 夸父逐日（夸父因逐日渴死）与后羿射日——巫族与太阳的"双雄悲歌"（[大事件/后羿射日与夸父逐日]）。
