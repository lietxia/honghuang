# 鲲鹏（北冥之鲲·妖师）

《庄子·逍遥游》的巨兽——"北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。"洪荒流中为**妖师鲲鹏**——混沌/先天大妖、妖族天庭军师级存在，创妖文妖典、参与布周天星斗大阵，地位与帝俊太一并列。来源：《庄子·逍遥游》《山海经》（北海之鲲）、洪荒流设定。

## 身份
- **《庄子》巨兽**：北冥之鲲化鹏——"鹏之背，不知其几千里也；怒而飞，其翼若垂天之云"（逍遥游开篇）；
- **妖师鲲鹏**（洪荒流）：混沌/先天大妖——妖族天庭的军师级存在（"妖师"）；
- 著《妖典》（创妖族文字）——妖族文明的奠基者之一；
- 与帝俊、太一并列为妖族巨头——后觊觎河图洛书（欲叛妖庭），巫妖大战中叛离（版本各异）。

## 神通
| 神通 | 说明 |
|---|---|
| **鲲鹏变化** | 化鲲则入水、化鹏则飞天——水陆空三栖（天地间极少数双形态巨兽） |
| **扶摇万里** | 鹏翼若垂天之云——一飞九万里（"抟扶摇而上者九万里"） |
| **吞海** | 鲲之巨口吞海量——鲸吞之势（"鲲"即鱼子/大鱼） |
| **极速** | 飞行速度洪荒顶尖——媲美金翅大鹏（"鹏程万里"语出鲲鹏） |
| **妖文神通** | 妖师所创妖文——妖族文字/咒语体系（妖文成阵） |

## 法宝/势力
- **妖师宫**（道场）：北冥妖师宫——妖文妖典之藏（北冥妖族大本营）；
- **河图洛书**（觊觎）：欲夺帝俊河图洛书未遂（巫妖大战中趁乱欲夺——叛离妖庭诱因）；
- **周天星斗大阵**：妖庭镇族大阵——鲲鹏参与布阵（[阵法/周天与都天神煞]）；
- 北冥妖族：巫妖大战后鲲鹏遁北冥自成一系。

## 故事（洪荒流）
1. 混沌初开，鲲鹏于北冥化形——先天大妖，尊为"妖师"；
2. 帝俊立妖庭——鲲鹏为军师：创妖文、布周天星斗大阵——功勋卓著；
3. 巫妖大战前：鲲鹏觊觎河图洛书欲叛（部分版本：趁乱夺宝逃走，或临阵叛离妖庭——"妖师叛妖庭"）——妖族败亡重要原因之说；
4. 巫妖大战后妖族衰落——鲲鹏遁入北冥自成一系（北冥妖族），与妖族余部若即若离；
5. 后世"鲲鹏"成志向远大象征——"燕雀安知鸿鹄之志"（大鹏意象之源）。
