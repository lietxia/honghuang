# 九灵元圣（九头狮子·竹节山九曲盘桓洞主）

太乙救苦天尊（东极青华大帝）的坐骑——**九头狮子**。因狮奴偷喝轮回琼液沉睡，九头狮子趁机下凡为妖，据玉华国竹节山九曲盘桓洞。西游中**实力最强的妖怪之一**（十大妖怪之首）——纯凭肉身神通碾压取经团队。来源：《西游记》第88-90回（玉华县一难）。

## 身份
- **太乙救苦天尊坐骑**——九头狮子（九灵元圣）——[道教神佛/道教神谱详录]太乙救苦天尊（骑九头狮子）直接对应；
- 下凡原因：照管坐骑的狮奴偷喝天尊的**轮回琼液**、沉睡三天（凡间三年）——九头狮子趁机下凡；
- 据玉华国竹节山九曲盘桓洞——黄狮精等的"祖爷"（徒子徒孙六个小狮妖：猱狮/雪狮/狻猊/白泽/伏狸/摶象）；
- 西游中**实力最强妖怪之一**（《西游记》十大妖怪之首——纯战力凌驾青牛精/金翅大鹏等法宝型妖王）。

## 神通（肉身神通第一）
| 神通 | 说明 |
|---|---|
| **九头真身** | 现出九颗狮子头——张口一吸便擒人——"一嘴噙住八戒、一嘴噙住沙僧、一头撞退悟空"——无需法宝、纯凭肉身神通 |
| **神通广大** | 仅凭肉身之力碾压取经团队——悟空亦不能敌（只能请其主人）——“无宝胜有宝”的顶级妖王 |
| **狮妖之王** | 徒子徒孙尊其为祖爷——竹节山狮妖体系（黄狮精偷兵开"钉钯会"引出） |

## 故事（西游记·玉华县一难）
1. 玉华县：黄狮精偷走唐僧师徒的兵器（开"钉钯会"请妖）——被悟空等打死；
2. **九灵元圣报仇**：九灵元圣为黄狮精报仇出马——现九头真身——一口一个将唐僧、八戒、沙僧及玉华国国王王子尽数擒入洞中——悟空无法破敌；
3. 悟空寻得端倪（九灵元圣乃太乙救苦天尊坐骑）——上天请来天尊；
4. 天尊以**元神出窍**收服九灵元圣（被天尊喝斥——"孽畜！还不现形！"——挨了狮奴一顿责打）——带回天界（"有后台的妖怪被救走"典型）。
