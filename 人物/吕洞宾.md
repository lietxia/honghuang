# 吕洞宾（纯阳祖师·剑仙之祖·八仙核心）

道教全真派北五祖之一（东华帝君→钟离权→吕洞宾→刘海蟾→王重阳）——八仙中知名度最高、影响最大的神仙（[地仙谱·八仙]）。号**纯阳子**——"吕祖"——剑仙之祖、酒仙之祖——"狗咬吕洞宾，不识好人心"的国民神仙。传为唐末进士——得汉钟离（钟离权）点化（"黄粱一梦"）成仙。来源：道教全真派文献、八仙传说（[地仙谱·八仙]）、百度百科。

## 身份
- **八仙之一**：八仙中核心（吕洞宾/汉钟离/铁拐李/张果老/何仙姑/蓝采和/韩湘子/曹国舅——[地仙谱·八仙]八仙总表）；
- **全真北五祖**：全真道祖师谱系（东华帝君→钟离权→吕洞宾→刘海蟾→王重阳——[教派/道门三教]全真派）——北五祖第三位（"纯阳祖师"——全真五祖之一）；
- **纯阳子**：号纯阳子（"纯阳"=纯阳之体/纯阳剑）——唐代诗剑双绝（传为唐末进士吕岩——"吕洞宾"）;
- **剑仙之祖**：剑术通神（"纯阳剑"——[法宝/兵器谱]）——后世剑仙/剑侠奉为鼻祖（[概念/剑仙与飞剑]）；
- 三教合流：儒家（进士）、道家（全真祖）、民间（神仙）——"三教归一"的象征人物。

## 故事（八仙传说）
1. **黄粱一梦**：长安酒肆遇钟离权——钟离权让他做饭时枕枕入梦——梦中状元及第/宦海浮沉/儿孙满堂/死生轮回——醒来黄粱未熟——悟"功名富贵皆虚幻"——拜师出家（"黄粱一梦"——[地仙谱·八仙]吕洞宾）；
2. **十试吕洞宾**：钟离权以十件事试探（贪财/好色/嗔怒等）——吕洞宾一一过关（"十试全过"——成仙考验）；
3. **三醉岳阳楼**：度化岳阳楼酒客（"三醉岳阳人不识，朗吟飞过洞庭湖"——吕祖神诗）；
4. **度人传说**：点化刘海蟾（弟子——北五祖第四）、度何仙姑等（八仙团队）；
5. 民间形象："狗咬吕洞宾"（成语——吕祖度狗——"不识好人心"）；"吕洞宾偷桃"（戏谑形象）——国民神仙。
