# 乌云仙（金须鳌鱼·随侍七仙之首）

截教通天教主座下**随侍七仙之首**（随侍七仙：乌云仙/金箍仙/毗卢仙/金光仙/虬首仙/灵牙仙/长耳定光仙——[人物/截教群仙]随侍七仙）——原身为**金须鳌鱼**（金须金睛鳌鱼修行得道）。万仙阵前以混元锤连败广成子/赤精子（"混元锤打金仙"）——后被准提道人以六根清净竹钓走（"钓金鳌"）——渡入西方（"乌云仙入西"）。来源：《封神演义》第82-83回。

## 身份
- **随侍七仙之首**：通天教主座下随侍七仙（亲随弟子——地位仅次于四大弟子——[人物/截教群仙]随侍七仙）；
- **金须鳌鱼**：原身金须金睛鳌鱼（鳌鱼——金须——[灵兽神兽/山海经异兽图鉴]鳌——"独占鳌头"）；
- **好战骁勇**：万仙阵前主动请战——连败阐教两位金仙（广成子/赤精子——[人物/广成子]、[人物/赤精子与清虚道德真君]）；
- 结局：被准提渡入西方（"六根清净竹钓金鳌"——[人物/西方二圣]准提）。

## 神通（法宝）
| 神通/法宝 | 说明 |
|---|---|
| **混元锤** | 法宝锤——"混元锤"（重锤——打金仙——广成子/赤精子皆被其所败） |
| **金须鳌鱼身** | 原形金须金睛鳌鱼（龙鱼之属——力大） |
| 六根清净竹（克） | 被准提六根清净竹钓走（"封人六识"——[法宝/十大先天灵宝榜]六根清净竹——被钓即失识）

## 故事（封神演义）
1. **万仙阵前请战**：万仙阵大战前——乌云仙（随侍七仙之首）持混元锤出战；
2. **连败二金仙**：先打广成子（[人物/广成子]——金仙之首——败走）；再打赤精子（[人物/赤精子与清虚道德真君]——亦败）——"混元锤连败两金仙"——截教高光时刻；
3. **准提钓鳌**：西方教准提道人（[人物/西方二圣]）出手——以**六根清净竹**作钓竿（钓钩钓金须鳌鱼）——乌云仙现原形被钓（"准提钓鳌"——封神名场面——[法宝/十大先天灵宝榜]六根清净竹）；
4. **渡入西方**：乌云仙被准提渡入西方（"乌云仙入西"——截教门人被渡的最典型案例——[教派/西方教与佛教]）。

## 相关设定
- **准提钓鳌**："六根清净竹钓金须鳌鱼"——封神"渡人"叙事的经典画面（西方教"渡有缘人"——[人物/西方二圣]准提"有缘皆渡"）；
- 随侍七仙结局各异：乌云仙（被渡西方）、金光仙/虬首仙/灵牙仙（被收为坐骑——[人物/文殊广法天尊与普贤真人]）、长耳定光仙（叛教——[人物/长耳定光仙]）、金箍仙（逃/隐）——"七仙七命"（[人物/截教群仙]）；
- 鳌鱼意象："独占鳌头"（鳌鱼——[灵兽神兽/山海经异兽图鉴]鳌）——金须鳌鱼=龙属（"鱼跃龙门"前的形态）。
