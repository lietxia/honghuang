# 九头虫（碧波潭万圣龙王之婿）

《西游记》中的九头虫（九头怪）——碧波潭万圣龙王之婿（"驸马"），盗金身佛宝舍利、大闹祭赛国金光寺——西游中"无后台但有奇技"的妖怪之一（被二郎神+悟空联军击败，逃往北海不知所踪——少见的"逃遁而非被收/被灭"结局）。来源：《西游记》第62-63回。

## 身份
- **九头虫**：九头怪物（九个头——"九头鸟"式妖怪——九凤/鬼车关联——[凶兽/其他凶兽]鬼车九头鸟）；
- **碧波潭万圣龙王之婿**：乱石山碧波潭龙宫驸马（万圣公主之夫——万圣龙王招婿）；
- 盗佛宝：盗取祭赛国金光寺的**佛宝舍利子**（"金光寺塔失宝"——国难嫁祸和尚）；
- **结局特殊**：被二郎神、梅山兄弟+悟空联军围剿——哮天犬咬掉一头（逃窜）——**逃往北海**（存亡未知）——西游中极少数"逃跑成功"的妖怪（并非被主人收走/被灭）。

## 故事（西游记·碧波潭一难）
1. 祭赛国：金光寺塔失宝（被盗佛宝舍利）——国王迁怒僧人（问罪下狱）；
2. 悟空师徒查明：碧波潭九头虫/万圣公主盗宝（"偷宝"案）；
3. 悟空+八戒大战九头虫——**二郎神携梅山兄弟**路过相助（"二郎神助战"名场面——二郎神率梅山六友+哮天犬围剿）；
4. 哮天犬咬掉九头虫一头（受伤）——九头虫败逃（入水/飞遁）——生死不明（逃往北海——无主人可领、未被灭——**西游唯一"逃遁存活"的无后台妖**）；
5. 佛宝归还金光寺——祭赛国案结（"失宝案"）。
