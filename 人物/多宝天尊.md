# 多宝天尊（多宝如来·化胡为佛）

通天教主亲传大弟子——截教首席、万仙之首，代师收徒传道（万仙来朝之盛况多宝出力最多）。封神后随老子"化胡为佛"入释门，为**多宝如来**（小乘佛教教主）——"佛本是道"的关键人物。洪荒流中佛道双修、身兼截教正宗与佛门大教的桥梁角色。来源：《封神演义》、佛道化胡传说。

## 身份
- **通天教主大弟子**——截教首席（四大弟子之首：[人物/截教群仙]）——代师收徒传道；
- 封神后老子"**化胡为佛**"——多宝入沙门——为**多宝如来**（小乘佛教教主）——地位与如来并列或更高；
- 佛道双修——身兼截教正宗与佛门大教——"佛本是道"关键人物（[参考/经典书目与流派沿革]化胡说）。

## 神通
| 神通 | 说明 |
|---|---|
| **多宝神通** | 身化万千法宝、以宝护身攻敌——截教第一"器修"——一人可抵万仙之宝 |
| **通天剑道** | 承通天教主剑法——携诛仙阵图可代师掌阵——剑意纵横 |
| **化胡为佛法** | 转投佛门后修寂灭极乐之法——以截教之道融佛门之果——创立小乘佛教 |
| **万仙阵统领** | 万仙阵中代通天掌旗——指挥截教万仙布阵应敌（[阵法/万仙与九曲黄河]） |

## 事迹（封神演义）
1. **诛仙阵代师**：封神中多宝主动下山——在诛仙阵中代师执掌诛仙剑阵——与广成子等交战（[阵法/诛仙剑阵]"非四圣不可破"）；
2. **被擒**：诛仙阵被四大圣人（元始/老君/接引/准提）联手破后——多宝被**老子以乾坤图擒拿**；
3. **化胡为佛**：老子西出函谷关——化胡为佛（"老子化胡"典故——道教东传西渡说）——多宝入沙门——创小乘佛教——从此佛教分大乘（如来/释迦）、小乘（多宝）；
4. **多宝如来**：佛教中地位尊崇——某些版本称其为"过去佛"或"东方宝净世界教主"。

## 神话原型 vs 洪荒流设定
| 原型 | 洪荒流 |
|---|---|
| 《封神演义》多宝被老子擒拿、后化胡为佛 | 截教大弟子——佛道双修的桥梁人物（[佛教/总览]） |
| 佛教中多宝如来为"东方宝净世界"之佛 | 与小乘佛教合流——有时与如来并列 |
| 无"多宝塔"重宝记载 | 设定为身怀万宝的器修天才 |
