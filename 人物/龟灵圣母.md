# 龟灵圣母（截教四大弟子·万载金鳌）

截教通天教主门下**四大弟子**之一（四大弟子：多宝/金灵/无当/龟灵——[人物/截教群仙]）——原身为万载金鳌（巨龟修行得道）。封神中先被惧留孙捆仙绳擒、后被西方教接引降服——途中被**蚊道人**吸干精血而亡（"蚊道人噬龟灵"——封神最惨烈的陨落之一——灵宝被毁）。来源：《封神演义》第77-78/83回。

## 身份
- **截教四大弟子之一**：通天教主亲传弟子（四大弟子中排名第三/第四——多宝/金灵/无当/龟灵——[人物/截教群仙]四大弟子）；
- **万载金鳌化身**：原身是万载金鳌（巨龟——修为万载——"金鳌岛"之名与金鳌关联——[地理/总览]金鳌岛碧游宫）；
- **好勇斗狠**：截教中性格刚烈、好斗（"龟灵圣母性好战"——主动请战多）；
- 封神后**未入封神榜**（被蚊道人吸干——魂飞魄散——"死不入榜"的例外——[量劫/量劫机制]）。

| **甲壳防御** | 龟壳防御力（金仙级——"乌龟壳"抗打——[概念/五行阴阳八卦]玄武意象） |

## 故事（封神演义）
1. **广成子三谒碧游宫**：广成子打死火灵圣母（龟灵圣母之徒）——龟灵圣母怒而出战——战广成子——被番天印打回原形（金鳌现形——[法宝/十二金仙法宝]番天印）；
2. **三教大会**：龟灵圣母誓报徒仇——万仙阵前再战——被**惧留孙**（[人物/惧留孙]）捆仙绳擒拿（"捆仙绳擒金鳌"）；
3. **接引降服**：西方教接引道人（[人物/西方二圣]）欲渡其入西方——将龟灵圣母收于"乾坤袋"（准备渡化）；
4. **蚊道人噬杀**：途中放出一群**血蚊**（蚊道人——[凶兽/其他凶兽]蚊类妖王——"蚊道人"）——将龟灵圣母**吸干精血而亡**（金鳌惨死——截教四大弟子的悲剧收场）；
5. 后续：蚊道人又飞入西方极乐世界——吮吸**十二品功德金莲**三品（金莲降九品——[法宝/十大先天灵宝榜]功德金莲——"蚊道人毁灵宝"连锁）。

## 相关设定
- 龟灵圣母=截教四大弟子悲剧的缩影（好斗→被擒→被渡→惨死——"截教门人结局的多舛"——[人物/截教群仙]）；
- **蚊道人噬龟灵**：封神"最惨烈陨落"之一（不是战死——是被蚊虫吸干——"死法屈辱"）；
- 十二品金莲降九品：蚊道人连锁事件（西方教至宝受损——"佛门损失"——[教派/西方教与佛教]金莲）；
- 金鳌意象：龟=玄武（[灵兽神兽/四灵详考]玄武——龟蛇合体）——龟灵圣母的"玄武血统"设定（洪荒流常设定其有玄武血脉）。
