# 猪八戒（猪悟能·天蓬元帅·净坛使者）

取经团队二徒弟——前身天蓬元帅（掌管天河十万水军），因调戏嫦娥被贬下凡、错投猪胎——"好吃懒做但关键时刻顶得住"的喜剧角色。《西游记》最具"人性"的妖怪/徒弟——懒惰、贪吃、好色、爱发牢骚，却也憨厚忠诚、危难时可靠。中国文学最著名的喜剧形象之一。来源：《西游记》、[人物/唐僧]、[神通/天罡地煞详解]。

## 身份
- **天蓬元帅**：天庭主管天河（十万水军）的元帅——道教北极四圣之首"天蓬大元帅真君"（[道教神佛/护法神将]天蓬——天蓬咒）——南下凡后为猪八戒；
- **贬谪之由**：因蟠桃会醉酒调戏嫦娥（一说霓裳仙子）——被贬下凡——错投猪胎——成猪头人身的"猪刚鬣"；
- **福陵山云栈洞**：占山为妖（曾娶卯二姐——早亡）——后高老庄强娶高翠兰（"高老庄招亲"）；
- **随唐僧取经**：法名**悟能**、号**八戒**（"八戒"=不杀生/不偷盗/不淫/不妄语/不饮酒/不坐高广大床/不着香华/不非时食——戒律名号）；
- 取经五圣之一——结局封**净坛使者**（如来的"吃货"安排——"因汝口壮身慵，食肠宽大……教汝净坛"）。

## 神通
| 神通 | 说明 |
|---|---|
| **三十六变（天罡数）** | 天罡三十六般变化——但不能变轻巧华丽飞腾之物（"变山变树变石块变土墩变赖象科猪水牛骆驼真个全会"——《西游记》第67回——[神通/天罡地煞详解]） |
| **九齿钉耙（上宝沁金钯）** | 太上老君用神冰铁锤炼、五方五帝六丁六甲施力打造的至宝——"举起烈焰并毫光，落下猛风飘瑞雪"——比金箍棒来历更硬的"农具型神兵"（[法宝/兵器谱]） |
| **天蓬神咒/天蓬火** | 天蓬元帅余威（道教天蓬咒护身——[道教神佛/道教经典与传统历法]） |
| **好吃懒做/贪生怕死** | 战斗常喊"散伙分行李"——但关键时刻立功（高老庄收妖、黄袍怪请回悟空等） |
| 云栈洞/高老庄 | 高翠兰之夫——"高老庄招亲"名场面（被悟空假扮高翠兰戏弄） |

## 故事
1. **高老庄被降**：悟空假扮高翠兰戏弄八戒——收服为唐僧二徒弟（"高老庄"章节——[人物/孙悟空]）；
2. **取经路**：挑担、探路、搞笑——"呆子"担当——大战流沙河收沙僧（沙僧被贬前与八戒相识——[人物/沙僧]）；
3. 关键时刻立功：黄袍怪一难请回悟空（激将法——"请师父回来"）、狮驼岭大战白象精等多次救场（[人物/奎木狼]黄袍怪）；
4. **净坛使者**：取经功成——如来封"净坛使者"（虽是"吃货"安排、却是取经果位之一——"五圣成真"）。

## 形象与象征
- **喜剧担当**：懒惰、贪吃、好色、爱发牢骚——"人性"最饱满的取经人（凡人的七情六欲化身）；
- **反差**：看似最无能——却总在关键处顶住（"呆子不呆"——[人物/孙悟空]"八戒是俺兄弟"）；
- **八戒哲学**："散伙分行李"（打退堂鼓）vs"咬牙坚持"（危难时）——取经路上的现实主义者（与悟空理想主义对照）；
- **天蓬元帅背景**：北极四圣之首的神格（道教护法——[道教神佛/护法神将]）——"神仙下凡错投猪胎"的落差喜剧；
- 民俗形象："猪八戒背媳妇"（经典民间笑料）、"猪八戒照镜子——里外不是人"（歇后语）。
