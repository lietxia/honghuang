# 崇黑虎（北伯侯·崇侯虎之弟·南岳大帝）

封神演义中的商朝北伯侯——**崇黑虎**——崇侯虎之弟（崇侯虎是陷害文王的佞臣）——崇黑虎却明辨是非、归顺西岐（"黑虎负义亲"——兄弟反目的忠奸对照）。骑火眼金睛兽、善使神鹰（铁嘴神鹰）。封神后封"**南岳衡山司天昭圣大帝**"（南岳大帝——[地祇/五岳大帝]五岳之一）。来源：《封神演义》第6-7/42回。

## 身份
- **北伯侯崇侯虎之弟**——崇黑虎——商朝北伯侯（镇守北方——曹州崇侯——[人物/纣王与商周群臣]崇侯虎兄弟）；
- **归周**：崇侯虎（谗害文王的佞臣）被伐——崇黑虎大义灭亲（"崇黑虎背兄归周"——识时务/明大义——"弃暗投明"的封神代表）；
- **南岳大帝**：封神后封"**南岳衡山司天昭圣大帝**"（南岳衡山——[地祇/五岳大帝]南岳——五岳大帝之一）；
- 武艺高强+异兽相助：火眼金睛兽（坐骑）+铁嘴神鹰（战宠——[灵兽神兽/坐骑谱]）。

## 故事（封神演义）
1. **崇侯虎征西**：崇侯虎（北伯侯）奉旨征西岐——崇黑虎随征（兄弟同征）；
2. **大义灭亲**：崇黑虎明察（知崇侯虎不义——[人物/纣王与商周群臣]崇侯虎谗害文王）——临阵倒戈——擒崇侯虎（"黑虎擒兄"——交周处置——崇侯虎被斩）；
3. **归周建功**：崇黑虎归周——为周营大将（铁嘴神鹰建功——[大事件/封神之战始末]）；
4. **渑池之战陨落**：渑池之战——崇黑虎与文聘、崔英、蒋雄同战张奎（[人物/张奎]）——被张奎刀斩（"五岳将殒渑池"——五岳之恨）；
5. **封神**：封"**南岳衡山司天昭圣大帝**"（南岳大帝——[地祇/五岳大帝]——五岳正神之一——与黄飞虎（东岳）、闻聘（中岳）等同列）。
