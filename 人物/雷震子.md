# 雷震子（风雷双翅·雷部正神）

西伯侯姬昌第一百子（义子）——襁褓中被雷震生于野，文王捡拾为子。阐教云中子弟子，服仙杏生风雷双翅，封神中周营猛将，封雷部正神（雷公）。"周营四猛"之一（与哪吒、杨戬、韦护并列）。来源：《封神演义》、[道教神佛/雷部]。

## 身份
- **文王第一百子**（义子）：西伯侯姬昌（周文王）第一百子——襁褓中雷震生于野、文王捡拾为子（"雷震子"之名源此）；
- **云中子弟子**：阐教福德仙云中子之徒（终南山玉柱洞）——[人物/云中子]；
- 封神中周营猛将——雷部正神（雷公）；
- 部分设定：勾陈上宫天皇大帝化身（雷部最高位）。

## 神通
| 神通 | 说明 |
|---|---|
| **风雷双翅** | 云中子以仙杏（先天灵根，[法宝/十大先天灵根]）喂之——生出风雷二翅（左风右雷）——一翅扇风雷、飞行如电、日行万里 |
| **雷法** | 掌雷——可召天雷轰敌（雷部正神本职） |
| **异相** | 仙杏改造后形貌异于常人：面如蓝靛、发似朱砂、獠牙外露——勇猛无匹 |
| **金刚不坏** | 雷公体质、肉身强横 |

## 法宝
- **黄金棍（风雷棍）**：云中子所赐——使动时风雷相随、一击山崩；
- **风雷二翅**：本体神通兼"法宝"——可当武器扇风雷；
- **仙杏改造**（六枚仙杏之力）：云中子以先天灵根仙杏喂服——蜕变出翅膀与异相（"仙杏生翼"著名典故，[人物/云中子]）。

## 故事（封神演义）
1. **救父**：文王被囚羑里——雷震子奉云中子之命救父——展翅飞至（风雷开路）、黄金棍开道——救出文王；
2. **周营先锋**：随姜子牙伐纣——与哪吒、杨戬、韦护等并列"周营四猛"；
3. 多次出战立功：破阵杀将——与余化、张奎等对战（渑池五岳之役等）；
4. **封神**：封雷部二十四天君之位（雷公）——掌行雷布雨（[大事件/封神榜三百六十五位正神]雷部）。
5. 另：肉身成圣七人之说（部分版本雷震子亦成圣——与李靖等列）。

## 洪荒流设定
- 雷震子为"雷部"正神代表之一——风雷翅膀+黄金棍设定颇具特色（"风雷双翼"经典形象）；
- 与雷部九天应元雷神普化天尊（闻仲）并列——雷部猛将（[道教神佛/雷部]二十四天君）；
- 仙杏=先天灵根→风水二翅——"灵根改造"的著名案例（妖族妖族改造/人族改造）。
