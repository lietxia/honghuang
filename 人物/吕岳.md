# 吕岳（瘟癀昊天大帝·瘟神）

截教瘟部正神——吕岳（九龙岛炼气士），封神中摆**瘟癀阵**（瘟疫大阵——"瘟癀之害"），被杨任五火神焰扇破之（"扇死吕岳"）。封神后封"瘟癀昊天大帝"（瘟部主神——[大事件/封神榜三百六十五位正神]瘟部）。"瘟神"信仰（[地祇/瘟神痘神与傩神]五瘟使者）在封神中的具象——天庭八部"瘟部"的主神。来源：《封神演义》第59/81回。

## 身份
- **九龙岛炼气士**（截教——九龙岛道场）——封神中助商（闻仲请来——[人物/闻仲]）；
- 瘟神法术：瘟疫/毒术（瘟丹/瘟癀阵——"瘟癀"=瘟疫）；
- 封神后封"**瘟癀昊天大帝**"（瘟部主神——天庭瘟部——[势力/天庭]八部正神）；
- 天庭八部·瘟部：掌人间瘟疫时疫（"瘟病之政"——[地祇/瘟神痘神与傩神]关联——与[人物/罗宣]火部、[人物/闻仲]雷部并列）。

## 故事（封神演义）
1. 商军败退——闻仲请吕岳（九龙岛）助商；
2. **瘟癀阵**：吕岳布瘟癀阵——瘟疫弥漫（西岐军民染疫——"人人病倒"——姜子牙也被困阵中百日——"百日之灾"）；
3. **杨任破阵**：杨任（[人物/杨任]）持**五火神焰扇**下山——一扇搧死吕岳（"五火神焰扇破瘟癀"——火克瘟）；
4. **封神**：封"**瘟癀昊天大帝**"——瘟部主神——天庭瘟部（掌时疫——[大事件/封神榜三百六十五位正神]瘟部）。
