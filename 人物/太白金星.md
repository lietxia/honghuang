# 太白金星（李长庚·主战伐之星官）

天庭重臣——太白金星（金星人格化——西方金德真君），玉帝特使、"和事佬"（招安悟空的使节）。道教中为金星神（西方太白金德真君——[道教神佛/斗部星君]五德星君）；封神中为文官之祖（李长庚）。《西游记》中最和蔼可亲的天庭神仙之一（"太白金星"成老好人代名词）。来源：《西游记》《封神演义》、道教星宿信仰。

## 身份
- **金星人格化**：太白金星=岁星（金星）之神化——西方金德真君（[道教神佛/斗部星君]五德星君——金德）——"太白"即金星古称（晨为启明、暮为长庚——故姓**李长庚**）；
- **天庭重臣**：玉帝特使（招安/宣旨）——天庭文官之首（"文曲"辅弼——与武官李靖相对）；
- 《封神演义》：李长庚为文官（纣王朝臣/周营军师级）——[大事件/封神榜三百六十五位正神]群星列宿金德星君；
- 《西游记》：玉帝身边传旨官——"太白金星"成天庭外交官（和事佬）。

## 神通
| 神通 | 说明 |

| **遁行三界** | 天庭特使——往来三界传旨（仙风道骨老神仙形象） |
| **外交斡旋** | "招安"悟空（弼马温→齐天大圣——[人物/孙悟空]）——"和事佬"技能（化解兵戈） |

## 故事（西游记）
1. **两度招安**：悟空闹龙宫地府后——太白金星建议招安（"降一道招安圣旨"）——第一次封弼马温、第二次封齐天大圣（"有名无实"大圣——管理蟠桃园）——悟空反下天（"齐天大圣"名号却成了悟空造反资本）；
2. **取经护法**：取经路上多次出场（传旨/调和——金角银角难中传老君旨意、狮驼岭请如来等）；
3. 成"天庭和事佬"符号：老好人、善斡旋（与[人物/李靖]主战派对照）。

## 相关设定
- 太白金星=西方金德真君（[道教神佛/斗部星君]五德星君）——"太白"为金星（黎明启明/黄昏长庚——李长庚）；
- 星战典故：李白（"李太白"）传为太白金星转世（"谪仙人"）——文人星宿信仰；
- 洪荒流：天庭文官/帝使设定——"太白金星"为玉帝传旨官标配（[势力/天庭]凌霄殿班底）。
