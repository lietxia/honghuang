# 金灵圣母（斗母元君·截教女仙之首）

截教通天教主亲传二弟子（四大弟子之二）——截教女仙之首，闻仲之师。法力高深、在万仙阵中代师掌旗、独斗三大士不落下风——被燃灯道人以定海珠偷袭而陨落。封神后封**斗母元君**——统率周天星斗、为天庭星部之主。来源：《封神演义》、道教斗姆信仰。

## 身份
- **截教通天教主亲传二弟子**——地位仅次于多宝天尊——截教"女仙之首"（四大弟子：多宝/金灵/无当/龟灵，[人物/截教群仙]）；
- **闻仲之师**：闻仲（雷祖）所学截教雷法皆由金灵圣母所传（[人物/闻仲]）；
- 封神后封**斗母元君**——统率周天星斗——天庭星部之主（道教斗姆=北斗众星之母——[道教神佛/斗部星君]）。

## 事迹（封神演义）
1. **闻仲之师**：闻仲雷法皆金灵圣母所传——"金灵圣母教出雷祖"（[道教神佛/雷部]闻仲=雷部普化天尊）；
2. **万仙阵独斗三士**：万仙阵中金灵圣母代师掌阵——独斗文殊广法天尊、普贤真人、慈航道人**三大士**（三大士已有金身法相、准提加持）——金灵圣母仍不落下风（截教女仙战力之巅）；
3. **定海珠偷袭**：燃灯道人趁金灵不备——以**定海珠**（二十四颗，从赵公明处所得，[人物/赵公明]）偷袭——正中其顶门——金灵圣母当场陨落（"惨被偷袭"的悲情女仙——洪荒流常为其鸣不平）；
4. **封神**：封斗母元君——统领周天星斗——天庭星部最高神职（[大事件/封神榜三百六十五位正神]斗部正神）。
