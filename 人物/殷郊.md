# 殷郊（太岁部首神·犁锄之刑）

商纣王之子（殷郊）——与弟殷洪被姜子牙救出（"比干之后"商室遗孤），后拜广成子/赤精子为师。下山助周途中被申公豹策反（"叛周"）——持番天印/落魄钟对抗周军——被犁锄之刑（"犁锄地心"）。封神后封"太岁部执年岁君"（值年太岁——[地祇/星辰之神与命运神]太岁信仰主神）。来源：《封神演义》第8-13/64-65回。

## 身份
- **商纣王之子（殷郊）**：殷商太子（纣王长子）——妲己时代被追杀（"杀子"桥段——殷郊殷洪被杨妃救出）；
- **广成子弟子**：被广成子救上九仙山学艺（使番天印/落魄钟）；
- **被策反**：下山助姜子牙途中——被申公豹游说（"助商"）——叛周（"商室正统"立场）；
- 封神后封"**值年太岁**"（太岁部首神——执年岁君——[大事件/封神榜三百六十五位正神]太岁部——统领日直众星/六十甲子太岁）。

## 神通（法宝）
| 神通/法宝 | 说明 |
|---|---|
| **番天印**（借） | 广成子借给殷郊的至宝（"番天印"——[法宝/十二金仙法宝]广成子之宝）——殷郊以此打伤阐教门人 |
| **落魄钟/落魂钟** | 摇动摄魂（"落魄钟"——魂魄离体） |
| **三头六臂**（部分版本） | 法术法身 |
| **犁锄之刑结局** | 被广成子（师门）以犁锄锄死（"犁锄"——师门清理门户——"殷郊犁锄"典故） |

## 故事（封神演义）
1. **遗孤**：纣王杀后（姜皇后）——妲己欲加害殷郊殷洪（"杀子"）——杨妃/比干救出二子；
2. **拜师**：殷郊拜广成子（九仙山）、殷洪拜赤精子（太华山）——学艺；
3. **下山之惑**：兄弟下山助周——途中被**申公豹**策反（"你是商室太子、何助周？"）——殷郊持番天印反攻周营（殷洪亦叛——被赤精子以太极图化灰——[人物/赤精子与清虚道德真君]）；
4. **殷郊之败**：殷郊以番天印伤阐教门人——广成子（师尊）出面——"犁锄"之刑（被师门以犁锄锄杀——"师门清理门户"悲剧）；
5. **封神**：封"执年太岁"（值年太岁）——太岁部之首——掌本岁人间吉凶（[地祇/星辰之神与命运神]太岁信仰）。

## 相关设定
- 殷郊=太岁部首神（值年太岁）——[道教神佛/斗部星君]六十甲子太岁由都雷太岁殷元帅统管（殷郊=都雷太岁——"殷元帅"）——太岁信仰主神；
- "殷郊犁锄"典故——封神"师门悲剧"名场面（与[人物/赤精子与清虚道德真君]化殷洪并列"师门清理双惨案"）；
- 殷商遗孤的悲剧立场：忠商（父子皆商室）vs助周（天道）——"正统与天命"的两难（[人物/纣王与商周群臣]）；
- 民间太岁信仰：殷郊成"太岁爷"（岁神崇拜——本命太岁/值年太岁——[地祇/星辰之神与命运神]）。
