# 玉皇大帝（昊天上帝 / 玉帝）

天庭之主，万天之主，统御三界十方、四生六道。封神后天庭正式建立，昊天上帝成为三界最高行政主宰。

## 身份
- 道教全称"**太上开天执符御历含真体道昊天玉皇上帝**"，民间俗称"老天爷""玉帝"。
- 与上古"昊天上帝"信仰合一——宋代真宗上尊号"玉皇大天帝"，玉皇信仰正式确立。
- 居三十三天之凌霄宝殿，四御（中天紫微、勾陈、后土、南极长生）辅佐，王母娘娘为配。
- 洪荒流设定：为**封神后天庭之主**——巫妖大劫后妖族天庭覆灭，昊天上帝接管三界（此前妖庭帝俊/太一为天帝）。

## 职掌
- 统御三界十方、四生六道（天、人、阿修罗、畜生、饿鬼、地狱）；
- 总管天庭八部正神（雷、火、瘟、斗、太岁、水、财、痘）；
- 掌人间善恶、生死祸福，敕封神仙、赦封神职；
- 万神之王、万仙之主——"昊天金阙无上至尊自然妙有弥罗至真玉皇上帝"。

## 出身与来历（多种说法）
| 说法 | 内容 |
|---|---|
| 道教正统 | 先天尊神，历亿劫修行，为三界至尊，位在三清之下 |
| 民间传说 | 本是凡间"张百忍"（张友仁），修行亿劫、功德圆满而被推举为玉帝 |
| 洪荒流 | 鸿钧座下童子（昊天），封神后受命执掌天庭；或为妖庭帝俊之后的第二代天帝 |
| 演义流 | 《封神演义》中昊天上帝命十二仙首称臣，引发三教封神 |

## 神通
- **昊天镜神通**：照彻三界、洞察万物——昊天镜为其权柄象征，可照妖、定魂、映照因果。
- **天帝诏令（言出法随）**：一言可调动八部正神、十万天兵天将，敕令即法旨，三界莫敢不从。
- **周天星斗借用**：可借周天星辰之力镇压强敌（虽妖庭覆灭，昊天亦可调动星斗）。
- **大罗天威**：居大罗天凌霄殿，受天道庇护——圣人以下难伤，乃"三界共主"之位格加成。
- **历劫亿数**：道教言玉帝历一千七百五十劫（每劫十二万九千六百年）方成至尊——其修为深不可测（部分洪荒流亦采用"1750劫"之数）。

## 法宝
- **昊天镜（昊天上帝印）**：统御三界的权印，照妖、定魂、号令三界（西游中照出真假美猴王亦倚此镜）。
- **封神榜**（代天执掌）：封神后昊天借封神榜约束三百六十五位正神——天庭法统之源。
- **天帝剑 / 斩妖剑**：诛邪之剑，斩妖除魔。
- **凌霄玉玺**：天庭法统象征，调兵遣将必用。
- **凤辇/九龙辇**：帝王仪仗。

## 西游中的玉帝
- 孙悟空大闹天宫：玉帝遣二郎神擒拿、请如来镇压——"佛祖，道祖，朕不出手"之梗（玉帝修为成谜）。
- 观音菩萨赴蟠桃会：玉帝设"安天大会"谢如来。
- 凤仙郡求雨：玉帝罚凤仙郡三年不雨（"米山面山金锁"），体现玉帝掌雨权。

## 在洪荒流设定
- 与妖庭帝俊/太一为**不同时期之天帝**——妖庭随巫妖大劫覆灭，封神后天庭重建，昊天正式执掌三界。
- 封神榜实为"充实天庭"的计划——昊天命十二仙首称臣，三教签押封神榜，365位正神入天庭任职。
- 玉帝修为：部分洪荒流设定其修为至准圣/圣人（1750劫），平时不出手，实为"深藏不露"。

## 神话原型 vs 洪荒流
- 道教：玉帝为至高神（三清之下、万神之上），掌三界。
- 民间：玉帝即"天"，老天爷——人生的最高主宰。
- 洪荒流：玉帝为封神后的行政天帝，位格低于圣人（圣人超然物外），却掌三界实权。
