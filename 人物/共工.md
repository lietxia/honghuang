# 共工（水之祖巫·怒触不周山）

十二祖巫之一（水之祖巫）——与祝融（火之祖巫）齐名的祖巫战神。巫妖大劫中怒触**不周山**（天柱折——"天倾西北、地陷东南"）——女娲补天神话的直接肇事者。中国神话中"失败的反叛者"典型（被颛顼/祝融战败后怒触天柱——神话宇宙观的"地理伤痕"制造者）。来源：《山海经》《淮南子》、[人物/十二祖巫]。

## 身份
- **十二祖巫之一**（水之祖巫）：盘古精血所化——掌水之法则（人面蛇身、朱发——[人物/十二祖巫]表）；
- **水神正统**：上古水神（与河伯等水神并列——但祖巫级别最高——[地祇/水神与河神]）；
- **怒触不周山者**：与祝融（或颛顼）争帝失败——怒触不周山——天柱折（[大事件/巫妖大战·不周山倾·女娲补天]）；
- 洪荒流：巫族祖巫战力（水法则——"水神戟"）——巫妖大战主力。

## 神通
| 神通 | 说明 |
|---|---|
| **水之法则** | 掌水（洪水/水行——"洪水滔天"之源）——水神之祖 |
| **不周山怒触** | 怒触不周山（天柱——盘古脊梁所化）——天柱折、天倾西北/地陷东南（创世级大神通——"撞断天柱"） |
| **水神戟** | 本命兵刃（控水神戟——[人物/十二祖巫]法宝表） |
| **洪水神通** | 发动大洪水（战后洪水滔天——女娲补天+大禹治水的"洪水源头"） |

## 故事
1. **祖巫之战**：巫妖大战——共工（水）与祝融（火）之战（一说与颛顼争帝"共工氏霸而不王"）——共工战败；
2. **怒触不周山**：共工怒而触不周山（天柱）——"天倾西北、地陷东南"——星辰移位、洪水泛滥；
3. **女娲补天**：女娲炼五色石补天、断鳌足立四极（[大事件/巫妖大战·不周山倾·女娲补天]）；
4. **后续**：洪水遗害——大禹治水（[人族/大禹治水]）——共工的"洪水遗产"成中国治水神话的起点；
5. 洪荒流结局：共工触山后（巫妖大战中）陨落（水之祖巫战死——十二祖巫除后土尽殁）。

## 象征
- **失败的反叛者**：战败而怒触天柱——"宁为玉碎"的悲壮（与[人物/刑天]断首仍战并列"不服者"神话）；
- **地理伤痕**：不周山折="天倾西北"（中国地理西北高东南低的神话解释——[地理/总览]）；
- 与[人物/祝融]的"水火相争"：中国神话"水火不容"的经典对偶（火胜水败——共工败祝融胜——"水火不容"成句）；
- 共工氏：后世"共工氏"为部落名（"共工之臣相柳"——[凶兽/其他凶兽]相柳）。
