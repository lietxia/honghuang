# 刑天（以乳为目 / 战神）

## 身份
- 上古战神，炎帝部落（或神农之臣）的猛将，与天帝（黄帝/帝俊）争神位。
- 被斩首后以乳为目、以脐为口，操干戚（盾与斧）继续战斗——"刑天舞干戚，猛志固常在"（陶渊明）。"
- 中国神话中不屈反抗精神的最高象征。

## 神通
- **刑天舞干戚**：断首后以乳为目、脐为口，仍持斧盾战斗不止，战意不死。
- **无头战神**：无首仍能战——洪荒流中为"战魂不灭"的化身。
- **干戚之舞**：干（盾）、戚（斧）为器，舞动如风，冲锋陷阵。
- **战神之躯**：肉身强横，炎帝麾下第一战将。

## 法宝/装备
- **刑天斧（开天斧之影）**：干戚中的"戚"，巨斧开山，相传为神器。
- **刑天盾（干）**：巨盾防身。

## 故事
- 刑天与天帝（黄帝）争神，天帝斩其首，葬于常羊之山。
- 刑天以乳为目、脐为口，操干戚以舞，继续与天帝争战（《山海经·海外西经》）。
- 后世："刑天"成为不屈与反抗的代名词，与精卫填海并列为"知其不可为而为之"的神话精神。

## 洪荒流设定
- 刑天为巫族（或炎帝麾下）大巫/战神，断首后战意不灭——常被设定为"最强战神"或"巫族余部之魂"。
- 其盾斧（干戚）在部分洪荒流中为后天至宝。
- 与蚩尤并列，为上古"不服天帝"的两位战神（蚩尤被黄帝所杀、刑天断首仍战）。
