# 刑天（以乳为目·战神·猛志常在）

中国神话中最不屈的战神——被斩首后"以乳为目、以脐为口，操干戚以舞"，战意不死。陶渊明《读山海经》"刑天舞干戚，猛志固常在"使之成为反抗精神的最高象征——与[人物/精卫]填海并列为"知其不可为而为之"的神话精神双璧。中国文学中"失败英雄"的第一形象。来源：《山海经·海外西经》、陶渊明《读山海经十三首》。

## 身份
- **上古战神**——炎帝部落（或神农之臣）猛将——与天帝（黄帝）争神位；
- **被斩首**：与天帝争神——天帝斩其首——葬于常羊之山（《山海经·海外西经》");
- **以乳为目**：断首后以乳为目、以脐为口——操干戚（盾与斧）继续战斗（"头可断、志不可夺"）；
- 中国神话中不屈反抗精神的最高象征——与[人物/精卫]（填海）并称"不屈双璧"。

## 神通
| 神通 | 说明 |
|---|---|
| **刑天舞干戚** | 断首后以乳为目、脐为口——仍持斧盾战斗不止——战意不死（"猛志固常在"） |
| **无头战神** | 无首仍能战——洪荒流中为"战魂不灭"的化身（"刑天战魂"） |
| **干戚之舞** | 干（盾）、戚（斧）为器——舞动如风、冲锋陷阵（"干戚舞"成典籍典故） |
| **战神之躯** | 肉身强横——炎帝麾下第一战将（与[人物/蚩尤]并列上古两大不服天帝的战神） |

| 装备 | 说明 |
|---|---|

| **刑天盾（干）** | 巨盾防身（"干戚"组合=盾斧——攻防一体） |

## 故事
- **争神之战**：刑天与天帝（黄帝）争神位——天帝斩其首；
- **葬于常羊之山**：首级被葬于常羊之山（《山海经·海外西经》）——身首异处仍战（"首虽断、志不屈"）；
- **无头再战**：刑天以乳为目、脐为口——操干戚以舞——继续与天帝争战（"刑天之舞"——战意不息的反抗）；
- 后世"刑天"成不屈与反抗的代名词——与[人物/精卫]填海并列为"知其不可为而为之"（[上古神话典故/英雄与征战]）。

## 洪荒流设定
- 刑天为巫族（或炎帝麾下）大巫/战神——断首后战意不灭——常被设定为"最强战神"或"巫族余部之魂"（[势力/巫族]大巫）；
- 其盾斧（干戚）在部分洪荒流中为后天至宝；
- 与[人物/蚩尤]并列——上古"不服天帝"的两位战神（蚩尤被黄帝所杀、刑天断首仍战——[人物/蚩尤]涿鹿之战对照）——"失败的英雄"主题；
- 洪荒流常见"刑天斩首后实力不降反升（无头战魂）"设定——"战魂不灭"的极致。
