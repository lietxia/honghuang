# 黑熊精（熊罴怪·守山大神）

西游黑风山黑风洞的熊精（熊罴怪）——号"熊罴大王"。无后台的妖怪中极少数"善终"者：因武艺高强、未贪图吃唐僧肉、有慧根——被观音收为落伽山**守山大神**（戴禁箍）。西游"八大没后台却本领超悟空"的妖怪之一。来源：《西游记》第16-17回。

## 身份
- **黑风山黑风洞的熊精**（熊罴怪）——号"熊罴大王"；
- **无后台的妖怪**——却因"武艺高强、未吃唐僧肉"被观音收为守山大神（稀有善终之妖——对照"没后台必死"的西游潜规则，[人物/西游记妖怪全录]）；
- 落伽山守山大神：看守普陀山（观音道场）——归佛门护法编制。

## 神通
| 神通 | 说明 |
|---|---|
| **武艺高强** | 与孙悟空大战数十合不分胜负——少数能正面硬撼玄奘求魔的高手（"八大没后台却本领超过孙悟空"之一） |
| **变化** | 能变化——化道士（凌虚子）、化白衣秀士 |
| **未害唐僧** | 主要目的是**偷袈裟**（见下）——并非吃唐僧肉——相对"干净"的妖（有佛性慧根） |
| **妖修有成** | 黑风洞自称"佛衣会"办佛事——对佛门器物感兴趣（慧根之证） |

## 故事（西游记·黑风山一难）
1. **观音禅院**：观音禅院老院主（金池长老）见唐僧锦斓袈裟起贪心——欲纵火烧死唐僧师徒夺宝；悟空借广目天王"避火罩"护住唐僧——反烧了禅院；
2. **偷走袈裟**：黑熊精趁乱偷走锦斓袈裟据为己有（老院主撞死）；
3. **悟空寻宝**：悟空寻妖讨宝——与黑熊精大战（化"白衣秀士""凌虚子"等斗法——悟空变金丹/蚊虫等巧斗）；
4. **观音收妖**：悟空请来观音——观音以**禁箍**（如来所赐三箍之一：金/紧/禁）变作紧箍——化作黑熊精的"佛衣会"请帖（"佛衣"诱饵）——诱黑熊精戴上禁箍——现原形；
5. **结局**：黑熊精皈依佛门——被观音收为**落伽山守山大神**（看守普陀山）——随侍观音（"熊罴守山"）。

## 洪荒流设定
- 黑熊精为"妖修有成"代表——有实力、有慧根（未贪吃唐僧）——故得正果（守山大神——佛门编制，[佛教/护法]）；
- 与"有背景妖怪被收走"不同——黑熊精**本无后台**——纯凭实力与观音惜才被收——西游中少见"善终野妖"；
- **三箍对应**：禁箍（黑熊精）守山、紧箍（红孩儿）善财童子、金箍（悟空）取经人——[人物/红孩儿]、[人物/孙悟空]；
- 黑风山"佛衣会"——黑熊精的雅趣（喜欢袈裟佛宝而非唐僧肉）——"恶人亦有善面"的复杂性。
