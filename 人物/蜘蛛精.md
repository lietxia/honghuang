# 蜘蛛精（七蜘蛛·盘丝洞·濯垢泉）

《西游记》中盘丝洞的七只蜘蛛精（七姐妹）——盘踞濯垢泉，是取经路上"无后台野妖"的典型（无背景无本事者必死的"西游潜规则"代表，被悟空打死）。"盘丝洞"成蜘蛛精代名词——影视游戏（《黑神话：悟空》盘丝洞）中人气极高的西游女妖。来源：《西游记》第72-73回。

## 身份
- **七只蜘蛛精**（七姐妹）——盘踞盘丝洞（濯垢泉）；
- 无后台野妖——"没背景没本事必死"规律典型（与有后台的妖怪被救走形成对比——[人物/西游记妖怪全录]"西游潜规则"）；
- 实际上"本事"不弱（吐丝结网困住唐僧/八戒）——但树敌天庭（偷浴濯垢泉）而无救兵——注定败亡；
- 与师兄蜈蚣精（百眼魔君）同门（黄花观投靠）。

## 神通
| 神通 | 说明 |
|---|---|
| **吐丝结网** | 从肚脐（脐孔）喷出白丝——结成大网（丝线如织锦、坚固异常）——盘丝洞"以丝为罗网"——丝不能缚悟空（跳脱）但可缠八戒（"茧子"般捆住） |
| **濯垢泉** | 七女妖在温泉濯垢泉沐浴（仙泉）——悟空变鹰叼衣、调戏七妖（西游记喜剧名场面） |
| **群体作战** | 七姐妹协同吐丝——结网罩人（唐僧被擒欲蒸食） |
| **蜈蚣精师兄** | 黄花观百眼魔君（金光阵）——七妖投靠师兄复仇（引出黄花观一难） |

## 故事（西游记）
1. 盘丝洞七妖——捉唐僧欲蒸食（蜘蛛精没有吃唐僧肉成功——反被收拾）；
2. 悟空探盘丝洞——见七女妖濯垢泉沐浴（"好耍子"名场面）——变鹰叼走衣裙；
3. 八戒化作鲇鱼精下水戏耍（"浑水摸鱼"）——激怒七妖；
4. 七妖吐丝罩住八戒——逃往**黄花观**（投靠师兄蜈蚣精）——引出"黄花观"一难；
5. 悟空破丝网（火烧盘丝洞）——七妖最终被**打死**（无后台野妖结局）；
6. 黄花观：蜈蚣精（百眼魔君）被毗蓝婆菩萨收走（金针破金光——[人物/黑熊精]相关毗蓝婆）。

## 相关设定
- 蜘蛛精为"盘丝洞"代名词——影视/游戏（《黑神话：悟空》盘丝洞"紫云山"支线）中人气极高的西游女妖（"盘丝洞"成妖窟代称）；
- 与[人物/西游记妖怪全录]中其他女妖（白骨精/玉兔精/老鼠精）并列"西游女妖群像"——皆无后台、皆被收拾（白骨精被打死、玉兔被收走——后台之别）；
- 毗蓝婆菩萨（昴日星官之母）克百眼魔君——"一物降一物"；
- 濯垢泉与[地祇/水神与河神]温泉（汤泉）体系关联（天上仙泉落人间）。
