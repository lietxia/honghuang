# 比干（文财神·无心宰相）

商纣王叔父、亚相比干——七窍玲珑心的忠臣典范。因妲己设计被挖心而死，死后被尊为文财神（"无心则无私、无私则公正"）。封神演义中最悲壮的忠臣形象之一。来源：《封神演义》、民间财神信仰研究、百度百科。

## 身份
- 商纣王（帝辛）之叔父、殷商**亚相**（相国）——王叔忠臣；
- **七窍玲珑心**：心窍通达、聪慧过人、能辨忠奸（传说中的"玲珑心"异禀）；
- 后世尊为**文财神**——与武财神赵公明相对（文武财神分掌），因"无心"而公平公正，掌人间财富分配；
- 商周之战的"忠臣殉国"符号（[人物/纣王与商周群臣]）。

## 神通（传说）
- **七窍玲珑心**：心窍通达、智慧无碍——"比干之心，七窍玲珑"（生而异禀）；
- **无心不死传说**：民间传说比干被挖心后得姜子牙符水护持，失心仍能行走——路遇卖菜老妇问"菜无心可活，人无心可活否？"老妇答"人无心即死"——比干应声倒毙（一说老妇即妲己所化，故意点破）；
- **财神职司**：死后封文财神（比干相公）——掌人间财富公平分配（"公道财神"）。

## 故事（封神演义）
1. **妲己设计**：妲己（九尾狐，[人物/妲己]）装病，谎称需七窍玲珑心做药引——纣王召比干献心；
2. **忠君自剖**：比干明知是计（姜子牙曾劝他弃商），却以忠臣之义自剖——剑刺腹、挖心献上；
3. **无心而亡**：出宫遇卖无心菜之妇（妲己所化），一语点破"人无心即死"——比干倒地而亡（"无心菜"典故）；
4. **封神**：死后封神（一说文曲星君/文明王，一说文财神）——与赵公明（武财神）分掌文武之财；
5. **文财神信仰**：后世商人供奉比干为财神——"公心"象征（财神文化中"公平公正"的代表；另两位文财神为范蠡/财帛星君）。
