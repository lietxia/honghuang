# 杨戬（二郎神·清源妙道真君）

天庭第一战将——玉鼎真人弟子、玉帝外甥，**肉身成圣**、听调不听宣。八九玄功（七十二变+金刚不坏）大成，天眼破幻、哮天犬辅助——封神中西游中皆战力天花板级存在（与孙悟空"神通相当"）。来源：《封神演义》《西游记》、百度百科等。

## 身份
- **阐教玉泉山金霞洞玉鼎真人弟子**——玉虚三代弟子中战力第一（[人物/三清]阐教三代）；
- **玉皇大帝外甥**：母亲瑶姬仙子（三圣母）思凡下界生杨戬（"二郎劈山救母"传说——华山救母）；
- 封号"**昭惠显圣二郎真君**"——住灌江口——率梅山六兄弟+一千二百草头神（二郎神民间信仰，[道教神佛/地方与俗神]）;
- **肉身成圣**：未入封神榜——不受天庭直接管辖（"听调不听宣"——天庭唯一不朝拜玉帝的将领）。

## 事迹
### 封神大战
1. 周营副帅——屡立战功；
2. **战魔家四将**：以八九玄功变化破青云剑/混元伞（变花狐貂咬魔礼寿——[人物/魔家四将]）；
3. **破瘟癀阵**、**收梅山七怪**：袁洪（白猿）——杨戬变化为女娲娘娘像将其擒拿（[人物/梅山七怪]）；
4. 擒余化、斗张奎（以变化破地行/遁术）等。

### 西游记
- 受命降孙悟空——与悟空赌斗七十二变——二者神通相当、难分高下——后以哮天犬+天眼配合擒住悟空（"二郎神擒悟空"名场面，[人物/孙悟空]）。
