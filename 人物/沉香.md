# 沉香（劈山救母·宝莲灯·孝子典范）

中国神话著名的"孝子"形象——沉香劈山救母（华山救母）主角：其母三圣母（华岳三娘）被二郎神杨戬压于华山之下——沉香长大、得宝莲灯、斧劈华山救母（"劈山救母"）。与[人物/许仕林]（祭塔救母）、目连（救母）并列"救母三孝子"。宝莲灯传说（元杂剧《沉香太子劈华山》/民间故事）是中国"孝感动天"叙事的经典。来源：《宝莲灯》传说、[人物/杨戬]（舅——劈山救母母题继承）。

## 身份
- **三圣母（华岳三娘）之子**：沉香——华山三圣母与凡人刘彦昌之子（"人仙之子"——[地祇/山神体系]华山三圣母）；
- **二郎神杨戬外甥**：其母三圣母为玉帝之女/二郎神之妹——"劈山救母"母题二代（杨戬救母→沉香救母——[人物/杨戬]劈山救母的传承）；
- **劈山救母**：长大后得知身世——夺宝莲灯、斧劈华山——救出母亲（"孝感动天"）；
- 结局：一家人团圆（部分版本沉香亦成神——"二郎神第二"的设定——[人物/杨戬]对照）。

## 故事（宝莲灯）
1. **人仙恋**：三圣母（华岳三娘——华山女神）与刘彦昌（书生）结为夫妻（"华山姻缘"——[地祇/山神体系]华山三圣母——与[人物/牛郎织女]、[人物/董永与七仙女]并列"人仙恋"母题）；
2. **镇于华山**：二郎神杨戬（[人物/杨戬]）以"仙凡有别"为由（或玉帝降罪）——将三圣母压于**华山**之下（"二郎神怒压华山"——与杨戬自己被玉帝压母的"母题反转"）；
3. **沉香成长**：沉香由刘彦昌抚养长大（刘沉香——"沉香"=救母之志如沉香木般坚定）——得知母亲被压华山——立志救母；
4. **宝莲灯**：得**宝莲灯**（至宝——[法宝/至宝体系]相关——"宝莲灯"神话重宝——灯=光明/希望/法力）——法力大增；
5. **劈山救母**：沉香持巨斧（开山斧）劈开华山——救出母亲（"斧劈华山"名场面——[上古神话典故/英雄与征战]"劈山"母题）——团聚（部分版本：与二郎神和解——"舅甥相认"——保留杨戬亦“劈过山”的呼应）。
