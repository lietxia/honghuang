# 女娲（娲皇·圣母）

人族之母、妖族之圣、天道圣人——洪荒流与上古神话中地位最特殊的存在：出身妖族却以"造人、补天"两件无量功德成圣，为洪荒功德证道典范。

## 身份
- **创始元灵四大弟子之一**（玄空气）——与鸿钧（玄清）、混鲲（玄灵）、陆压（玄明）同门（《创始元灵》体系设定，见[创始元灵/创始元灵与四大弟子]）；
- **妖族圣人**：妖族出身（一说人首蛇身），妖族天庭亦尊其地位——"招妖幡"号令万妖；
- **人族圣母**：抟土造人、补天救世——人族共认之母（[人族/起源与女娲造人]）；
- **天道圣人**：以造人功德+补天功德证道成圣——六圣之一（紫霄宫圣位，[大事件/紫霄宫分圣位与分宝]）；
- 居**娲皇宫**（三十三天外/女娲道场）。

## 神通
- **造化之道**：无中生有、点化万物——抟土造人、炼石补天皆赖此道；洪荒"造化大道"之代表；
- **功德证道**：造人、补天两件无量功德直接成圣——功德证道之典范（对应[概念/气运功德香火业力]）；
- **五色神光（补天衍生）**：炼五色石时显化的五行圆满之威（非孔宣五色神光，勿混淆）；
- **招妖幡神通**：一幡摇动、天下妖族听召——妖族圣者统御权柄；
- **山河社稷图神通**：图中演小千世界，入图者迷失其中难出；
- **补天之手**：炼石补天、断鳌足立四极——"补天"神通（[大事件/巫妖大战·不周山倾·女娲补天]）。

## 法宝
| 法宝 | 说明 |
|---|---|
| **山河社稷图** | 先天灵宝——图内自成一方世界，困敌于山河幻境，非大神通不可破（杨戬曾借以困袁洪） |
| **红绣球** | 本命法宝——主姻缘、缚敌（红线/绣球婚姻意象），一掷可定乾坤 |
| **招妖幡** | 统御万妖的号令之宝——摇动则群妖来朝（轩辕坟三妖即召之入宫） |
| **炼妖壶（九黎壶）** | 可收摄、炼化妖族，亦能化妖为人 |
| **九天息壤** | 不死不灭的神土——女娲造人、补天所用之材，落土即生（大禹治水亦用） |
| **五色石（补天石）** | 女娲炼五色石补天后有余石——**注意考据**：其中"青埂峰下顽石"化《红楼梦》贾宝玉；《西游记》花果山仙石原著为"天真地秀、日精月华"所孕孕出孙悟空，**并非女娲补天石**（"补天石化悟空"仅为民间衍生解读，两大名著设定混同属误传） |

## 故事
1. **造人**：巫妖纪元，女娲以九天息壤+自身精血抟土造人（藤条甩泥浆生更多人）——人族诞生，女娲功德成圣（[大事件/女娲造人]）；
2. **补天**：共工怒触不周山、天柱倾——女娲炼五色石补天、断鳌足立四极、积芦灰止水（[大事件/巫妖大战·不周山倾·女娲补天]）；
3. **封神伏笔**：纣王于女娲庙题诗亵渎（"凤凰鸾宝帐…"）——女娲怒，命轩辕坟三妖（妲己等）入宫乱商，由此开启封神大劫（[人物/妲己]、[量劫/封神大劫]）；
4. **超然立场**：妖族出身却立教化——巫妖大劫、封神大劫中皆处超然地位（不插手量劫、不沾因果，因功德护体）。

## 洪荒流设定
- 女娲是"圣母型"圣人：造人（人）、补天（天）、炼妖壶（妖）——人妖两族的天然纽带；
- 不立教（有别于三清立人教/阐教/截教）——故无教派气运之争，超然于后天杀伐；
- "人族气运"归属：女娲享人族香火（[概念/气运功德香火业力]）——洪荒流常设定女娲庇护人族（火云洞三皇与其呼应）。
