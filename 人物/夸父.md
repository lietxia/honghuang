# 夸父（逐日·夸父逐日）

中国神话中"追日"的巨人——夸父（《山海经》"夸父逐日"本出）。与日竞走、渴饮大泽不行、道渴而死——"弃其杖，化为邓林（桃林）"。夸父逐日=大无畏/不自量力两种解读并存——"知其不可为而为之"的悲壮英雄之一。洪荒流中为巫族大巫（土之道）。来源：《山海经·海外北经》《大荒北经》、[大事件/后羿射日与夸父逐日]。

## 身份
- **上古巨人**：《山海经》"夸父与日逐走"——追日巨人；
- 一说为**后土之孙、信之子**（"后土生信，信生夸父"——[人物/后土娘娘]系谱）——具有神（幽冥神系关联）；
- 一说为**炎帝后裔**（部分典籍"夸父夸娥氏"——巨人族）；
- **洪荒流**：巫族大巫（土之道——夸父为大地/巨力大巫）——与[人物/后羿]并列为巫族英雄（[势力/巫族]大巫）。

## 神通（特点）
- **逐日飞跑**：与日竞走——日行千里（巨人脚步）；
- **河渭饮干**：渴而饮河、渭（黄河渭水一度饮干）——又北饮大泽（未至）；
- **杖化邓林**：道渴而死——弃其杖——化为**邓林**（桃林——"夸父杖化桃林"传说，河南灵宝夸父山）；
- **巨人力士**：夸父族为巨人种族（"夸父逐日"成"逞强/执着"意象）。

## 故事
1. 夸父与日逐走——入日（追到太阳）；
2. 渴（日晒）——饮于河、渭——河渭不足（不足以解渴）——北饮大泽；
3. 未至——道渴而死——弃其杖化为邓林（桃林——遗爱人间，"杖化桃林"为悲伤结局添温情）；
4. 后世解读：
   - 大无畏说：追求光明的巨人（与[人物/精卫]填海并列——"知其不可为而为之"）；
   - 不自量力说："夸父逐日"喻不自量力（《列子》版本演化）——两种解读并存的罕见神话。

## 洪荒流设定
- 夸父为**巫族大巫**（土之道——大地巨人）——与[人物/后羿]（射日）同为"太阳之敌"（巫族vs金乌——妖庭十日）；
- 夸父逐日："巫族与太阳的悲歌"——夸父追日而亡→后羿射日报仇（[大事件/后羿射日与夸父逐日]）——巫妖大战的导火索之一；
- 洪荒流常设定夸父身高万丈/力量型大巫（与刑天/蚩尤并列巫族战神）。
