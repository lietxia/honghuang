# 夸父（逐日·夸父逐日·巫族大巫）

中国神话中"追日"的巨人——《山海经》"夸父与日逐走"。与日竞走、渴饮大泽不行、道渴而死——"弃其杖，化为邓林（桃林）"。夸父逐日=大无畏/不自量力两种解读并存——"知其不可为而为之"的悲壮英雄之一。洪荒流中为巫族大巫（土之道）——夸父逐日与后羿射日是巫妖大战的直接导火索。来源：《山海经·海外北经》《大荒北经》、[大事件/后羿射日与夸父逐日]。

## 身份
- **上古巨人**：《山海经》"夸父与日逐走"——追日巨人；
- 一说为**后土之孙、信之子**（"后土生信，信生夸父"——[人物/后土娘娘]系谱——幽冥神系关联）——神族血统；
- 一说为**炎帝后裔**（部分典籍"夸父夸娥氏"——巨人族——炎帝部落巨人）；
- **洪荒流**：巫族大巫（土之道——夸父为大地/巨力大巫）——与[人物/后羿]并列为巫族英雄（[势力/巫族]大巫——后土一脉）。

| 神通 | 说明 |

| **巨人力士** | 夸父族为巨人种族（"夸父逐日"成"逞强/执着"意象） |

## 故事
1. **夸父与日逐走**——入日（追到太阳——"入日"意象：追进太阳的热力范围）；
2. 渴（日晒）——饮于河、渭——**河渭不足**（不足以解渴——太阳之力）——北饮大泽；
3. **未至**——道渴而死——弃其杖化为邓林（桃林——"杖化桃林"为悲伤结局添温情——"夸父遗爱"）；
4. 后世解读：
   - **大无畏说**：追求光明的巨人（与[人物/精卫]填海并列——"知其不可为而为之"——陶渊明"夸父诞宏志，乃与日竞走"）；
   - **不自量力说**："夸父逐日"喻不自量力（《列子》版本演化——"夸父不量力，欲追日影"）——两种解读并存的罕见神话（褒贬两极）。
