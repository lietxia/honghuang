# 车迟国三妖（虎力·鹿力·羊力大仙）

《西游记》车迟国一难的三位妖道——虎力大仙（虎精）、鹿力大仙（鹿精）、羊力大仙（羊精）。三妖于车迟国求雨有功、被封国师——与唐僧师徒"赌斗"（祈雨/坐禅/猜物/砍头/剖腹/下油锅五场比试）——全败被灭（无后台野妖——被打死的典型）。来源：《西游记》第44-46回。

## 身份
- **虎力大仙**（虎精）、**鹿力大仙**（鹿精）、**羊力大仙**（羊精）——三妖道（车迟国国师）；
- 车迟国：三妖以法术求雨有功（虎力登坛祈雨——雷公电母风伯雨师应召）——被国王尊为国师——道教国师（贬佛——"拆佛寺、毁佛像"——车迟国灭佛）；
- **无后台野妖**——三妖道排佛（佛门之敌）——被悟空等“斗法”尽灭（西游"灭妖"的正面典型——对抗佛门的妖怪必死）。

## 三妖神通
| 大仙 | 原形 | 神通 |
|---|---|---|
| **虎力大仙** | 虎精 | **祈雨**（登坛焚符——雷公电母应召）、**砍头再生**（五雷法）——五场比试主力 |
| **鹿力大仙** | 鹿精 | **坐禅**（云台禅定）、**剖腹洗肠**（剖腹投水取五脏） |
| **羊力大仙** | 羊精 | **猜物**（隔板猜物——"山河社稷袄/乾坤地理裙"）、**下油锅**（冷龙护身） |

## 故事（西游记·车迟国斗法）
1. **车迟国灭佛**：国王尊三妖道为国师——拆佛寺、罚僧人（劳役）——三妖道"灭佛"背景；
2. **师徒入国**：唐僧师徒至车迟国——悟空/八戒/沙僧戏弄三妖道（毁三清观塑像——"供品入腹"名场面）——结怨；
3. **五场斗法**：国王主持比试——
   - 祈雨：虎力登坛——悟空上天阻雷公电母（"风婆婆"相助）——虎力祈雨失败、悟空祈雨成功；
   - 坐禅：鹿力vs唐僧（悟空变虫咬鹿力——鹿力败）；
   - 猜物：羊力vs悟空（悟空变穿山甲换物——羊力败）；
   - 砍头：虎力砍头（悟空变黄狗叼头——虎力死）；
   - 剖腹：鹿力剖腹（悟空变饿鹰叼五脏——鹿力死）；
   - 下油锅：羊力下油锅（悟空搅锅破冷龙——羊力死）；
4. **结局**：三妖道尽灭（现虎/鹿/羊原形）——车迟国复奉佛（"灭佛之国的翻案"）。
