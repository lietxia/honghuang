# 神通总览

神通是修行者以自身道行施展的术法——与法宝不同、不假外物。洪荒神通体系大体分**天罡三十六法**（道之变）、**地煞七十二术**（术之化）与**各家秘术**（教派本命）三大类，另有佛门六通、巫族本命神通等旁支。来源：综合百度百科（天罡地煞）、知乎、腾讯动漫、封神/西游原著。

## 神通体系关系
```
天罡三十六法（道之变·大神通）——斡旋造化/移星换斗/起死回生……
地煞七十二术（术之化·小法术）——通幽/隐身/定身/分身……
各家秘术（本命·教派特色）——五色神光/掌中佛国/太阳真火/祖巫法则……
佛门六通（六神通）——超感知类
```
- **天罡vs地煞**：天罡为"体"（本元变化）、地煞为"用"（外形变化）——天罡胜地煞（[神通/天罡地煞详解]）；
- **神通vs功法vs法宝**：功法筑基（[功法/功法总览]）、境界定高（[境界/境界详解]）、神通应用、法宝外物——四者配合。
