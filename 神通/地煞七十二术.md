# 地煞七十二术（全名单详解）

《西游记》中菩提祖师授孙悟空之神通（七十二般变化）——悟空为躲"三灾利害"而学（祖师授"地煞数七十二般变化"，悟空"愿多里捞摸"选了七十二变）。七十二术出自清·徐道《历代神仙通鉴》（《历代神仙演义》）上卷"地煞七十二术"——为七十二种具体法术的完整名录。来源：维基百科（七十二变）、百度百科（天罡三十六法地煞七十二术）。

## 二、分类解读
### 变化/形体类
| 术 | 说明 |
|---|---|
| 假形 | 变化外形（七十二变核心——变飞禽走兽/草木器物/人物） |
| 分身 | 化身千万（毫毛变猴子） |
| 隐形 | 隐匿身形 |
| 定身 | 定住目标不动 |
| 续头 | 断头再生（悟空被砍头复原） |
| 胎化易形（天罡） | 改变容貌体态（与假形相似） |
| 支离 | 支解身体重聚 |

## 三、相关设定比较
| 体系 | 说明 |
|---|---|
| **地煞七十二术** | 孙悟空/二郎神/牛魔王所修："七十二变"——重灵巧诡变、外形变化 |
| **天罡三十六法** | 猪八戒所修：三十六变——"变轻巧华丽飞腾之物不能"，变山/树/石/土墩/赖象/科猪/水牛/骆驼全会（"身体大、肚肠大"之故）；天罡胜地煞（见[神通/天罡地煞详解]） |
| **八九玄功** | "八九七十二"——杨戬（[人物/杨戬]）、袁洪（[人物/梅山七怪]）修：《封神演义》唯一会变化的阐教三代弟子 |
| 炼丹/御剑等 | 部分地煞术为其他道术归类（剑术/土行/布阵独立体系） |

## 四、地煞七十二术在洪荒流的应用
- 洪荒流中"七十二变"为变化神通代表（妖修/散修多会）——悟空、杨戬、六耳猕猴、袁洪皆以此闻名；
- 地煞术为"术"级神通（vs 天罡"法"级）——大罗以下修士常用（见[神通/天罡地煞详解]体用关系）；
- 封神/西游实战：悟空定身术定七仙女、假形变麻雀/鱼/庙宇；杨戬八九玄功变化降梅山七怪。
