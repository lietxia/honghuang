# 志怪精怪篇（聊斋志异·搜神记·精怪谱）

中国志怪小说中的精怪世界——以《聊斋志异》为代表的狐鬼花妖故事，是中国民间精怪信仰的文学巅峰。本篇收录志怪精怪谱系与名篇。来源：维基百科（聊斋志异/聂小倩）、维基文库、三联中读。

## 一、《聊斋志异》概述
- 清代蒲松龄著，完成于康熙年间（约1680年），共491篇（各版本452-496篇不等），以文言写狐仙、鬼、妖、花精。
- 成书轶闻：蒲松龄在家门口开茶馆，喝茶者可以一个故事抵茶钱——以此搜集民间鬼怪故事，历时40年。
- 文学地位：中国志怪小说巅峰，鲁迅评"用传奇法，而以志怪"；博尔赫斯盛赞其地位"犹如《一千零一夜》之在西方"。
- 主题：借狐鬼花妖写人性——"鬼比人还有情义"，暗含对社会（科举、贪腐、婚姻制度）的批判；清代文字狱时曾被列为禁书。

## 二、聊斋名篇精怪谱

### 狐仙类（聊斋最著名）
| 篇目 | 主角 | 故事 |
|---|---|---|
| **《婴宁》** | 狐女婴宁 | 爱笑的狐女，天真烂漫（"此女亦殊无黠"），大胆追求自由爱情——聊斋最著名的女性形象之一 |
| **《莲香》** | 狐女莲香 | 狐女与女鬼桑儿共爱一书生，人狐鬼三者的情谊 |
| **《娇娜》** | 狐女娇娜 | 表兄妹之谊，红颜知己（"腻友"说） |
| **《青凤》** | 狐女青凤 | 人狐恋，青凤知书达理 |
| **《红玉》** | 狐女红玉 | 助贫士成家、伸冤 |
| **《辛十四娘》** | 狐女辛十四娘 | 拼尽全力为丈夫冯生伸冤 |
| **《武孝廉》** | 狐女 | 被背叛后转身离开（"反恋爱脑"），果断止损 |

### 鬼类（聊斋经典）
| 篇目 | 主角 | 故事 |
|---|---|---|
| **《聂小倩》** | 女鬼聂小倩 | 十八岁夭亡女子，受夜叉胁迫害人，被正直书生宁采臣感化，弃暗投明、嫁与采臣，产子成家——聊斋改编最多的一篇（《倩女幽魂》） |
| **《画皮》** | 恶鬼 | 恶鬼披人皮化美女惑人（"披着人皮的鬼"），王生被挖心，妻子求疯乞丐救之——"画皮"成伪善者代名词 |
| **《陆判》** | 判官陆判 | 陆判官为朱尔旦换心（愚者聪）又为其妻换头（丑者美）——"换头"奇谭 |
| **《连琐》** | 女鬼连琐 | 月下吟诗之女鬼，与书生结缘 |
| **《公孙九娘》** | 女鬼九娘 | 于七案冤魂，人鬼恋悲剧 |
| **《王六郎》** | 溺鬼王六郎 | 善良溺鬼，不忍害替身，受封土地神 |

### 花精妖类
| 篇目 | 主角 | 故事 |
|---|---|---|
| **《葛巾》** | 牡丹花精葛巾 | 牡丹花神下凡嫁常生（"洛阳牡丹花下死"之浪漫） |
| **《香玉》《绛雪》** | 牡丹花精/耐冬花精 | 崂山下清宫花精与书生黄生 |
| **《黄英》** | 菊花精黄英 | 菊花精姐弟，善植菊 |
| **《西湖主》** | 龙女/鱼精 | 洞庭君之女 |

### 其他名篇
- 《崂山道士》：王生学穿墙术，心术不正，头触硬壁——"穿墙术"典故。
- 《促织》：成名因进贡蟋蟀，子魂化蟋蟀——讽科举/进贡之害。
- 《罗刹海市》：美丑颠倒之国（马骥以俊貌扮丑得宠）——讽世态。
- 《席方平》：孝子入冥司为父伸冤，历经酷刑——"席方平"成冥界抗争典型。
- 《山市》：海市蜃楼（淄川奂山山市）。
- 《考城隍》：生魂赴试选城隍（"有心为善，虽善不赏"）。

## 三、《搜神记》（东晋·干宝）与早期志怪
- 《搜神记》：东晋干宝著，中国最早的志怪小说集之一（"干宝《搜神记》"），记神仙、方术、精怪、鬼魂故事。
- 名篇：
  - 《干将莫邪》：铸剑名匠之子复仇；
  - 《董永》：孝子董永遇七仙女（牛郎织女/天仙配之源）；
  - 《毛衣女》：鸟衣女/田螺姑娘（"螺女"）；
  - 《韩凭夫妇》：生死不渝，墓树交枝（连理枝/鸳鸯）；
  - 《宋定伯捉鬼》：人智斗鬼；
  - 《左慈》《于吉》：方士术士传说（三国）；
  - 狐怪、树精、山精等精怪记载。

## 四、精怪谱系（中国民间精怪）
| 精怪 | 传说 |
|---|---|
| **狐仙** | 最有灵性之妖，狐仙/狐妖（九尾狐见[山海经异兽图鉴]）；化美女惑人（画皮/聊斋狐女），亦有善狐（报恩） |
| **蛇精** | 白蛇（见[上古神话典故/四大民间传说]白蛇传）、青蛇；蛇妖化人 |
| **花妖/树精** | 花精（牡丹/菊花/杏花）、树精（松/柏/槐）；树千年成精 |
| **尸妖/僵尸** | 尸变（聊斋《尸变》）、僵尸（跳尸/僵尸村）；白骨精为尸妖 |
| **水族精** | 鱼精、龟精、螺精（田螺姑娘）、虾蟹精 |
| **山魈** | 山中精怪（独脚/赤面），五通神之源（见[地祇/五显五通与财神信仰]） |
| **鬼** | 怨鬼/溺鬼（找替身）/冤魂/幽魂（聂小倩/连琐） |
| **精（草木山石）** | 石精、人参精（人参娃娃）、何首乌精 |
| **魑魅魍魉** | 山林鬼怪总称（《山海经》"魑魅魍魉"） |
| **夜叉** | 捷疾鬼（见[佛教/罗汉与天龙八部]）；聂小倩受"姥姥"（夜叉）胁迫 |

## 五、志怪精怪与洪荒流
- 洪荒流中精怪多归"妖族"（见[势力/妖族]）——狐、蛇、花、树、鬼修炼化形，属妖族修行体系。
- 聊斋/搜神记提供大量精怪素材：狐仙（妲己九尾狐）、白蛇（白素贞）、僵尸、山魈等，洪荒流可直接化用。
- 精怪与"草木花神"（见[地祇/草木花神]）、"身体神"（黄庭经身神）共同构成中国"万物有灵"信仰。
