# 少数民族神话（创世与族源）

中国五十五个少数民族（及汉族支系）世代口传的神话，是中华神话体系的另一半。各族的创世神话、洪水神话、族源神话、英雄神话，与中原汉族神话相互交融，共同构成"多元一体"的中华神话。来源：中国作家网（盘古神话研究）、彝族人网、中国民俗学会、百度百科（中国各民族神话）。

## 一、创世神话（开天辟地者各不同）
各民族的创世者形象极其丰富——创世神、祖先、图腾动物皆可开天辟地：

| 民族 | 创世者 | 开天辟地情节 |
|---|---|---|
| **壮族** | 布洛陀（男性始祖） | 开天辟地、定万物 |
| **瑶族**（布努支系） | 密洛陀（女性始祖） | 女性创世 |
| **阿昌族** | 遮帕麻（天公）/遮米麻（地母） | 兄妹/夫妇开天辟地 |
| **蒙古族** | 麦德尔娘娘（神女） | 女神创世 |
| **哈萨克族** | 萨迦甘（创世主） | 创世 |
| **鄂温克族** | 保鲁根巴格西（天神） | 天神创世 |
| **满族** | 创世萨满 | 萨满创世 |
| **苗族** | 巨鸟 | 巨鸟生天地 |
| **藏族/独龙族** | 蚂蚁 | 蚂蚁分开天地 |

## 二、盘古神话的少数民族流传
- **盘古母题**遍布绝大多数民族：土家族《盘古开天，女娲补天》、侗族《古老和盘古》、壮族《盘古创世》、毛南族《盘古的传说》、苗族《盘皇造万物》。
- **盘古名称不固定**：盘古/盘瓠/盘王/盘果王混同；不少民族将盘古与伏羲相混（闻一多《伏羲考》：盘瓠本义葫芦，伏羲女娲本义亦葫芦，"字异声义同"）；道教称盘古为元始天王。
- **盘古来历各异**：壮族=天上贬下之神；毛南族=土地神子孙；瑶族=云彩所生；侗族=蟠桃所化。
- **盘古体貌各异**：汉族有身高一万八千丈/九万里/十万八千里诸说；土家族一丈二尺五；白族一丈八；侗族三丈六；形象有龙头蛇身/虎头人身/三头六臂等。
- 学术界多认为：盘古、伏羲、女娲神话或源出南方少数民族，后传入中原、经文人加工定型。

## 三、族源神话（多民族"一母所生"）
许多族源神话叙述多民族同出一源，是"中华民族共同体意识"的古老表达：
| 民族 | 族源神话 |
|---|---|
| **阿昌族** | 遮帕麻兄妹婚生大葫芦，出汉族、傣族、景颇族、傈僳族、阿昌族、德昂族等九民族 |
| **布朗族** | 天上四兄弟降世为汉、佤、布朗、拉祜、傣族 |
| **德昂族** | 茶树叶变各民族祖先（汉族、傣族、白族等） |
| **独龙族** | 洪水后兄妹婚生九对男女，繁衍汉族、怒族、独龙族等九族 |
| **哈尼族** | 一女人感风孕子成汉、哈尼、彝、傣、白等族 |
| **基诺族** | 玛黑玛妞兄妹种大葫芦生汉族、基诺族、傣族 |
| **拉祜族** | 葫芦生一对男女，结婚繁衍多族 |
| **傈僳族** | 盘古劈南瓜，兄妹婚生三男繁衍汉族、彝族、傈僳族 |
| **珞巴族** | 太阳子+月亮女婚生汉、藏、珞巴、门巴族 |
| **纳西族** | 两只猴子婚生子变汉、藏、纳西族 |
| **怒族** | 洪水后兄妹婚生七对子女成汉、白、傈僳、怒、藏族等 |
| **佤族** | 从石洞走出汉族、佤族、拉祜族、傣族 |
| **藏族** | 四兄弟变汉、珞巴、虎、乣祖先 |
| **瑶族** | 女始祖密洛陀众女儿造出汉族、壮族、苗族、瑶族 |
| **苗族** | 洪水后召亚兄妹婚生汉、苗、彝族 |

## 四、各民族特色神话（专题）
- **苗族**：《苗族古歌》——神巨人开天辟地（盘古神话开中国创世神话先河）；洪水神话、枫树蝴蝶妈妈（祖先图腾）。
- **瑶族**：盘古神话体系最完整（瑶人保存的盘古神话"开中国创世神话先河"）。
- **彝族**：创世史诗《勒俄特依》《梅葛》、支格阿鲁英雄神话（射日月）。
- **纳西族**：《创世纪》——崇仁利恩与衬红褒白洪水神话。
- **蒙古族**：麦德尔娘娘创世、成吉思汗祖先神话（孛儿帖赤那/苍狼白鹿）。
- **藏族**：《格萨尔》史诗（世界最长史诗）、猕猴与罗刹女（人类起源）、苯教创世。
- **满族**：天宫大战、萨满创世、长白山天池传说。
- **壮族**：布洛陀创世、莫一大王、刘三姐（歌仙）。
- **维吾尔族**：乌古斯可汗、狼图腾（阿史那）。
- **朝鲜族**：檀君神话（桓因天王之子檀君开国）。
- **白族**：本主信仰（各村守护神）。
- **傣族**：英叭创世（开天辟地）、泼水节（七公主斩魔）。
- **鄂伦春/鄂温克/赫哲族**：萨满教、鹿神/熊神图腾、自然崇拜。

## 五、少数民族神话与洪荒流
- 洪荒流设定可化用少数民族神话：盘古（各族创世母题）、洪水神话（大洪水=量劫）、创世神（布洛陀/密洛陀/遮帕麻/麦德尔可作"混沌魔神"原型）、图腾（苍狼白鹿/枫树蝴蝶/茶树叶）。
- 少数民族神话为洪荒流提供"多元创世者""图腾修炼""萨满/巫术体系"等新素材，与汉族神话互补。
