# 封神大劫时间线

洪荒第三场量劫——阐截之争、商周兴替、封神榜定。

## 时序
1. **纣王题诗** → 商纣王（帝辛）在女娲庙题诗亵渎女娲——女娲命轩辕坟三妖（妲己等）入宫乱商（[人物/妲己]）。
2. **姜子牙下山** → 玉虚宫姜子牙奉师命下山——渭水垂钓、遇文王、拜相（封神执行人，[人物/姜子牙]）。
3. **崇侯虎/张桂芳征西岐** → 哪吒下山助周——封神之战开幕（姜子牙金台拜将）。
4. **魔家四将/九龙岛四圣** → 闻仲请截教助阵——九龙岛四圣（王魔等）、魔家四将（[人物/九龙岛四圣]、[人物/魔家四将]）先后败亡。
5. **十绝阵** → 金鳌岛十天君摆十绝阵（[人物/十天君]）——阐教燃灯率众破阵（天绝/地烈/风吼/寒冰/金光/化血/烈焰/落魂/红水/红砂）。
6. **赵公明下山** → 赵公明（定海珠/缚龙索）连败阐教——被陆压钉头七箭书拜死（[人物/赵公明]、[人物/陆压道君]）。
7. **九曲黄河阵** → 三霄娘娘（混元金斗+金蛟剪）摆九曲黄河阵削十二金仙顶上三花——元始/老君亲临破阵，三霄陨落（[人物/三霄娘娘]）。
8. **诛仙剑阵** → 通天教主摆诛仙剑阵（非四圣不可破）——四圣（元始/老君/接引/准提）联手破阵（[阵法/诛仙剑阵]）。
9. **万仙阵** → 截教倾巢万仙阵（[阵法/万仙与九曲黄河]）——阐教+西方教联手，截教覆灭（多宝被擒、金灵/龟灵/乌云仙等陨落或渡走）。
10. **闻仲绝龙岭** → 十绝阵尽破后闻仲败走——云中子通天神火柱烧死于绝龙岭（[人物/闻仲]）。
11. **姜子牙封神** → 岐山封神台——364/365位正神入榜（八部正神，[大事件/封神榜三百六十五位正神]）。
12. **武王伐纣** → 牧野之战，商军倒戈——纣王摘星楼自焚（[人物/纣王与商周群臣]）。
13. **周朝建立** → 封神大劫终结——天庭充实（365正神）、西方教东扩（佛门兴起前奏）。

## 关键
- 封神大劫是三教（阐/截/人道）气运之争的结果——截教"有教无类"终被清算，阐教"顺天"获胜，西方教"渔翁得利"。
- 封神榜正神：死后封神（香火神道）vs 肉身成圣（李靖/哪吒/杨戬等7人）——两种结局对照。
- 零售商周之战为人间线，仙人斗法为天上线——"量劫显化为战争"。
