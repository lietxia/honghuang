# 封神大劫时间线

洪荒第三场量劫，也是最详细的一场——三教之争，封神榜定。

## 时序
1. **纣王题诗** → 商纣王在女娲庙题诗亵渎，女娲命轩辕坟三妖（妲己等）入宫乱商。
2. **姜子牙下山** → 昆仑玉虚宫弟子下山，渭水垂钓遇文王，拜相封神。
3. **张桂芳征西岐** → 哪吒下山助周，封神之战正式开始。
4. **魔家四将** → 魔礼青/红/海/寿征西岐，杨戬下山破魔家四将。
5. **十绝阵** → 闻仲请十天君布十绝阵（天绝/地烈/风吼/寒冰/金光/化血/烈焰/落魂/红水/红砂），阐教破阵。
6. **赵公明下山** → 以定海珠连败玉虚诸仙，燃灯不敌；后陆压以钉头七箭书拜死赵公明。
7. **九曲黄河阵** → 三霄为兄报仇，以混元金斗+金蛟剪布阵，削十二金仙顶上三花。元始天尊与太上老君亲临破阵，三霄陨落。
8. **诛仙阵** → 通天教主布诛仙剑阵，非四圣不可破。太上老君、元始天尊、接引道人、准提道人四圣联手破阵。
9. **万仙阵** → 截教最后大阵，万仙来朝。四圣+阐教大破万仙阵，截教覆灭，通天被鸿钧带走。
10. **姜子牙封神** → 封三百六十五位正神（雷部/火部/瘟部/斗部/太岁等），充实天庭。
11. **周朝建立** → 商灭周兴，封神大劫终结。

## 关键
- 截教万仙应劫，阐教也元气大伤，十二金仙被削三花后需重修炼。
- 封神榜使天庭从空虚走向充实，昊天正式执掌三界。
- 西方教借机收走孔宣、乌云仙等截教精英，为佛教大兴奠定基础。
