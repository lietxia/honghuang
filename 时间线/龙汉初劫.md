# 龙汉初劫时间线

洪荒第一场量劫——三族大战与道魔之争的时序梳理。

## 时序
1. **盘古开天** → 洪荒初成，先天三族（龙/凤/麒麟）鼎立。
2. **三族争雄** → 祖龙统鳞甲（龙族）、元凤统飞禽（凤族）、始麒麟统走兽（麒麟族），争夺天地主角。
3. **罗睺挑拨** → 魔道魔神罗睺暗中以诛仙四剑布西方，引三族煞气入阵，挑拨三族关系。
4. **三族大战** → 全面战争爆发，洪荒大地破碎，生灵涂炭。三族俱伤无一胜者。
5. **道魔之争** → 罗睺出手欲夺天地气运，鸿钧+杨眉大仙+乾坤老祖+阴阳老祖四人联手战罗睺。罗睺自爆，诛仙四剑与阵图被鸿钧所得。
6. **鸿钧合道** → 以造化玉碟残片合天道，成道祖，于紫霄宫传道三千客。
7. **三族退隐** → 龙族退守四海（四海龙王为后裔），凤族隐于南明火山，麒麟族几乎绝迹。
8. **纪元终结** → 龙汉初劫终结，洪荒进入道祖纪元（紫霄宫讲道→巫妖纪元）。

## 关键
- 此为洪荒第一场量劫，确立了"量劫=天道清算"的规则。
- 三族从此退出天地主角之争，再无复兴之机。
- 罗睺虽败但魔道不灭，道魔之争成为洪荒流贯穿始终的重要叙事线。
