# 龙汉初劫时间线

洪荒第一场量劫——先天三族（龙/凤/麒麟）大战与道魔之争。这场量劫奠定"量劫=天道清算"的规则，同时完成洪荒最具转折性的事件：**鸿钧合道成道祖**。来源：[量劫/龙汉初劫]、[人物/罗睺]、[大事件/魔道之争·鸿钧VS罗睺]。

## 时序
1. **盘古开天** → 洪荒初成——先天三族鼎立（龙族掌海、凤族掌天、麒麟族掌地——[先天三族/总览]）；
2. **三族鼎盛** → 祖龙（龙族）、元凤（凤族）、始麒麟（麒麟族）各自统类称霸——争夺天地主角之位；
3. **罗睺布局** → 魔道魔神罗睺（西方混沌）以诛仙四剑+诛仙阵图布阵——引三族煞气、挑拨离间——"以杀证道"（[人物/罗睺]）；
4. **三族大战（龙汉初劫爆发）** → 祖龙/元凤/始麒麟率族全面开战——洪荒大地破碎、生灵涂炭（"量劫"机制首次显化——[量劫/量劫机制]）；
5. **三族俱伤** → 祖龙力竭（身陨，龙族退守四海——[地祇/龙王体系]）；元凤重伤垂死（凤族隐南明火山——[人物/孔宣]）；始麒麟陨落（麒麟族几乎绝迹——四不相遗世——[人物/姜子牙]）；
6. **罗睺现身** → 罗睺趁乱以诛仙剑阵割据西方——魔道气运大盛——道魔决战一触即发；
7. **道魔之争** → 鸿钧老祖+杨眉大仙+乾坤老祖+阴阳老祖四大高手联手战罗睺——诛仙剑阵"非四圣不可破"——前后历经苦战（[大事件/魔道之争·鸿钧VS罗睺]）；
8. **罗睺自爆** → 罗睺不敌自爆（以魔道本源殉道）——魔道虽败但魔念不灭（"魔祖不灭"）；
9. **鸿钧合道** → 鸿钧得罗睺遗落的诛仙四剑+阵图——又以造化玉碟参悟天道——最终**以身合道**（成道祖）——紫霄宫时代开启（[人物/鸿钧老祖]）；
10. **三族退隐** → 龙/凤/麒麟退出天地主角之争——洪荒进入新纪元（巫妖崛起之序——[时间线/巫妖大劫]）。

## 关键
| 事件 | 影响 |
|---|---|
| 量劫确立 | 龙汉初劫确立"量劫=天道清算"规则（气运洗牌机制——[概念/气运功德香火业力]） |
| 魔道永存 | 罗睺虽死魔道不灭——后世魔劫不断（洪荒流常见设定"魔祖不灭"——[人物/罗睺]） |
| 鸿钧合道 | 鸿钧成为道祖——圣人时代（紫霄宫圣位——[大事件/紫霄宫分圣位与分宝]）随之而来 |
| 诛仙四剑 | 罗睺之宝归鸿钧→分宝岩赐通天——封神"非四圣不可破"之阵（[阵法/诛仙剑阵]） |
