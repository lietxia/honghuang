# 西游量劫时间线

洪荒第四场量劫，以取经为表、佛门东扩为实。

## 时序
1. **封神之后** → 西方教演变为佛教，如来为佛祖，佛门大兴。
2. **佛道暗争** → 佛门欲东扩传法，道门（天庭）固守中土，佛道气运之争暗流涌动。
3. **悟空出世** → 花果山仙石迸裂，灵明石猴出世。拜菩提祖师学艺，得七十二变、筋斗云、八九玄功、金刚不坏。
4. **大闹天宫** → 悟空闹龙宫得金箍棒、闹地府勾生死簿，自封齐天大圣。十万天兵不敌，二郎神擒拿后八卦炉反炼成火眼金睛。如来出手镇压于五行山下。
5. **取经启动** → 五百年后，如来命金蝉子（唐僧）转世取经，观音寻取经人，收悟空、八戒、沙僧、白龙马。
6. **九九八十一难** → 取经路沿途降妖除魔，佛门势力随取经路线东扩。每降一妖，佛门即在当地建一寺。
7. **取经成功** → 到达西天大雷音寺，取经成功。各封佛位：唐僧旃檀功德佛、悟空斗战胜佛、八戒净坛使者、沙僧金身罗汉、白龙马八部天龙。
8. **佛门东扩** → 佛教在中土广泛传播，与道门鼎立。西游量劫后，洪荒进入佛道鼎立、人皇治世的格局。

## 关键
- 西游量劫本质是佛道气运的重新分配，取经路上的妖魔多属道门/天庭，被打死即佛门势力扩张。
- 西游量劫规模远小于封神大劫，但影响深远——佛教从此在东方站稳脚跟。
- 佛道关系在西游量劫后趋于稳定，形成"佛道鼎立、人皇治世"的格局。
