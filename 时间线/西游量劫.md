# 西游量劫时间线

洪荒第四场量劫——取经为表、佛门东扩为实，佛道格局大洗牌。与前三次量劫（龙汉/巫妖/封神）不同——西游是"软量劫"：不以大规模杀伐清算，而以"佛门东扩"完成气运转移。八十一难=佛门"演劫"——每难对应因果业力消解。来源：[量劫/西游量劫]、[大事件/西游取经与佛门东扩]。

## 时序
1. **封神之后** → 西方教演变为佛教（如来为佛祖）——佛门大兴——"西牛贺洲"成佛门根基（[教派/西方教与佛教]）；
2. **佛道暗争** → 佛门欲东扩传法、天庭（道门）固守中土——佛道气运之争暗流涌动（天庭孙悟空之乱正是棋子）；
3. **悟空出世** → 花果山仙石迸裂、灵明石猴出世——拜菩提祖师（灵台方寸山斜月三星洞）学艺——得七十二变/筋斗云/长生诀（[人物/孙悟空]）；
4. **大闹天宫** → 悟空闹龙宫（金箍棒——[地祇/龙王体系]）、闹地府（勾生死簿）、大闹天宫（十万天兵不敌）——如来以"掌中佛国"镇压于五行山下（[人物/如来佛祖]）；
5. **取经启动** → 如来命金蝉子（唐僧）转世——观音寻取经人——唐僧+悟空+八戒+沙僧+白龙马组队（[人物/唐僧]等各篇）；
6. **西行之路** → **九九八十一难**——途中所遇妖怪多为天庭/佛门"内部人士下凡"（[人物/西游记妖怪全录]）：黑熊精/黄风怪/奎木狼/金角银角/青牛精/牛魔王/九灵元圣/狮驼岭三魔等；
7. **佛门东扩完成** → 取经成功——师徒五圣成真（旃檀功德佛/斗战胜佛/净坛使者/金身罗汉/八部天龙马）——佛教在中土广泛传播；
8. **格局定格** → 西游量劫终结——"佛道鼎立、人皇治世"格局形成——洪荒进入平稳期。

## 关键
- **"软量劫"**：不以大规模杀伐清算——而以"取经"完成气运转移——（对比前三次量劫的血腥）；
- 八十一难=佛门"演劫"——每难对应因果业力消解（[量劫/量劫机制]）；
- **"有后台的妖怪被救走、没后台的被打死"**——反映佛道天庭势力渗透（[人物/西游记妖怪全录]"西游潜规则"）；
- 佛道暗争的隐喻：老君坐骑（青牛精——[人物/青牛精]）、寿星白鹿、嫦娥玉兔——天庭"道具"轮流下凡——道门在规则内展示底蕴（[大事件/西游取经与佛门东扩]深层解读）。
