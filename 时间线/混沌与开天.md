# 混沌与开天时间线

洪荒世界从混沌到开天的序章——宇宙诞生与盘古开天辟地。

## 时序
1. **混沌未分** → 天地未开，只有一团混沌（无极）——"鸿蒙初辟，混沌未分"。
2. **创始元灵诞生** → 混沌中孕育出创始元灵（一说盘古自混沌中醒）——混沌三千大道的本源（见[创始元灵/初创世元灵]）。
3. **三千魔神孕育** → 混沌中随大道法则诞生三千混沌魔神——各掌一道（时间/空间/命运/造化/毁灭等，见[宇宙/混沌魔神]）。
4. **盘古开天** → 盘古（力之大道/创世神）执盘古斧劈开混沌——清浊分离：清气上升为天、浊气下沉为地（见[大事件/盘古开天与三千魔神之战]）。
5. **斩三千魔神** → 开天途中三千魔神阻挠（不愿混沌被破），盘古以力证道横扫诸魔——魔神血洒洪荒、怨气化先天生灵（血海冥河、先天灵宝等）。
6. **盘古身陨** → 天地成形后盘古力竭身陨：双目化日月、呼吸化风云、血脉化河流、肌肉化山岳、元神化三清、精血化十二祖巫（[人物/三清]、[人物/十二祖巫]）。
7. **洪荒初成** → 盘古之躯撑天立地（天日高一丈、地日厚一丈），最终天地稳固，洪荒世界诞生——随后进入先天三族时代（龙汉初劫序幕）。

## 关键
- 开天量劫：洪荒第一场大劫（开天之劫）——盘古以力证道失败身陨，但为洪荒奠定一切。
- 盘古遗产：开天三宝（太极图/盘古幡/混沌钟）+先天灵宝无数——洪荒乱局的"兵工厂"。
- 三千魔神执掌的法则，成为后世修行法则（三千大道，见[宇宙/三千大道]）。
