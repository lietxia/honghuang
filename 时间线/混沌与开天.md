# 混沌与开天时间线

洪荒世界从混沌到开天的序章——宇宙诞生与盘古开天辟地。这场"开天之劫"是洪荒第一场大变局：盘古劈混沌、斩三千魔神、身化万物——奠定洪荒世界的一切基础。来源：[大事件/盘古开天与三千魔神之战]、[宇宙/混沌魔神]。

## 时序
1. **混沌未分** → 天地未开——只有一团混沌（无极）——"鸿蒙初辟、混沌未分"；
2. **创始元灵诞生** → 混沌中孕育出创始元灵（一说盘古自混沌中醒）——混沌三千大道的本源（[创始元灵/创始元灵与四大弟子]）；
3. **三千魔神孕育** → 混沌中随大道法则诞生三千混沌魔神——各掌一道（时间/空间/命运/造化/毁灭等——[宇宙/混沌魔神]、[大事件/三千魔神法则榜]）；
4. **盘古开天** → 盘古（力之大道/创世神）执盘古斧劈开混沌——清浊分离：清气上升为天、浊气下沉为地（[大事件/盘古开天与三千魔神之战]）；
5. **斩三千魔神** → 开天途中三千魔神阻挠（不愿混沌被破）——盘古以力证道横扫诸魔——魔神血洒洪荒、怨气化先天生灵（血海冥河/先天灵宝等）；
6. **盘古身陨** → 天地成形后盘古力竭身陨——双目化日月、呼吸化风云、血脉化河流、肌肉化山岳、**元神化三清**（[人物/三清]）、**精血化十二祖巫**（[人物/十二祖巫]）；
7. **洪荒初成** → 盘古之躯撑天立地（天日高一丈、地日厚一丈——天倾西北/地陷东南之由来）——最终天地稳固——洪荒世界诞生——随后进入先天三族时代（龙汉初劫序幕——[时间线/龙汉初劫]）。

## 洪荒流与其他神话的对应
- 盘古开天 ↔ 希腊"混沌生盖亚"、北欧"巨人伊米尔"——各文明创世母题的共象；
- 盘古化万物 ↔ 亚当夏娃/盖亚——"身体化生"型创世（[参考/经典书目与流派沿革]《三五历纪》首创）；
- 三千魔神 ↔ 希腊提坦神族（旧神时代——被新神取代的母题）——洪荒流独创的"旧神"设计。
