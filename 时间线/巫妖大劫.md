# 巫妖大劫时间线

洪荒第二场量劫——妖族天庭与巫族两败俱伤、人族趁势崛起。这是洪荒流最惨烈的量劫：周天星斗大阵vs都天神煞大阵、后羿射日、共工触不周山、女娲补天、后土化轮回——一役改变天地格局。来源：[量劫/巫妖大劫]、[人物/妖族天庭]、[人物/十二祖巫]。

## 时序
1. **妖庭建立** → 帝俊、东皇太一（太阳星金乌）成立妖族天庭——统御万妖、掌天界（[人物/妖族天庭]、[势力/妖庭（妖族天庭）]）；
2. **巫族立族** → 十二祖巫率巫族居大地——不修元神、肉身成圣——与妖庭分庭抗礼（[人物/十二祖巫]）；
3. **女娲造人** → 人族诞生（女娲以九天息壤+精血抟土造人）——"天地间第三方势力"出现（[人族/起源与女娲造人]）；
4. **矛盾积累** → 妖庭欲食人（妖族以人族为食粮——人族血食避祸）；巫族与妖族地盘冲突不断（"巫妖分治天地"的矛盾结构）；
5. **夸父逐日** → 夸父（巫族大巫）逐日渴死——巫妖矛盾激化（[大事件/后羿射日与夸父逐日]、[人物/夸父]）；
6. **后羿射日** → 后羿射落九只金乌（帝俊之子——[人物/后羿]）——巫妖大战正式爆发；
7. **巫妖全面战争** → 妖族**周天星斗大阵**vs巫族**都天神煞大阵**（十二祖巫合体召盘古真身）——洪荒天崩地裂（[阵法/周天与都天神煞]）；
8. **共工触不周山** → 共工（水之祖巫）怒触不周山（天柱折断）——天倾西北、地陷东南、洪水滔天（[人物/共工]）；
9. **女娲补天** → 女娲炼五色石补天、断鳌足立四极（[大事件/巫妖大战·不周山倾·女娲补天]）；
10. **两败俱伤** → 帝俊/太一陨落（东皇钟传陆压——[人物/陆压道君]）；十二祖巫除后土全数战死——巫妖同归于尽；
11. **后土化轮回** → 后土（土之祖巫）感众生魂魄无归——以身化六道轮回（幽冥建立——[人物/后土娘娘]、[幽冥/总览]）；
12. **人族崛起** → 巫妖退场，人族（三皇五帝治世）成为天地主角——下一纪元开启（[人族/三皇五帝]）。

## 关键
- 巫妖大劫为最惨烈量劫——"杀劫洗牌"彻底完成（巫族灭族边缘、妖族元气大伤）——量劫清算的极致样本（[量劫/量劫机制]）；
- 不周山倾为女娲补天提供洪荒最大"补丁"事件——共工怒触不周山成"天倾西北"的宇宙观（天倾西北/地陷东南——[地理/总览]）；
- 后土化轮回虽非圣人——却补全天道轮回空缺——功德无量（平心娘娘——[概念/气运功德香火业力]功德）；
- 量劫规律验证：旧主角（巫妖）退场→新主角（人族）崛起（[概念/气运功德香火业力]气运转移）。
