# 巫妖大劫时间线

洪荒第二场量劫，也是最为惨烈的一劫——巫妖两败俱伤，人族崛起。

## 时序
1. **妖庭建立** → 帝俊、太一立妖族天庭，统御万妖，掌周天星斗。
2. **巫族立族** → 十二祖巫统十二部落，居大地，掌都天神煞。
3. **女娲造人** → 人族诞生，成天地间第三方势力，但尚弱小。
4. **夸父逐日** → 夸父追日渴死，巫族与妖族矛盾激化。
5. **后羿射日** → 后羿射杀九日金乌（帝俊之子），巫妖大战全面爆发。
6. **全面战争** → 周天星斗大阵 vs 都天神煞大阵，天崩地裂，日月无光。
7. **共工触山** → 共工战败后怒触不周山，天柱折，天西北倾、地东南陷。
8. **女娲补天** → 炼五色石补苍天，断鳌足以立四极，杀黑龙济冀州，积芦灰止淫水。
9. **同归于尽** → 帝俊、太一与东皇钟俱陨，十二祖巫除后土外全部战死。
10. **后土化轮回** → 后土见世间怨魂无数，以身化六道轮回，建立幽冥地府。
11. **人族崛起** → 巫妖两败俱伤，人族成为天地主角，进入人道纪元。

## 关键
- 洪荒史上最惨烈的量劫，奠定"巫妖俱伤、人族崛起"的格局。
- 不周山倾后，天界与人界通道断绝，天庭需通过封神重建。
- 后土化轮回后，幽冥地府体系建立，六道轮回运转。
