# 洪荒流世界观百科

> 中国神话 / 洪荒流小说的系统化设定百科。洪荒流是以《封神演义》《西游记》为蓝本、吸收《山海经》《风俗通》等神话，并融汇道教典籍衍生的网络小说流派，开山之作是梦入神机的《佛本是道》（2006），体系由《重生混元道》《莽荒纪》等逐步完善。
>
> **两大铁律**：① 圣人之下皆蝼蚁；② 量劫清算因果、重开天地。

本仓库按主题分目录整理，方便检索与扩展。所有条目均经多渠道（百度百科、知乎、起点、游侠、NGA、Tavily 等）交叉核查。
